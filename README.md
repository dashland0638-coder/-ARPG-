# ソウルフォージ・プロトタイプ

見下ろし型(トップダウン)3D ARPG。`basefile.html` 1ファイルに、描画・ロジック・UI・アセット生成のすべてが収まっている。ビルド不要、ブラウザで直接開けば動く。

## 遊び方

`basefile.html` をブラウザで開くだけ。ローカルサーバーも不要(`file://` で完結)。

1. 職業・性別・性格・名前を決め、ダイスで能力値を割り振ってキャラを作る
2. 街(酒場)を拠点に、鑑定所で装備・スキル・スフィア(アビリティ)を整える
3. 出撃メニューから6つのダンジョンいずれかへ。ボスを倒す、あるいは撤退で街に戻る
4. 進行状況は自動的にセーブされる(下記「セーブデータ」を参照)

対応入力: キーボード+マウス / タッチ(仮想スティック) / ゲームパッド(Backbone One等、USB/Bluetooth接続で自動認識)。

## 技術構成

- **描画**: Three.js(CDN経由、`cdn.jsdelivr.net` から SRI ハッシュ付きで読み込み。バージョンは `<script>` タグに直書き)
- **テクスチャ**: 外部画像なし。すべて `<canvas>` 上で手続き的に生成(木目・石畳・芝生など)
- **効果音**: 外部音声ファイルなし。WebAudio で都度合成
- **保存**: `localStorage`。キャラ進行(`soulforge_save_v1`)と表示設定(`soulforge_settings_v1`)は別スロット
- **フォント**: Google Fonts(Cinzel / Noto Serif JP / Noto Sans JP)

依存パッケージのインストールやバンドラーは無い。`basefile.html` を編集してブラウザをリロードするだけで反映される。

## ファイルの歩き方

`basefile.html` は約17,700行、1つの `<script>` に約500関数が収まっている。大まかな並び順:

| 行の目安 | 内容 |
|---|---|
| 冒頭 `<style>` | 全UIのCSS(タイトル/HUD/メニュー/鑑定所など) |
| 1350〜 | クラス定義・キャラメイクUI・ダイス割り振り |
| 1770〜 | Three.js初期化、手続きテクスチャ生成 |
| 2200〜 | ワールド構築の共通処理(壁・扉・階段・当たり判定) |
| 4000〜6900 | 各ダンジョンのビルド関数(`buildForest` / `buildClocktower` / `buildTavern` / `buildMansion` / `buildGhostShip` / `buildWaterway...` など) |
| 7000〜9000 | プレイヤー/敵のリグ・アニメーション |
| 9000〜11000 | 出現・湧き・ボスの特殊行動 |
| 11300〜12200 | ダメージ計算・ドロップ・装備・所持品 |
| 12200〜 | `state`(ゲーム状態)定義、セーブ/ロード、入力(キー/タッチ/ゲームパッド) |
| 13900〜15500 | 会話・ボス撃破演出・スキル/スフィア/ショップUI |

| 17400〜末尾 | 設定バインド、`beginGame` / `continueGame`、起動処理 |

セクション区切りは `// ====` 系のコメント見出しを検索すると拾いやすい。

## セーブデータ

- **`soulforge_save_v1`**: キャラの進行(レベル・装備・所持品・スキル/スフィア・クリア済シナリオなど)。街に戻るたび・メニューの「セーブ」・タブを非アクティブにした瞬間・ページを閉じる直前に自動保存される
- **`soulforge_settings_v1`**: 音量・画質・画面の揺れなどの表示設定。キャラとは独立に、起動時へ復元される
- 「新しく始める」は既存のセーブを上書きする(確認ダイアログあり)
- ダンジョン内の座標そのものは保存対象外。再開時は必ず街(酒場)から始まる

## 未実装のシナリオ

`SCENARIO_DEFS` 内の `pyramid`(砂漠のピラミッド)・`volcano`(業火の火山)は `unlocked:false` のまま出撃メニューに「近日追加予定」として表示される。ワールド構築関数はまだ存在しない。

## 既知の制約

- 単一HTMLファイルという構成上、自動テストやリンタは未整備
- エラーハンドリングは主要な境界(起動処理・ワールド構築)に限定的に入っている程度
- モバイル実機でのタッチ操作の当たり判定は未検証の組み合わせが残っている
