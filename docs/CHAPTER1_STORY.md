## 1. 守ること（不変）

- **主人公と支援の顔ぶれ、交代の時期、一本道、再訪なし**は Chapter 1 System Freeze のまま。
- **新しい敵・ボス・マップ・システムを作らない。** 道は新規敵なし・強敵なし・ボスなし。ボスの性能・フェーズも変えない。
- **怪異の正体を断定しない。「ずれ」の原因も、第一章では説明し切らない。**
- **台詞は短く、説明しない。** 行動から伝わる台詞を優先する（洋館・村の基準）。
- **第一章の台詞は本編（`legacyGrowth()` が false）のときだけ出す。** テストモードと将来の周回（Chapter 2 以降）では、既存の周回用の台詞をそのまま残す。
- 第一章では行けない場所（地下水路・神殿・温室）へ本筋を向けない。幽霊船の「瓶の手紙」（地下水路を指す）は既存のまま残す。

## 2. 第一章を通す糸 ―― 「ずれ」の連鎖

第一章の怪異は、どれも本来の時や形から**ずれて**いる。これは**台詞で説明しない**。並べて見せるだけで、プレイヤーが気づく。

| 段 | ずれ | 見せ方（既存） |
| --- | --- | --- |
| 森の洋館 | 影が人から離れ、遅れて追う | 館の主 Phase 3、本体の 0.42 秒後に影が追撃する |
| 宵待ちの村 | 記憶が遅れて繰り返される | 水門守の残響（1.6 秒遅れ）、村の残響 |
| 幽霊船 | 帰るはずの時から進めない船 | 港を見失ったまま霧を漂う |
| 時計塔 | 時刻が七時十三分で止まる | 時喰らい、鐘の停止 |
| 道 | 正体不明の人物の影が、本人よりわずかに遅れて動く | 橋に残る影、島から見える人影 |

**第一章の核心**

- 四人は怪異の正体を最後まで分からない。それでも「見る → 理解する → 位置を選ぶ → 時を合わせる → 崩す」ことはできた。
- 最後に出会うのは、同じ「ずれ」を持った人物。四人は正体を完全には理解できないまま、その人物と**一緒に歩くことを選ぶ**。

## 4. 各段の物語

台詞例は**意味の基準**。言い回しは実装時に洋館・村の人物の基準で整えてよいが、意味は変えない。

### 4-1. 宵待ちの村 → 幽霊船（弓師＋魔法使い）

**向かう理由**

- 弓師が霧の港の噂を持ち込む。「乗員のいない船が、毎晩同じ時刻に船鐘を鳴らしている」。
- 魔法使いは村で「消えたわけじゃない、残った」と知った。人だけがいなくなった場所を、もう一度、最初から自分の目で確かめたい。
- 依頼主はいない。

**出発**（既存の交代の4行に足す）

- 弓師「毎晩、同じ時刻に鳴るんです。乗っている人は、いないのに」
- 魔法使い「……確かめに行きます。今度は、最初から見ておきたいので」
- 剣士（酒場に残る）「見てから決めろ。……あの村で、そうしただろう」

### 4-2. 幽霊船

**船の存在理由**

- 既存: 船長は沈没船の"錨"を「早く帰れる近道」だと思って引き上げ、船ごと霧に縛られた。
- 追加（N-1）: **霧の中の船は、時計塔の鐘を頼りに港へ帰る。** その鐘が鳴らなくなったので、船は港を見失ったまま霧の港へ流れ着いた。

**流れ**（部屋・敵・ボスは既存。足すのは会話と手記の文面だけ）

| 場所 | 足すもの |
| --- | --- |
| 甲板 | 海を見る影の後に、弓師「……あの人、陸のほうを見ていました」 魔法使い「帰り道を探しているんでしょうか」 |
| 船長室 | 止まった船の時計（手記の文面、N-5）:「七時十三分」。弓師が噂の鐘と同じ時刻だと気づく |
| 晩餐の間（中間イベント） | 魔法使い「この船の人たちは、帰る場所があったんですね」 弓師「ええ。だから、降りられないんだと思います」 魔法使い「……あなたは?」 弓師「私は、どこにも。……だから、少しだけ羨ましい」 |
| 船倉の警告 | 魔法使い「分かっているつもりで、決めてしまったんですね。……少し、覚えがあります」 |
| ボス前 | 弓師「……鐘を待っている顔です」 |
| ボス（帰港を望む船長） | 第一章の台詞へ差し替え（性能は不変）。霧の中では鐘だけが帰り道だった／あの塔の鐘が七時十三分で黙った／近道を選ぶべきではなかった |
| 撃破後 | 既存の「港が……見える……」の前に、船長「……鐘を。あの塔の鐘を、鳴らしてくれ。まだ、霧の中に……」 |
| 酒場の痕跡 | 棚に船の小さな角灯（`scenarioClears('ghostship')` で判定。セーブ項目は増やさない） |

### 4-3. 幽霊船 → 時計塔（盗賊＋弓師）

三つの事実が重なって、塔へ向かう。

1. 船の時計も塔の鐘も、**七時十三分**で止まっている。
2. 船長が「あの塔の鐘を、鳴らしてくれ」と頼んだ。帰れない船は、この船だけではない。
3. 塔に入った管理人が、七日戻らない（既存）。

どこにも属さない弓師が、この頼みを引き受ける。理由は言わない。

酒場（既存の交代の4行に、弓師の一行を足す）:

- 主人「塔の鐘が、毎晩同じ時刻で止まるらしい」
- 弓師「止まっているのは、鐘だけじゃありません。船も、あの時刻で」
- 盗賊「止まってるなら、入るのは簡単だ。開いてる窓はどこにでもある」
- 弓師「……その言い方、あとで詳しく聞かせて」
- 盗賊「着いてからな」

### 4-4. 時計塔

**目的**: 鐘を正しい時刻に鳴らすこと。管理人の捜索は、その途中で起きる。

**塔の状態（既存）**: 七時十三分は、管理人の娘が家を出た時刻。塔はその時刻から先へ進まない。娘・管理人・時喰らいの関係は**断定しない**。

| 階 | 足すもの |
| --- | --- |
| 1F 玄関 | 盗賊「七日か。……待つ側にしちゃ、短いな」 |
| 2F 歯車の間（管理人の手帳） | 弓師「待っている人がいるんですね」 盗賊「……出ていった方は、戻りにくいもんだ」 |
| 3F 針の回廊（中間イベント。娘の書き置き） | 弓師「上の階へ向かう側に落ちていました」 盗賊「下りる気は、なかったんだな」 |
| 4F 鐘の広間（譜面） | 弓師「振り返らないで。……今だけは、私が後ろを見ています」 |
| 5F 前室 | 管理人の外套と懐中時計（手記の文面）。針は七時十三分。盗賊が懐へ入れる「……預かっとく。返すまでな」 |
| ボス前（時喰らい） | 既存の台詞の後に、盗賊「止めてりゃ、出ていかれずに済むってか。……そうはいかねえよ」 |
| 撃破 → 崩壊 | 歯車が一斉に回り出す。時が動き出し、塔が二人を拒む（説明しない）。「降りる階段は無い。……ならば、上だ」（既存） |

**盗賊の過去**（射出台の前。何を盗んだか、誰から盗んだかは**具体的には語らない**）

- 盗賊「……昔、出ていったことがある。持ってっちゃいけない物を持って」
- 弓師「戻らなかったんですか」
- 盗賊「戻れなかった、って言うと格好がつくな。……戻らなかった」
- 弓師「なら、今度は戻りましょう。跳んだ先から、ちゃんと」

### 4-5. 時計塔 → 道（CT-03）

**屋上から跳ぶ理由**

1. **下へは戻れない。** 塔が崩れ、螺旋階段が失われた（既存）。
2. **脱出口がある。** 屋上の射出台。銘板に二人分の名前があり、ひとつは彫りかけ（既存。由来は断定しない）。
3. **跳ぶ瞬間がある。**
   - 盗賊が抜け道を見つける。「出口は一つだ。……窓はどこにでもある、って言ったろ」
   - 弓師が「今」を読む。「鐘が鳴ります。……鳴ったら、跳びます」
   - 時が動き出した塔が、一か月ぶりに**正しい時刻の鐘**を鳴らす。その一打で跳ぶ。

**名も無い島（既存の着地）**

- 懐中時計は、盗賊が預かった管理人の時計（N-2）。止まっている。
- 遠い鐘が、もう一度正しく鳴る。
- **対岸の街道を、一人で歩いていく人影が見える（N-4）**。
  - 加入前のグラフィックで、遠景。影が本人よりわずかに遅れて動く。
  - 名前は出さない。話者名も付けない。
  - 弓師「……影が、少し遅れていました」。盗賊は答えない。

**酒場（翌朝）**

- 主人の道の導入（既存）に一行足す。「朝の鐘で目を覚ましたら、もういなかった」。
- 盗賊が懐中時計をカウンターに置く。「塔の管理人に、返しといてくれ」。盗った物ではなく、預かった物を返す。
- 主人「管理人は、朝になったら塔の下に座り込んでたそうだ。娘の名前を呼んでな」（**管理人は生還する**、N-3）。
