## 1. 守ること（不変）

- **主人公と支援の顔ぶれ、交代の時期、一本道、再訪なし**は Chapter 1 System Freeze のまま。
- **新しい敵・ボス・マップ・システムを作らない。** 道は新規敵なし・強敵なし・ボスなし。ボスの性能・フェーズも変えない。
- **怪異の正体を断定しない。「ずれ」の原因も、第一章では説明し切らない。**
- **台詞は短く、説明しない。** 行動から伝わる台詞を優先する（洋館・村の基準）。
  - ただし**情報まで曖昧にしない**（Human の依頼 2026-10-26、`DEC-010`）。各会話は「状況・原因・人物の意図・次の行動」のどれかを具体的に伝える。説明しないのは**怪異の正体**であって、村人がしたこと・主人公の目的・次に向かう場所ではない。宵待ちの村の台詞は `.ai/reports/CH1-DUSK-IMMERSION-analysis.md` §A で見直した
- **第一章の台詞は本編（`legacyGrowth()` が false）のときだけ出す。** テストモードは既定で本編と同じ第一章の台詞を出す（TEST-MODE-CURRENT-001）。テストモードの「旧成長システム」と将来の周回（Chapter 2 以降）では、既存の周回用の台詞をそのまま残す。
- 第一章では行けない場所（地下水路・神殿・温室）へ本筋を向けない。幽霊船の「瓶の手紙」（地下水路を指す）は既存のまま残す。

## 2. 第一章を通す糸 ―― 「ずれ」の連鎖

第一章の怪異は、どれも本来の時や形から**ずれて**いる。これは**台詞で説明しない**。並べて見せるだけで、プレイヤーが気づく。

| 段 | ずれ | 見せ方（既存） |
| --- | --- | --- |
| 森の洋館 | 影が人から離れ、遅れて追う | 館の主 Phase 3、本体の 0.42 秒後に影が追撃する |
| 宵待ちの村 | 記憶が遅れて繰り返される | 水門守の残響（1.6 秒遅れ）、村の残響 |
| 幽霊船 | 帰り道が、内側へずれる船 | 外へ向かう扉・梯子が船の奥へ繋がる。弓師の刻んだ矢印が別の部屋で奥を指す |
| 時計塔 | 時刻が七時十三分で止まる | 止刻の残響、七時十三分の繰り返し（娘が出ていく場面）、管理人が針を進める |
| 道 | 正体不明の人物の影が、本人よりわずかに遅れて動く | 橋に残る影、島から見える人影 |

**第一章の核心**

- 四人は怪異の正体を最後まで分からない。それでも「見る → 理解する → 位置を選ぶ → 時を合わせる → 崩す」ことはできた。
- 最後に出会うのは、同じ「ずれ」を持った人物。四人は正体を完全には理解できないまま、その人物と**一緒に歩くことを選ぶ**。

## 4. 各段の物語

### 4-1. 宵待ちの村 → 幽霊船（弓師＋魔法使い）

**向かう理由**

- 弓師が霧の港の噂を持ち込む。「沖の霧の中に、毎晩、灯が点る。乗っている人はいないのに」。
- 魔法使いは村で「消えたわけじゃない、残った」と知った。人だけがいなくなった場所を、もう一度、最初から自分の目で確かめたい。
- 依頼主はいない。

**帰還**（CH1-EXP X-5、DEC-006。村から戻った魔法使いのまま。交代の会話の前）

- 主人「戻ったか。湖の村は、どうだった。」
- 魔法使い「誰もいませんでした。……でも、消えたわけでは、ありませんでした。」

その後、弓師が歩み寄って交代の会話になり、会話の後で操作キャラクターが弓師に切り替わる。剣士は支援から外れ、酒場の卓のそばに残る。

**出発**（既存の交代の4行に足す）

- 弓師「沖の霧の中に、毎晩、灯が点るんです。乗っている人は、いないのに」
- 魔法使い「……確かめに行きます。今度は、最初から見ておきたいので」
- 剣士（酒場に残る）「見てから決めろ。……あの村で、そうしただろう」

### 4-2. 幽霊船 ―― 帰れない（GHOSTSHIP-REBUILD-002、DEC-017）

**船の正体**（台詞では全部言わない。皿・矢印・扉・点呼板・鎖の音で見せる）

- 船長は「全員で帰る」と誓い、錨の鎖を握り続けて船を霧に留めている。乗組員は二十人。陸を探しに小舟で出た五人が戻らないので、点呼の数はそろわない。灯は戻らない五人のために毎晩点される。
- 乗り込んだ弓師と魔法使いは、空いた席を埋める乗員として数えられる。船は二人を降ろさないため、外へ向かう道を船の奥へ繋ぎ直す。
- 船長が鎖を手放すと錨が海の底へ落ち、船はもう何も留めない。構造が戻り、閉じていた甲板への昇降口が開く。
- 錨の正体・出所、霧の原因は語らない（瓶の手紙は既存のまま）。

### 4-5. 時計塔 → 道（CT-03）

**屋上から跳ぶ理由**

1. **下へは戻れない。** 時間が動き出して塔が崩れ、下の階段がもう持たない（管理人の言葉。CLOCKTOWER-001）。
2. **脱出口がある。** 屋上の射出台。銘板に二人分の名前があり、ひとつは彫りかけ（既存。由来は断定しない）。
3. **跳ぶ瞬間がある。**
   - 盗賊が抜け道を見つける。「出口は一つだ。……窓はどこにでもある、って言ったろ」
   - 弓師が「今」を読む。「鐘が鳴ります。……鳴ったら、跳びます」
   - 時が動き出した塔で、管理人がひと月ぶりの**正しい時刻の鐘**を鳴らす（CLOCKTOWER-001）。その一打で跳ぶ。

**名も無い島（既存の着地）**

- 懐中時計は、盗賊が預かった管理人の時計（N-2）。止まっている。
- 遠い鐘が、もう一度正しく鳴る。
- **対岸の街道を、一人で歩いていく人影が見える（N-4）**。
  - 加入前のグラフィックで、遠景。影が本人よりわずかに遅れて動く。
  - 名前は出さない。話者名も付けない。
  - 弓師「……影が、少し遅れていました」。盗賊は答えない。

**酒場（翌朝）**
