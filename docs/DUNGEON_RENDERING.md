# Dungeon Rendering / Camera Rules（ダンジョン共通の描画・カメラ方針）

**確定**（GHOSTSHIP-REBUILD-004、2026-11-07 の Human の依頼文）。過去のシナリオと、今後作るすべてのダンジョンに適用する。

実装の状況は各節の「実装」に書く。**ここに書いた方針のうち、まだ入っていないシナリオは未対応として扱う**（完了扱いにしない）。

## 1. 三つの領域を区別する

| 領域 | 描き方 |
| --- | --- |
| 内部として存在する領域（床・壁・通路・地形がある所） | **正しく、途切れずに描く**。カメラや移動で消えたり現れたりしない。階層・部屋の切り替え後も同じ |
| 外側・存在しない領域（建物や船の外、部屋と部屋の間の何も無い所） | **黒くする、または描かない**。海・空・外の地形（草地）を屋内から見せない |
| 壁の向こう・未到達の部屋 | **先に見せない**。通路や開口の先は、近づいた時にその範囲だけ見えてよい |

- 黒い所を床や壁で一律に埋めて隠さない。欠けて見える所は、まず原因（配置データ・生成漏れ・影・カリング・下地の範囲）を調べる（§4）
- 外側を「黒く塗った板」で覆うより、**外側の物を描かない**（表示を切る）ことを優先する
- 視界を狭めすぎない。敵の攻撃予兆・重要な物は、必要な範囲で見えることを優先する

## 2. 現在いる空間を中心に描く

- いま居る部屋（空間）を描く。隣の部屋は、扉の無い開口・通路の先と、**開いている扉の先**を描く（距離は問わない）。閉じた扉・板で塞がった開口の先は描かない
- **一度開けた扉は開いたまま**（物語の場面・罠部屋の封鎖扉を除く）。開けた扉の先は、扉の両側から、離れても・部屋を移って戻っても見え続ける。扉の開放状態（扉の `opened`）と描画の範囲は分けて扱い、描画は「プレイヤーがどの部屋にいるか」だけで決める（カメラの位置では決めない）
- 屋外の舞台（村など）は屋外を常に描く。分けるのは建物の中身だけ
- 重要な物を見せる演出（§3）の間は、映す対象の部屋を描いてよい
- 表示の切り替えは見た目だけにする（当たり判定・敵の行動・イベントは変えない）

## 3. 重要な物は、見せてから話す

基本の順序:

1. 対象が画面に入る
2. 対象の特徴が分かる位置にカメラが来る
3. 認識できる短い間を置く
4. 必要なら会話を始める

- 会話が先に始まり、見せる前に説明してしまう順番にしない
- 見せる時間は短く（1〜2 秒）。演出が終わったら通常の追従へ滑らかに戻す
- 他のシナリオのカメラ設定をそのまま写さない。マップの形に合わせて作る

| 森の洋館 | **対応**（CAMERA-001）: 共通の `sceneCamShot`（13）と、出来事の `show` オプション（02 `registerProximityEvent`）。食堂の卓・厨房の竈・塞がれた扉・作業室の鍛冶屋・瓦礫の山・異常空間の玄関ホールを見せてから一文・会話 |
| 宵待ちの村 | **対応**（CAMERA-001）: 記憶の場面（魚屋の帳場・住宅の食卓・船小屋の水際・商店街の屋台）・水門・水門守の到来・ボスの手前で、対象を見せてから台詞。入口の場面は既存の振り向き（`cutsceneTurnTo`）のまま |
| 時計塔 | **対応**（CLOCKTOWER-002）: 長針・歯車の輪・鐘楼を映してから一文。入口の時が止まる場面は縦穴を見上げて目的地（大時計の裏）を見せる（共通のカメラに `look` を足した）。灯りの記憶・七時十三分の繰り返し・盗賊の閃き・橋が架かった後・輪が回った後・初めての鐘は映してから話す。床の高さ（`y`）をカメラに渡す |

共通のカメラ（`sceneCamShot`）は向き（camYaw）を変えない。床の高さ `y`（既定 0）を受け取る（CLOCKTOWER-001）。見せたい物の少し上・今のカメラの側から見て、終わると元の追従へ戻る。**自動カメラを OFF にしている人には使わない**（進行に要らない自動の演出なので。出来事はすぐ起きる）。ボスの寄り・ボス戦の追尾の間は割り込まない。幽霊船の `gsCamShot` は自動カメラ OFF でも動く（既存。今回は変えていない）。

## 4. 描画品質の確認項目（欠落を作らない）

新しいダンジョン・間取りの変更では、次を確かめる。

- **部屋の表と、外殻・下地・外周の飾りの範囲が一致しているか**。部屋を足したら、外殻（外壁・屋根）・暗い下地・外周の木立・飾りの除外範囲も同じ範囲へ広げる
- **外壁や高い物が、屋内の床へ太陽の影を落としていないか**。外から見せるための外殻は影を落とさない（屋内の床の端が「描けていない」黒に見える）
- **下地（暗い床）の縁から、外の地形が見えないか**。カメラの見える範囲は下地の余白より広い。離れ島の区画では外の地形そのものを描かない
- 部屋と通路の境で床が途切れていないか。カメラを回しても、移動しても、床と壁が消えないか
- 上からの全体写真（正射影・霧なし）で、内部の欠落と外側の見え方を確かめる

### 4-1. 見つかった不具合と原因（森の洋館、GHOSTSHIP-REBUILD-004）

| 症状 | 原因 | 修正 |
| --- | --- | --- |
| 厨房の中に外壁が立ち、木が生え、外の草地が見える | 厨房（x 17〜30）を足した時、外殻（x 21 まで）・下地（x 22 まで）・東の木立（x 25 / 28）を広げていなかった（配置データの不整合） | 外殻 x 31・下地 x 32・木立 x 35 / 38、飾りの除外範囲 x 40 |
| 大広間・厨房の床の端が真っ黒 | 高さ 7 の外殻が太陽の影を屋内の床へ約 5 落としていた | 外殻は影を落とさない |
| 二階・一階奥・地下・異常空間で、床の外に草地が見える | 離れ島の下地の余白（約 2）より、カメラの見える範囲が広い | 離れ島の中では森を描かない |

原因はどれも洋館の配置データ・洋館の作り（森の上の離れ島）にあり、共通の描画処理（`buildWorld` / 静的バッチ / カメラ）には無かった。他のシナリオは同じ作りではないので一括の変更はしていない。
