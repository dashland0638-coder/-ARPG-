# Characters

職業体系、キャラクター性、役割。戦闘の挙動そのものは [COMBAT.md](./COMBAT.md) を参照。

## Class System

**確定** — 基本職4種と、それぞれに対応する上位職4種。

| 基本職 | 上位職 | 実装キー（基本職 / 上位職） |
| --- | --- | --- |
| 剣士 | 戦騎士 | `warrior` / `battleKnight` |
| 盗賊 | バーサーカー | `rogue` / `berserker` |
| 魔法使い | 魔導士 | `mage` / `archmage` |
| 弓師 | 鷹の目 | `archer` / `hawkEye` |

**実装事実** — 上位職は別キャラクターではなく **上乗せフラグ** で表現する。
`state.classDef.key`（基本職キー）は変えず、`state.job` に上位職キーを立てる。
影響範囲は「見た目」「ステータス」「表示名」に限定され、
`WEAPON_TYPES` / `STANCE` / `CLIPS` / `BOSS_ABILITIES` など基礎職キーに
紐づく既存システムには触れない（`src/legacy/parts/01-character-creation.js`）。
転身条件はレベル50到達（`unlockLv:50`）。

## 剣士 / 戦騎士

- **戦闘役割**: 前衛。高いHPと広い攻撃範囲。横薙ぎで複数の敵を巻き込む（`cleave:true`）
- **見るもの**: 剣士＝距離 / 戦騎士＝身体
- **操作感**: **実装事実** — 攻撃間隔 0.52秒、近接射程 3.6、体幹倍率 1.3、
  コンボ3段。回避は大きく丸まる正統派ロール
- **武器**: 大剣（戦騎士は長剣）
- **キャラクター性**: Chapter 1 の主人公。**確定** — 名前を持たず、表示名は「剣士」
- **既定仕様**: 戦騎士は「守るための剣」。重装を纏う（`statBonus:{vit:10, str:6}`）
- **未確定**: 剣士個人の来歴（実装・既存ドキュメントに記述なし）

## 盗賊 / バーサーカー

- **戦闘役割**: 俊敏な近接。急所を突く。攻撃速度に優れ範囲は狭い
- **見るもの**: 盗賊＝隙間 / バーサーカー＝次の位置
- **操作感**: **実装事実** — 攻撃間隔 0.38秒、近接射程 2.8、体幹倍率 0.7、
  コンボ4段。刀装備時は1段目が確定クリティカル。回避は低く速いタンブル
- **武器**: 両手短剣（双剣）／バーサーカーは両手斧
- **キャラクター性**: **確定** — 本物の盗賊ではない。友人の宝を盗んだ過去があり、
  それを後悔している
- **既定仕様**: バーサーカーは盗賊の身軽さを残した狂戦士。防具を減らす
  （`statBonus:{str:10, agi:6}`、純粋な攻撃特化）
- **未確定**: 上記の過去をどのシナリオ・会話で描くか

## 魔法使い / 魔導士

- **戦闘役割**: 遠距離。魔力を纏い敵を撃つ
- **見るもの**: 魔法使い＝戦場 / 魔導士＝戦場の変化
- **操作感**: **実装事実** — 攻撃間隔 0.6秒、`range:'ranged'`、コンボ2段。
  回避はロールではなく短い明滅（脚をほとんど動かさない）
- **武器**: 杖（alt: 魔法の剣）。**仕様上の正式な武器名は未確定**
- **キャラクター性**: **確定** — 「分かっているつもりだった人」。怪異について知識がある
- **重要な固定仕様**: 属性システムを導入しない（[COMBAT.md](./COMBAT.md) の Mage 参照）
- **既定仕様**: 魔導士は「人間から魔法そのものへ近づいていく術者」
- **未確定**: 上記の性格づけを反映した台詞・イベント

## 弓師 / 鷹の目

- **戦闘役割**: 遠距離。高い機動性
- **見るもの**: 弓師＝現在 / 鷹の目＝未来（予兆を読んで未来の位置を狙う）
- **操作感**: **実装事実** — `range:'ranged'`、コンボ4段、近接距離ではダメージ -35%。
  回避は横っ跳び。鷹の目は突進・跳躍など「読める行動」をした敵に対してのみ
  狙い筋が補正される（限定ターンアシスト）
- **武器**: 小弓（鷹の目は大弓／alt: ボウガン）
- **キャラクター性**: **確定** — 「どこにも属さなかった人」
- **既定仕様**: 鷹の目は「見ることを極限まで研ぎ澄ました狩人」。傍らに鷹を伴う
- **未確定**: 所属を持たない経緯

## 5人目のキャラクター（影の旅人）

- **確定**
  - 人間なのか怪異なのか曖昧な存在
  - Chapter 1 では最初の酒場NPCとして登場する
  - 特殊な役割を持つ
  - ボスから特殊能力を取得する仕組みに関係するのは、このキャラクターだけ
- **実装事実**
  - 名称は「影の旅人」。酒場の北の壁際、専用の小卓に一人で座っている
  - 初対面の会話では酒場の案内（店主・鍛冶士／仮設の作業台）をするだけで、
    プレイヤーが「案内役」と誤解する下地を作る意図で書かれている
  - 黒ずくめの装いと、足元にまとわりつく紫がかった「影だまり」で
    「本人とは少し違う意思を持つ影」を視覚的にほのめかす
  - 進行フラグは `state.shadowGuideMet` / `state.shadowGuideTalks`（セーブ対象）
  - 戦闘には一切関わらない。専用クラス／戦闘キットは未実装のため
    `CHAPTER_CAST` の第五章は `classKey:null`（プレイ不可）
  - ボス能力（`BOSS_ABILITIES`）は現状すべてのキャラクターが獲得する
    （→ docs/README.md D-05）
- **未確定**
  - プレイアブル化の正式条件（実装コメントの「名もなき街道クリア後」は
    他に定義が無く、仕様として確定していない）
  - 専用クラス・武器・戦闘スタイル

## Character Creation

**確定（実装反映済み）** — プレイヤーによるキャラメイクは廃止。
章ごとに主人公の職業・性別・性格が固定される（`CHAPTER_CAST`）。
名前入力欄は無く、表示名はクラス名そのものを使う（例: 「剣士:「……」」）。

ステータス配分（ダイス由来の `allocPoints` など）はキャラメイクの名残ではなく、
レベルアップ時の恒久ステータス振り分けとして鑑定所で今も使われている。
