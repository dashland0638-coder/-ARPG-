# Characters

職業体系、キャラクター性、役割。戦闘の挙動そのものは [COMBAT.md](./COMBAT.md) を参照。

## Class System

**確定** — 基本職4種と、それぞれに対応する上位職4種。

| 基本職 | 上位職 | 実装キー（基本職 / 上位職） |
| --- | --- | --- |
| 剣士 | 戦騎士 | `warrior` / `battleKnight` |
| 盗賊 | バーサーカー | `rogue` / `berserker` |
| 魔法使い | 魔導士 | `mage` / `archmage` |
| 弓師 | 鷹の目 | `archer` / `hawkEye` |

**実装事実** — 上位職は別キャラクターではなく **上乗せフラグ** で表現する。
`state.classDef.key`（基本職キー）は変えず、`state.job` に上位職キーを立てる。
影響範囲は「見た目」「ステータス」「表示名」に限定され、
`WEAPON_TYPES` / `STANCE` / `CLIPS` / `BOSS_ABILITIES` など基礎職キーに
紐づく既存システムには触れない（`src/legacy/parts/01-character-creation.js`）。
転身条件はレベル50到達（`unlockLv:50`）。

## 剣士 / 戦騎士

- **戦闘役割**: 前衛。高いHPと広い攻撃範囲。横薙ぎで複数の敵を巻き込む（`cleave:true`）
- **見るもの**: 剣士＝距離 / 戦騎士＝身体
- **操作感**: **実装事実** — 攻撃間隔 0.52秒、近接射程 3.6、体幹倍率 1.3、
  コンボ3段。回避は大きく丸まる正統派ロール
- **武器**: 大剣（戦騎士は長剣）
- **キャラクター性**: Chapter 1 の主人公。**確定** — 名前を持たず、表示名は「剣士」
- **既定仕様**: 戦騎士は「守るための剣」。重装を纏う（`statBonus:{vit:10, str:6}`）
- **未確定**: 剣士個人の来歴（実装・既存ドキュメントに記述なし）

## 盗賊 / バーサーカー

- **戦闘役割**: 俊敏な近接。急所を突く。攻撃速度に優れ範囲は狭い
- **見るもの**: 盗賊＝隙間 / バーサーカー＝次の位置
- **操作感**: **実装事実** — 攻撃間隔 0.38秒、近接射程 2.8、体幹倍率 0.7、
  コンボ4段。刀装備時は1段目が確定クリティカル。回避は低く速いタンブル
- **武器**: 両手短剣（双剣）／バーサーカーは両手斧
- **キャラクター性**: **確定** — 本物の盗賊ではない。友人の宝を盗んだ過去があり、
  それを後悔している
- **既定仕様**: バーサーカーは盗賊の身軽さを残した狂戦士。防具を減らす
  （`statBonus:{str:10, agi:6}`、純粋な攻撃特化）
- **未確定**: 上記の過去をどのシナリオ・会話で描くか

## 魔法使い / 魔導士

- **戦闘役割**: 遠距離。魔力を纏い敵を撃つ
- **見るもの**: 魔法使い＝戦場 / 魔導士＝戦場の変化
- **操作感**: **実装事実** — 攻撃間隔 0.6秒、`range:'ranged'`、コンボ2段。
  回避はロールではなく短い明滅（脚をほとんど動かさない）
- **武器**: 杖（alt: 魔法の剣）。**仕様上の正式な武器名は未確定**
- **キャラクター性**: **確定** — 「分かっているつもりだった人」。怪異について知識がある
- **重要な固定仕様**: 属性システムを導入しない（[COMBAT.md](./COMBAT.md) の Mage 参照）
- **既定仕様**: 魔導士は「人間から魔法そのものへ近づいていく術者」
- **未確定**: 上記の性格づけを反映した台詞・イベント

## 弓師 / 鷹の目

- **戦闘役割**: 遠距離。高い機動性
- **見るもの**: 弓師＝現在 / 鷹の目＝未来（予兆を読んで未来の位置を狙う）
- **操作感**: **実装事実** — `range:'ranged'`、コンボ4段、近接距離ではダメージ -35%。
  回避は横っ跳び。鷹の目は突進・跳躍など「読める行動」をした敵に対してのみ
  狙い筋が補正される（限定ターンアシスト）
- **武器**: 小弓（鷹の目は大弓／alt: ボウガン）
- **キャラクター性**: **確定** — 「どこにも属さなかった人」
- **既定仕様**: 鷹の目は「見ることを極限まで研ぎ澄ました狩人」。傍らに鷹を伴う
- **未確定**: 所属を持たない経緯

## 5人目のキャラクター（影の旅人）

- **確定**
  - 人間なのか怪異なのか曖昧な存在
  - Chapter 1 では最初の酒場NPCとして登場する
  - 特殊な役割を持つ
  - ボスから特殊能力を取得する仕組みに関係するのは、このキャラクターだけ
- **実装事実**
  - 名称は「影の旅人」。**この名前は加入後の呼び名**で、道での正式加入（主人公の交代）の
    瞬間に初めて表示される（DEC-004 N-4、docs/CHAPTER1_STORY.md §3）。加入前（酒場の隅・
    島から見える人影・道の遅れる影・山道の野営地での出会い）は正体不明の人物として扱い、会話の話者名は
    「？？？」。テストモードの酒場の隅の会話だけは従来の「影の旅人」表示のまま
  - **加入前**: 酒場の北の壁際、専用の小卓に一人で座っている（時計塔をクリアすると席を立ち、
    道 — その先へ の山道の野営地で出会う）
  - 初対面の会話では酒場の案内（店主・鍛冶士。本編の加入前は店主だけ ―― 作業台が無いので指す行を出さない、PROGRESSION-004）をするだけで、
    プレイヤーが「案内役」と誤解する下地を作る意図で書かれている
  - 加入前の姿は黒ずくめの装いと、足元にまとわりつく紫がかった「影だまり」で
    「本人とは少し違う意思を持つ影」を視覚的にほのめかす（`buildRoadTravelerFigure`。
    動くときは影だまりが本人より少し遅れてついていく、CR-02）
  - 進行フラグは `state.shadowGuideMet` / `state.shadowGuideTalks`（セーブ対象）
  - 加入前は戦闘に関わらない
  - **加入後**（WORK 11、CR-02、R3-7 / DEC-032）: 道（Chapter 1 の⑤、道 — その先へ）の山道の野営地で出会い、その一幕の中で
    主人公になる（`CHAPTER_CAST[5]`: `classKey:'wanderer'`、支援は盗賊）。職業ではない。
    `CLASSES.wanderer.kit = 'warrior'` は装備・配色・必殺技ゲージ・セーブの鍵として残し、
    戦い方は自前（WANDERER-RENEWAL-001、`.ai/decisions/AGENT-DECISIONS.md` AD-005。下の「戦い方」）
  - 加入の条件は「時計塔をクリアし、道の山道の出会いの一幕を終える」こと
    （`core/chapter1-progress.js` の `MET_INSIDE`。新しいセーブ項目は無い）
  - ボス能力（`BOSS_ABILITIES`）は、Chapter 1 の本編ではどのキャラクターにも効かない。
    テストモードと Chapter 2 以降では現状すべてのキャラクターが獲得する（→ docs/README.md D-05）
- **戦い方**（実装事実。WANDERER-RENEWAL-001 / 002、Human の最終キャラクター設計書 = `.ai/decisions/DEC-034-wanderer-shadow-hands.md`。
  数値・形・時刻は `src/core/wanderer-style.js`、差し込みは `src/legacy/parts/17-wanderer-style.js`）
  - コンセプト「半拍遅れて歩く、静かな旅人」: 武器を一切持たない。本人が手を振る・払う・広げる・握る・
    差し出すと、少し遅れて地面から巨大な**影の手**が現れて敵を襲う。本人は静か、影は獰猛
  - 影の手: 人間の手を巨大化した形（手のひら・4 本の指・大きく外へ開く親指）。指は長く、指先だけ鋭く
    尖る。関節は少し不自然に折れる。手首は地面の影（黒紫の円・紫の縁）と一体。内部は黒に近い紫の不透明、
    輪郭だけ影の紫 #8A5AD6 に光る（指先は太く明るい輪郭）。床の下から立ち上がり、沈んで消える。
    大きさ（手首から先）は主人公（身長 2.54）に対し、通常 約 1.4 倍・強い一撃（握砕・影残し）約 2 倍・
    必殺技 約 2.2 倍 × 5 本（`WANDERER_HAND_SCALE`。手は敵の足元・攻撃範囲の上に出し、短時間で沈める）
  - 間合い 3.2・扇 半角 60°・攻撃間隔 0.44・体幹 0.9（剣士と盗賊の間の「中間の間合い」）
  - 通常攻撃 3 段（判定は影の手が当たる瞬間 = 入力の 0.14〜0.18 秒後）:
    ① 影の突き上げ（扇の中の一番近い敵の足元から突き上げる。手のまわり半径 1.5）
    ② 影の薙ぎ払い（横向きの手が前方の扇を薙ぐ）
    ③ 影の握砕（敵の足元に開いた手 → 当たる（半径 1.6）→ 入力の 0.45 秒後に指を閉じて握り潰す = 影の追撃、0.6 倍）
  - 影の追撃（0.45 秒。加入前の影と同じ遅れ。理由は語らない）: 3 段目の握砕・Skill 1・Skill 2。
    影の手の側から当たるので、正面に盾を持つ守護型の正面耐性を抜けられる
  - Skill 1「影残し」（第一章の固定 Skill 1）: 前へ手を振って 2.8 m 退く。元の位置から巨大な影の手が現れ、
    0.45 秒後に周りを一回り薙ぐ（半径 2.4、0.8 倍）
  - Skill 2「影渡り」（道のエリア 4 で閃く。クールダウン 9 秒）: 影の手が地面を這って前へ 6.5 m（壁の手前で
    止まる。這う途中で線上の敵に当たる）、先端で向きを変え、0.45 秒後にこちらへ薙ぎ戻す（1.5 倍、挟み撃ち）
  - 必殺技「影送り」: 数値・判定は既存のまま（半径 4.2・3.2 倍）。範囲のまわりから 5 本の巨大な影の手が
    立ち上がり、中心へ一斉に倒れ込む。本人は低く沈んでから両腕を大きく広げる
  - 回避: 横へ滑るように（丸まらない）。元の位置に小さな影の手が一瞬。回避攻撃・切り上げは見た目に影の手
  - 本人のモーション: 構えは腕を下ろした静かな立ち姿。攻撃は身体全体の大振り（突き上げ = 右手を下から
    前上へ振り上げて体を反らす / 薙ぎ払い = 腰と上体を回して右腕を大きく横へ / 握砕 = 両腕を大きく広げ、
    前傾しながら右手を握り込む）。斬撃の弧・刃の軌跡は出さない
  - 加入後の足元の影: 本人より 0.45 秒遅れてついてくる。待機で少し揺れ、走ると移動の向きへ少し伸びる。
    外套の後ろ裾・マフラーの端は体の動きより遅れて揺れる
  - 勝利・戦闘終了の専用の動きは無い（全キャラクター共通の仕組みが無いため。構えを解いて静かな立ち姿へ戻り、
    足元の影が遅れて追いつく）
  - 被弾・ダウン・ジャンプ・歩き/走りは全キャラクター共通の仕組み（回避・滞空・低HP の係数だけ影の旅人の行を持つ）
- **未確定**
  - 正体（人間か怪異か）。第一章では明かさない（CHAPTER1_STORY.md）

- **頭身の定義と計測**（CHARACTER-VIS-002 T-1、DEC-036。キャラクター間で同じ基準を使う）:
  頭身 = 体の高さ ÷ 頭の高さ。体の高さ（`stature`）は足の裏から頭頂までで、被り物・髪の盛り上がり・
  武器を含まない（`hipY + height + headGap + headR`）。頭の高さは `headR × 2`。全高は 剣士 2.54 /
  魔法使い・弓師 2.40 / 盗賊 2.42（上位職は基礎職と同じ）。4.75 頭身は全高を変えず、頭を大きくした分を
  脚 6 割・胴 4 割で短くした（肩幅・手足の太さは変えない）。デバッグの Motion Preview の `HEADS` 行で確認できる
- **頭の形**（4基礎職・上位4職）: 頭の下半分を丸くした断面（`HEAD_SECTION_RATIOS_SOFT`。顎・顎線を広げ、
  頬から上は従来と同じ）。首の上端は顎の下へ少し埋め、頭との境目が見えないようにしている。
  影の旅人は従来の頭の形・首のまま
- **目**: 全員共通。白目・黒目・ハイライトの3層（`eyeSizeMul` 0.72、左右の間隔 0.095、
  黒目の基準半径 0.046、白目の縦横比 1.28。眉・口は無い）。目の大きさは頭の大きさに比例する（`headR` 基準）。
  4基礎職・上位4職は目の外周の点の数を増やして角を目立たなくしている（白目 14・瞳 12・ハイライト 8。
  影の旅人は 8 / 6 / 4）
- **肌色**: 剣士 0xffe6d2 / 魔法使い 0xffeee5 / 盗賊 0xffe7d4 / 弓師 0xe8bd98
