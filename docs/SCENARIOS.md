## Chapter 1 Structure

**確定**

Chapter 1 は開始時から自由な3人パーティではない。

```
開始時                    剣士のみプレイ可能
  ↓
剣士シナリオ終了後        次のプレイアブルキャラクターが酒場に登場
                          以前のプレイアブルキャラクターはサポートAIになる
```

キャラクター切り替えはメニューからの自由選択ではなく、
**酒場やイベントを通して自然に行う**。

**実装事実**（WORK 10 / WORK 11）— 交代は実装済み。誰が主人公で誰が支援かは、
セーブ済みの `scenarioClears` から毎回導く（`core/chapter1-progress.js`、新しいセーブ項目は無い）。
交代が起きるのは「酒場に戻ったとき」と「道の出会いの一幕」だけ。

## Chapter 1-①: 囚われの洋館

**確定**（詳細は `MANSION_SCENARIO.md` が一次資料）

初回プレイの体験を最優先した一本道シナリオ。分岐・周回変異は
「初回導線から外す」だけで、仕組み自体は他ダンジョンのために温存する。

体験の骨格:

```
酒場 → 森の入口 → 古い森道 → 最初の異常 → 戦闘① → 森の奥 → 前庭 → 正面玄関 →
玄関ホール → 食堂 → 一階廊下 → 大広間【戦闘②】 → 大階段 → 二階廊下 → 書斎 →
作業室【鍛冶屋と出会う】 → 使用人通路【瓦礫 / Skill 2 を閃く】 →
使用人区画【戦闘③】 → 地下入口【扉を境に分離】 →
異常空間【鍵束の番人】 → 地下室 → 地下奥【戦闘④】 → 主の間【ボス】 →
怪異が弱まる → 館の構造が正常化 → 玄関ホールで鍛冶屋と再会 → 二人で脱出 →
酒場へ帰還 → 鍛冶屋が加入
```

- 演出の優先順位: ①ビジュアル ②SE ③移動と探索 ④短い会話 ⑤手記
- 手記は「読まなくても本筋が分かる」補助に留める（**実装事実**: 5点。来客名簿・献立・手紙・使用人の書き置き・異常空間の記帳簿。`MANSION_SCENARIO.md` 冒頭の「3点」は後から足した2点を数えていない古い記述。CM-05 で訂正予定）
- 怪異の正体はどこでも断定しない（館の主自身も分かっていない）
- 敵構成: 通常敵3種（使用人／侍女／猟犬）、強モブ（鍵束の番人）、
  中ボス（黒衣の執事）、ボス（館の主。3フェーズ＋影分離）
- ダンジョン中盤の瓦礫の通路で、主人公が Skill 2「崩し斬り」を閃く

## Tavern

**確定** — 酒場はシナリオ進行に伴って人や施設が増える。
序盤のシナリオをクリアすると、救出した人物などが酒場へ加わる。
酒場は単なるメニュー画面ではなく、キャラクター加入や物語進行を表現する場所として扱う。

**実装事実**

| フラグ | 酒場に増えるもの |
| --- | --- |
| （なし） | **何も無い**（本編。剣士だけの序盤は鍛冶士も鍛冶設備も酒場に無く、鑑定所には入れない。Human Decision 2026-10-04、PROGRESSION-004）。テストモードだけ仮設の作業台＋道具4本＋木箱 |
| `smithJoined` | 鍛冶士本人＋金床＋火の入った炉＋炉明かり |
| `smithToolsRecovered` | 道具箱2つ＋立てかけた鋼材4本＋作業台＋工具 |

工具と鋼は「施設が解放された」のではなく、**あの晩に担いで帰った物がそこに置いてある**
ように見せる。洋館で見たのと同じ木箱を酒場の一角にそのまま並べている。

常駐NPC: 酒場の主人（依頼・出撃）、隅の小卓の人物（加入前の影の旅人。話者名は「？？？」。時計塔クリアで席を立つ）、
鍛冶士（洋館クリア後）。道を終えると、剣士・魔法使い・弓師が隅の卓のまわりに立つ。

## Companion / Guest

**確定** — 前章の主人公がサポートAIとして同行する。

**実装事実**

- 同行AI（`companion`）の基盤は存在し、敵の選択・追従・攻撃を行う
- サポートAIは非敵対の強モブ／ガーディアンに不用意に絡まない
  （`core/enemy-aggro.js`）
- 鍛冶屋の同行は戦闘参加ではなく探索・ギミック役（瓦礫の撤去など）
- 段に連動した支援の切り替えは実装済み（WORK 10 / WORK 11。`CHAPTER_CAST` の `guestClassKey`）
