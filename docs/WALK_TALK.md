# 歩きながらの掛け合い（共通機能の方針）

Status: 方針（DEC-029）。最初の実装は道（新）の宿場（ROAD-VISUAL-003 R3-1、PR #134）。
**この文書は方針だけを決める。今の実装は変えず、他のシナリオへ一度に広げない**（広げる時は、そのシナリオの Task で一つずつ）。

## 1. 何か
探索の途中、仲間が短く言葉を交わす。会話の窓を開かず、画面の下に一行ずつ流して消す。
物語の大事な会話ではなく、歩いている場所の空気を伝えるためのもの。

## 2. 守ること
| # | 方針 |
| --- | --- |
| W-1 | 移動・タッチ・カメラを止めない。表示はタッチを受けない（`pointer-events:none`） |
| W-2 | 戦闘の緊張が高い間・会話の窓・演出（カットシーン）・一時停止の間は、止めて隠す。終わったら続きから |
| W-3 | 同じ話題は、その出撃で 1 回だけ（繰り返さない） |
| W-4 | 出す条件（場所・時機）と台詞は、シナリオごとのデータに書く。表示と流し方は共通 |
| W-5 | 表示の位置・大きさ・一行を出す時間は、全シナリオで同じ |
| W-6 | iPhone の横向き（844 × 390）で読める。HUD・操作ボタン・スティックと重ならない |
| W-7 | 物語の大事な会話（本編の会話・調べ物の後の会話・怪異の会話・加入など）は、今までどおり専用の会話の窓で出す。掛け合いに置き換えない |
| W-8 | 一話題 2〜3 行。一行は短く（名前を含めて全角 20 字前後）。正体・由来・伏線の答えに触れない |

## 3. 分け方（共通にする所 / シナリオが持つ所）
| 部分 | 中身 | 今の場所（R3-1） | 共通にする時 |
| --- | --- | --- | --- |
| 流し方（状態） | 話題の列・一行の時間（2.8 秒）・行の間（0.35 秒）・1 回だけ・止めている間は進めない | `src/core/road-banter.js`（state・THREE に依存しない） | そのまま使える。名前の `road` を外すのは、二つ目のシナリオで使う時 |
| 止める条件 | 会話の窓・演出・一時停止・戦闘の緊張（`combatIntensity >= 0.35`） | `14-dungeon-road2.js` `road2UpdateBanter` | 共通の関数一つにまとめる（シナリオは足さない） |
| 表示 | 下中央の帯（`#hud-zone-bc`）の一番下、カメラ回転のボタンの上。半透明の暗い帯・14px・最大幅 min(46vw, 420px) | `14-dungeon-road2.js` `road2BanterElement`（id `road2-banter`） | 共通の表示一つにする（id はシナリオの名前を持たない） |
| 出す条件と台詞 | 話題の ID・場所の帯・台詞・出す条件（本編だけ、など） | `14-dungeon-road2.js` `ROAD2_BANTER`、帯は `registerProximityEvent` | シナリオのデータのまま（共通の帯の仕組み `registerProximityEvent` を使う） |

## 4. 広げる時の手順（一度にしない）
1. 二つ目のシナリオで掛け合いを使う Task の中で、表示と止める条件を共通の場所へ移す（道（新）の見た目・試験はそのまま通す）
2. そのシナリオの台詞と帯をデータで足す
3. 試験: 一話題が流れて消える・同じ話題は 1 回・止める条件で隠れる・HUD と重ならない（`tests/road2-inn.spec.js` の掛け合いの試験と同じ確かめ方）
