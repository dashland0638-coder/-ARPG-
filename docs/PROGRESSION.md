# Progression

成長、装備、スキル取得、クリア後要素。

## Chapter 1 Policy

**確定** — Chapter 1 では成長システムを簡略化する。

- レベル上げを主要な成長要素にしない
- スフィア盤（奥義の環）は Chapter 1 では使用しない
- パッシブ大量取得システムは Chapter 1 では使用しない
- クラフトは Chapter 1 では使用しない

Chapter 1 で中心に据えるもの:

- 装備
- スキル
- キャラクター固有能力

> **実装との差異あり** — 奥義の環は現在ロックされておらず、レベルアップごとに
> 1点振れる状態で常時開放されている（docs/README.md の D-02）。
> 勝手に実装を変更しないこと。

## Post-Clear

**確定** — メインシナリオクリア後に次を解放する。

- スフィア盤
- 育成施設
- エンドダンジョン

クリア後は自由にキャラクターを選択してダンジョンへ挑戦できる。

**未確定** — 「育成施設」「エンドダンジョン」の具体的な中身、解放の正確な条件、
キャラクター自由選択のUI。実装・既存ドキュメントのいずれにも定義が無い。

## Repeat Runs（周回）

**確定** — 深層ダンジョンでは周回要素を持たせる。

- 難易度上昇
- マップ変異
- マップ追加
- 強モブ出現

**実装事実**

- シナリオごとに ★（`scenarioStars`）が積み上がり、上限は `MAX_STARS = 8`
- 初回クリアは時間制限なし。2周目（★2）以降に制限時間が付く。
  ★1つごとに8%短縮し、基準タイムの60%を下限とする
  （`SCENARIO_TIME_LIMIT_BASE` / `core/scenario-timer.js`）
- マップ追加の例（森の洋館）: ★3で保管庫の奥の隠し部屋、★4で主の間の先の屋根裏
- マップ変異（`routeMutationActive`）の仕組みは残っているが、
  森の洋館では `ROUTE_MUTATABLE_NODES.mansion` を空にして休止している
  （初回体験を一本道にするため。他ダンジョン向けに仕組み自体は温存）
- 強モブ（Super Armor / Guardian を持つ敵）の基盤は `core/enemy-tier.js` /
  `core/enemy-profiles.js` にあり、洋館では「鍵束の番人」が該当する

## Level / Stats

**実装事実**（Chapter 1 の簡略化方針とは別に、現状こうなっている）

- レベルとXPが存在し、シナリオには推奨レベル（`levelRange`）と
  突入に必要な `minLevel` がある
- レベルアップで振り分けポイントが増え、鑑定所で6ステータス
  （vit / str / mag / mnd / agi / foc）へ恒久配分する
- 上位職への転身はレベル50到達で解禁（`unlockLv:50`）。
  転身はステータス加算（`statBonus`）と常時倍率（`JOB_PASSIVE`）を持つ

**決定（WORK 12.1）** — Chapter 1 の本編にはレベルが無い。

- 経験値・レベルアップ・レベル表示・推奨レベルでの出撃制限・レベルによる
  攻撃Tier・レベル50転身・レベルアップの振り分け・パッシブ（能力の強化）・
  奥義の環（スフィア盤）・武具強化・ランダム装備ドロップは、本編では動かない
- ステータスは「クラスの基礎値＋装備」だけ。成長は主人公の交代と Skill 2 の閃きで表す
- 仕組みそのものは Chapter 2 の基盤として残してあり、テストモード（開発用）だけで動く
- 判定は `core/chapter1-rules.js` の `legacyGrowthEnabled()` 一か所
- 武器はクラスの武器種だけ装備できる（剣士=大剣 / 盗賊=双剣 / 魔法使い=杖 / 弓師=小弓）

## Equipment

**実装事実**

- 装備はドロップ（`rollEquipment`）から出る。武器には `weaponType` が刻まれ、
  装備した瞬間にモーション・数値が切り替わる。外すと native 武器種へ戻る
- 鍛冶士の鑑定所で鑑定・強化・アビリティのランク上げを行う
- 鑑定所はダンジョン中のチェックポイント（洋館の大広間）からも開ける
- 購入・ランク上げは「スキルの組み替え」ではないため、
  戦闘中のロードアウト制限（[COMBAT.md](./COMBAT.md)）の対象外

## Boss Abilities

**確定** — ボスから特殊能力を取得する仕組みは、5人目のキャラクターだけが関係する
（[CHARACTERS.md](./CHARACTERS.md)）。

**実装事実** — 現行の `BOSS_ABILITIES` はボス撃破で誰でも獲得する常時パッシブ。

| ボス | 能力 | 効果 |
| --- | --- | --- |
| 館の主 | 離れゆく影 | 回避の無敵時間 +20% |
| 幽霊船長 | 船長の海図 | ゴールド獲得量 +15% |
| 水路の亀 | 甲羅の加護 | 被ダメージ -8% |
| 神殿の守護者 | 守護神像の重心 | 体幹削り +12% |
| 時計塔の番人 | 時喰らいの均衡 | 必殺ゲージ獲得量 +15% |
| 温室の母樹 | 母樹の芯 | 最大HP +6% |

→ 差異は docs/README.md の D-05。

## Retreat / Defeat

**実装事実**

- 中途撤退: 自分の意思で撤退すると、そのダンジョンでの撃破数に応じた
  XP・ゴールドを70%のボーナス率で持ち帰れる（ボス撃破のクリア報酬とは別枠）
- 全滅: 所持ゴールドの30%を失う。XPと装備は失わない

## Save Data

**実装事実**

- `soulforge_save_v1`: 進行（レベル・装備・所持品・スキル／スフィア・
  クリア済シナリオ・`state.job`・`shadowGuideMet` など）
- `soulforge_settings_v1`: 表示設定（音量・画質・画面の揺れ・hit-stop 強度）
- 保存タイミング: 街へ戻るたび／メニューの「セーブ」／タブ非アクティブ化／
  ページを閉じる直前
- ダンジョン内の座標は保存対象外。再開は必ず酒場から
- 新規フィールドは「キーが無い＝旧セーブ」として扱い、既に使えていた要素を
  取り上げない方針（例: `learnedSkill2` が無い旧セーブは習得済みとして読む）
