## 2. 時間帯と出来事（設計 §3 のまま）
| 位置 | 時間帯 | きっかけ |
| --- | --- | --- |
| 0 | DAY | 出撃。原野の分かれ道（z 146）まで一定 |
| 0 → 1 | AFTERNOON | 原野の後半（z 146 → 280）。太陽は西へ |
| 1 → 2 | SUNSET | 谷（z 280 → 310 → 458）。山道の野営地（出会いと加入）で最も深い夕暮れ |
| 3 | NIGHT | 森に入る（z ≥ 468） |
| 重み | DEEP_NIGHT | 古き守り手の戦闘の間だけ（3 秒で上がり、倒すと 3 秒で戻る） |
| 4.0 → 4.5 → 4.8 → 5.0 | DAWN | 古き守り手を倒した、または遺構の北の端（z 615）を過ぎた → 峠 → R5-01 → 石環 |

- 出撃し直した時: 到達 0〜2 は昼、3 は 1.5、4 は 2、5 は 4.6（保存は増やさない）
- テストモードの開始地点: 着いた位置から目標を引き上げる（z とエリアで決まる）
- 光の強さは範囲の中（半球光 0.13〜0.52・太陽 0.15〜0.95・リム 0.14〜0.30。DEEP_NIGHT の半球光は下限 0.16）
- DAY の値は今の `WORLD_MOOD.road2` と同じ（入る時の見た目は変わらない）。A-1 の二つ目の影・A-2 の影は太陽の影の地図なので、時間帯の向きにそのまま付いてくる

## 3. Agent Decisions
- 空は今の作法（`scene.background` と霧の色）で時間帯の色にする。設計 §5-2 の空の球・太陽／月の板・光だまり・環境音の分け替えは、完成に必須でないので後の候補（`.ai/reports/ROAD-VISUAL-COMPLETE-backlog.md`）
- 灯（`M.glow`）は夜に明るさを最大 1.8 倍にして灯って見せる（点光源は使わない）
- 太陽の位置の長さは今の既定と同じ（約 57.7）。影のカメラ（far 90）の中
- 結末の重み（T6）は表と関数だけ用意し、R3-5 / T6 で使う
