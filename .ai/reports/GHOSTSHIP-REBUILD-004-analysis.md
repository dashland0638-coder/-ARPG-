## 1. 描画方式（調べた事実）

| 項目 | 事実 | 場所 |
| --- | --- | --- |
| ワールド | 1 度に 1 つだけ建てる（`buildWorld` / `disposeWorld`） | `02-world-common.js` |
| 背景・霧 | `applyWorldMood`: `scene.background` と `FogExp2`（ワールドごとの色・濃さ） | 同上 |
| 光 | 半球光＋太陽（影あり、影の範囲はプレイヤーに追従）＋逆光 | 同上 |
| カメラ | 透視投影 50°、near 0.1 / far 500。追従は `updateCamera`（camYaw・camDist・camHeight） | `02` / `13-update-loop.js` |
| 壁 | 静的バッチ（材質ごとに 1 つのメッシュへ合成）。高さ 2.3（幽霊船は 1.15） | `02` `addWallBox` / `endStaticBatch` |
| カリング | three.js の視錐台カリングのみ。区画ごとの表示切り替え・遮蔽カリング・マスクは無い（洋館は区画ごとにバッチを分けて視錐台カリングを効かせているだけ） | `02` `mansionZone` |
| 洋館の作り | 森（巨大な草地の板＋木・岩）の上に、各階を離れた「島」として置く。島の下に暗い下地（`mansionUnderlay`）。一階だけ外殻（外壁・屋根）と外周の木立を持つ | `02` WORLD_DEFS.mansion、`03` |
| 幽霊船（第一章） | 海の板（120×240）の上に部屋を並べる。部屋ごとに ±2 の暗い下地。区画は段階ごと（往路・後・撃破後）のグループだけ | `14-dungeon-ghostship.js` |

検索の記録: `layers` / `visible =` / `frustumCulled` / `occlusion` / `stencil` / `clipping` で検索 → 汎用の遮蔽・マスクの仕組みは無い。

## 2. 森の洋館の描画欠落（原因）

正射影・霧なしの上からの写真と、実際のカメラの写真（`scratchpad` の `m-f1` / `g-k1` / `g-h1` / `g-sd` / `g-xf`）で特定した。

| 場所 | 症状 | 原因 | 種類 |
| --- | --- | --- | --- |
| 一階・厨房 | 外壁が部屋を横切り、床に木が生え、外の草地が見える。木は当たり判定もある | 厨房（x 17〜30、仕様 12 で追加）に合わせて、外殻（X1 = 21）・下地（x 22 まで）・東の木立（x 25 / 28）を広げていなかった。森の飾りの除外範囲（x < 32）とコメント（下地 -40..30）だけが更新されていた | マップの範囲定義の不整合 |
| 一階・大広間 / 厨房の東側 | 床の端の帯が真っ黒 | 高さ 7 の外殻が太陽（+x, +z 方向から）の影を屋内の床へ約 5 落としていた | 影の設定 |
| 二階・一階奥・地下・異常空間 | 床の外に森の草地が見える（カメラの向きによる） | 島の下地の余白（約 2）より、カメラが見る範囲が広い。島の下は森の草地のまま。異常空間は自前の下地（50×54）だけで、島として扱われていない | 外側の描き方 |

調べて問題が無かったもの: 部屋と通路の境の床（表どおり連続）、階段の移動後の表示、視錐台カリング（区画のバッチの境界球が正しい）、深度・レイヤー（特別な設定なし）。
部屋どうしの間の黒（例: 一階廊下の左右）は、部屋の表に無い「存在しない領域」で、方針どおり黒のままにする。

共通の描画処理（`buildWorld`・静的バッチ・カメラ）には原因が無い → 共通処理は変えず、洋館の配置データと洋館の作りの範囲で直す。

## 4. 幽霊船

| 項目 | 原因 |
| --- | --- |
| 点呼の影が見えない | 汎用の `spawnApparition`（円錐＋球）に色 0x2a3640・不透明度 0.32。暗い床と壁にほぼ溶ける |
| 船の中から海が見える | 海の板が船の全体の下にあり、部屋の下地の余白（±2）の外は海。背景も夜空の色 |
| 隣の部屋・別の階層が見える | 壁が低く（1.15、003 で断面図のように）、表示の切り替えが段階ごとのグループだけ。往路の階層は同じ平面に並ぶので、船底から船倉の床まで見える |
| 錨の鎖が見つけにくい | 鎖の材質が壁に近い暗い色（0x4a4640）で、床を這う部分も無い |
| 穴を塞いだ板が目立つ | 003 で板を明るい色＋青白い自発光にした |

## 5. 方針

- 幽霊船: 部屋ごとの区画（静的バッチも区画ごとに分ける）で「今いる部屋＋開口のそばの隣＋カメラ演出の対象」だけを描く。外にいる時だけ海
- 洋館: 外殻・下地・木立を厨房まで広げる。外殻は影を落とさない。離れ島では森を描かない
- 共通の方針は `docs/DUNGEON_RENDERING.md` に記録し、洋館・村のカメラは別の未完了の Work Item にする
