## 2. Design principles

**PROPOSAL**（Human の大方針「中世ファンタジー × トゥーン × マット × シンプル」を、判断に使える原則へ具体化したもの。細部の値は HD）

| # | 原則 | 判断基準（YES / NO で使える形） |
| --- | --- | --- |
| P-1 | **仕様に無いものは出さない** | Chapter 1 の本編に存在しない概念（Lv・XP・スキル3・スフィア・鑑定・パッシブ）が本編画面に 1 つでも見えるか → 見えたら不合格 |
| P-2 | **戦闘画面の主役はキャラクターと敵** | 戦闘中、常時表示 UI の合計面積が画面の一定割合以下（目安 **12%**、HD）。画面中央 60%×60% の領域に常時 UI を置かない |
| P-3 | **必要な時だけ出す** | 各 HUD 要素に「常時 / 条件 / 一時 / 非表示」のどれかを必ず割り当てる（§4）。割り当ての無い要素は作らない |
| P-4 | **同じ意味は同じ見た目** | 「選択中」「無効」「押せる」「危険」がそれぞれ 1 つの視覚ルール。画面ごとの独自表現を作らない |
| P-5 | **マット** | 光沢グラデ・ガラス風 blur・常時 glow を使わない。塗りはフラット（最大 1 段の明暗差）。glow は「準備完了」「緊急」の一時状態だけ |
| P-6 | **トゥーン** | 形は丸みのある太めのシルエット、はっきりした輪郭。細い線・小さな装飾・写実的な質感（革・木・金属テクスチャ）は使わない |
| P-7 | **中世ファンタジーは控えめに** | 世界観は色・見出し書体・アイコンのモチーフで表す。枠飾り・巻物・紋章などの装飾を UI 部品に常設しない（タイトル等の限定箇所のみ、HD） |
| P-8 | **1 つの UI system、2 つの layout** | 1280×800 と 844×390 は同じ token・部品から layout だけを変える。PC 版を縮小しない |
| P-9 | **キャラクター identity と UI semantic を分ける** | UI の意味色（HP・危険・選択）はキャラごとに変えない。キャラ色は「誰か」を示す箇所（ポートレート縁・名前の下線）にだけ使う |
| P-10 | **開発用 UI は本番に出さない** | 本番ビルドの通常操作で Test Mode / Arena / PERF / Motion Preview に到達できない |

### 4.4 通知の統合（PROPOSAL、仮決定可）

- 通知は 1 系統: E 下中央（または左下）に 1〜3 行、新しいものが下、数秒で消える。重要度は 3 段（情報 / 獲得 / 警告）で色とアイコンを変える。

## 7. Icon system

### 7.1 方針（PROPOSAL）

- UI アイコンは **ゲーム専用ピクトグラム** に置き換え、emoji / 単色 Unicode を UI アイコンとして使わない（B-6、PI-06 / PI-07）。
- 台詞・固有名詞の中の記号（「▼」送り、★ 評価など）は範囲外（HD 不要、仮決定: 評価の★はアイコン化する）。

### 7.2 設計ルール（PROPOSAL。最終見本は HD-7）

| 項目 | ルール |
| --- | --- |
| グリッド | 24×24 を基準に描く（表示 16 / 20 / 24 / 32 / 40）。内側 2px の余白 |
| 表現 | **塗りのシルエット**（fill）を基本。細部は塗りの抜きで表す。線画（line）は使わない（小サイズでの判読とトゥーン感を優先） |
| 輪郭 | 必要な場合のみ外側に 1.5〜2px の輪郭（暗色）を付ける。付けるかどうかはセット全体で統一（HD-7 の見本で決める） |
| 角 | 角丸（半径 1.5〜2px 相当）。鋭角は武器の刃先など意味がある箇所だけ |
| シルエット | 1 アイコン 1 モチーフ。塗りつぶしても意味が読める形。似た形を別の意味に使わない（現行の 👑 🌀 🗡️ ✦ 重複の解消） |
| 色 | アイコン自体は単色（`currentColor`）。状態・意味の色は **アイコンではなく容器（ボタン・枠）** が持つ |
| selected | 容器の塗りが selected 色、アイコンは容器上の文字色 |
| disabled | アイコンと容器を disabled 色に、形は変えない（半透明を重ねない） |
| active / pressed | 容器が 1 段沈む（縮小 or 明度）。アイコンは不変 |
| cooldown | 容器の外周リング（現行の conic リングを継続）。アイコンは減光。残り秒数の数字は出さない（HD 不要、仮決定） |
| ready（Ult 等） | 容器の外周に一時 glow（P-5 の例外） |
| 職業 / キャラ | 職業アイコンは 4＋1（影の旅人）で、UI semantic 色ではなく **キャラ識別色の容器**（§11.3）に載せる |

### 7.4 配信形式（候補、HD-7）

| 候補 | 利点 | 欠点 |
| --- | --- | --- |
| **A. インライン SVG スプライト（`<symbol>` を 1 回だけ DOM に置き `<use>` で参照）** | 色を CSS で変えられる、HTTP リクエスト無し、Canvas 用の Path データを同じ定義から取れる | 定義ファイルの管理が必要 |

## 8. Design system

### 8.1 token の階層（PROPOSAL）

token を増やしすぎないため 3 段に分け、**画面の CSS が参照してよいのは semantic と component だけ** とする。

```
primitive  色の実値・尺度（数を絞る）          例: --ink-900 … --paper-100, --ember-500
semantic   意味（画面はここを参照）             例: --color-surface, --color-danger, --space-3
component  部品固有（必要最小限）               例: --btn-height, --hud-bar-height
```

### 8.2 token 候補一覧（PROPOSAL。値は §10・§11 と HD）

| 分類 | token 案 | 数 |
| --- | --- | --- |
| color（semantic） | surface / surface-raised / surface-sunken / overlay-scrim / line / line-strong / text / text-muted / text-disabled / text-on-accent / interactive / interactive-strong / selected / focus / danger / warning / success / info | 18 |
| color（status） | hp / resource / stamina / ult / posture / posture-break / enemy-hp | 7 |
| color（feedback） | dmg-out / dmg-in / crit / heal / ally-dmg | 5 |
| typography | font-display / font-body / font-numeric、size: caption / label / body / title / display / hud-num / combat / combat-crit、weight: regular / bold | 13 |
| spacing | 4px 基準の 7 段（4 / 8 / 12 / 16 / 24 / 32 / 48） | 7 |
| radius | sm / md / lg / pill / round | 5 |
| border | width: thin / thick | 2 |
| shadow | panel / raised（2 段のみ。glow は state 側） | 2 |
| state | disabled-opacity は使わず色で表す、focus-ring、press-scale | 2 |
| z-index | world / hud / context / hub / system / modal / dev（7 帯） | 7 |
| layout | hud-margin、safe-area 合成値、touch-min | 3 |
| **合計** | | **約 71**（うち primitive を除く画面参照用） |

- 現行 10 変数（`--bg` 〜 `--text-dim`）は primitive / semantic へ対応づけて移行し、旧名は移行完了まで別名として残す（§14）。
- `src/render/player-palette.js`（3D キャラ配色）は token に含めない（P-9、§11.3）。

### 11.3 Character identity（PROPOSAL）

- **T-5 の `player-palette.js` をそのまま UI に流用しない**（依頼、P-9）。3D の布の色は照明下での見え方のための値で、UI の平面・小サイズでの判別には向かない可能性がある（INFERENCE）。
- UI 用に **職ごと 1 色（job-accent）** の別表を持つ。候補の出所は `CLASSES` の `trim`（01-character-creation.js、剣士 `#c99c47` / 盗賊 `#60496c` / 魔法使い `#8260ab` / 弓師 `#78512d` / 影の旅人 `#8a5ad6`）を参考値とし、UI 用に明度・彩度を調整した値を HD-20 で決める。
- 使う場所は限定: ポートレート縁・名前の下線・職業アイコンの容器・支援 AI の小表示。**HP・選択・ボタンには使わない**。

### 11.4 ベース色（PROPOSAL）

- 現行の「紫がかった黒＋ember」（O-01）を出発点にしつつ、マット化のためにパネルのグラデと blur をやめ、フラットな面＋1 段の明暗差にする。
- トゥーン寄りにするための明度・彩度（例: 背景を黒ではなく深い藍 / 焦げ茶にする）は **画面を見て決める**（HD-5v）。

| `action`（HUD） | 攻撃・スキル・必殺 | round、cooldown リング | pressed / cooldown / ready / disabled / locked(非表示) |
| `choice-card` | 3 択・職業・スキルの選択 | card＋selected 塗り | selected / disabled |

- pill 形（現行の `.event-btn` 等）は廃止し、角丸 md に統一（O-03）。ただし `action` は円。
- 「選択中」は `tab` / `choice-card` / `menu-item` で同じ selected 表現（O-04）。
- 「無効」は全 variant で同じ disabled 表現（O-05）。「未解放」は disabled＋ロックアイコン、「存在しない」は非表示（現行の Skill 2 と同じ考え方）。

## 13. Debug / Test separation

### 13.1 現状（FACT）

- タイトルに「🛠 テストモード」が常時（F-17）。`ver` 5 連打と `` ` `` キーでデバッグ切替（F-17、09:335）。
- Arena・PERF・Motion Preview は本番と同じ DOM / CSS に同居（O-11）。
- E2E はテストモード入口を多用（§1.4）。iPhone 実機テストは本番ビルド（GitHub Pages）で `ver` 5 連打を使う想定（14-hud-boot.js の既存コメント）。

### 13.2 提案（PROPOSAL、方式は HD-3）

**Dev gate を 1 つ作り、すべての開発用 UI の入口をそこに集める。**

| 候補 | 仕組み | 本番ユーザー | E2E | iPhone 実機テスト |
| --- | --- | --- | --- | --- |
| **G1（推奨）** | `?dev=1` の URL パラメータ（または dev サーバ）で dev gate が開く。開いていない時はテストモード入口・`ver` 連打・`` ` `` を無効化 | 到達不可 | `page.goto('/?dev=1')` へ変更（tests の変更が必要） | URL に付けるだけで可 |
| G2 | ビルド時フラグ（Vite の `define` / `import.meta.env.DEV`）で dev UI を本番ビルドから除外 | 到達不可 | dev サーバで実行するので現状のまま | 本番ビルドでは不可（別デプロイが必要） |
| G3 | 現状維持＋入口を目立たなくする | 到達可 | 変更なし | 可 |

- どの候補でも、開発用 UI は `#dev-layer` 相当の 1 つの容器にまとめ、dev 用の色・等幅書体・z-index 帯（最上位の dev 帯）を使い、**本番の token を上書きしない**。
- テストモード画面・Arena は日本語 / 英語の混在（F-18）を許容してよい（dev 専用のため、HD 不要、仮決定）。
- テストモードは `state.testMode` と `saveGame()` の既存ガードを維持（セーブを汚さない仕組みは変えない）。
