## 4. 自動テストで確認できること / 実機でしか確認できないこと

| 対象 | 自動テスト（Agent） | 実機の通し（Human、iPhone） |
| --- | --- | --- |
| 進行の順序・再訪なし・倒れた後 | E2E `chapter1-progression`、CH1-T3 の戦闘不能 | 実際に倒れて戻る流れの分かりやすさ |
| 主人公交代・加入 | E2E（state の注入） | 一幕の間・見え方 |
| 台詞の文言・順番 | unit（配置）、E2E（画面の文言。後半 2 段は CH1-T3） | 読む速さ、戦闘中に割り込まないか |
| 禁止要素が出ない | E2E `chapter1-legacy-ui` ほか、CH1-T1 の文言の検査 | 通しの中で見かけないこと（G-05） |
| 島の人影・跳躍の間・影の遅れ | 配置と条件（unit）だけ | 見えるか、自然か（D-13〜D-16、E-11） |
| 戦闘の手触り・ボス戦の長さ | 数値の固定（unit）だけ | 理不尽な被弾、長さ、Skill 2 の使いでがあるか |
| 支援 AI | 当たり判定・攻撃（CH1-T5） | 仲間に見えるか、邪魔にならないか |
| UI の重なり・文字の大きさ | `dialog-result-layout`・`menu-character-layout`・`ui-foundation`（2 サイズ） | 正式な書体、タッチのしやすさ、safe area |
| 負荷・BGM | 負荷の上限の unit（CV-01）、BGM の設定の unit | fps・発熱・聞こえ方 |
| セーブ・中断 | E2E `save-load`、CH1-T2 | 実際の画面ロック・アプリ切り替え |
