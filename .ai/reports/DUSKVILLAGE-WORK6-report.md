## 4. 水門守の残響（§5〜§9）

### 4-1. 見分けるもの

これまでの敵との関係:

| 敵 | 見分けるもの |
| --- | --- |
| 水鏡の影（WORK 3） | 本体と分身（挙動の**差**） |
| 写し身（WORK 4） | 現在とコピー |
| 記憶漁師（WORK 5） | 現在と過去の**位置** |
| **水門守の残響（WORK 6）** | **いま動いているものと、過去の動作をなぞっているもの** |

**水鏡の影の仕組みはコピーしていない。** あちらは「挙動の微妙な差」で見分けたが、
こちらは **時間** で見分ける:

```
本体   予備動作がある    足元の水面が強く応える   いま動き出す
残響   予備動作が無い    水面は弱くしか応えない   本体が少し前にやったことをなぞる
```

文字もマーカーも出していない（`actorTell()` が返すのは予備動作の秒数と
水面の強さだけで、本体フラグを持たない ―― ユニットテストで固定）。

### 4-2. 最後まで水門を閉めようとしている（§6）

水門守の行動は、プレイヤーを追うことではない:

```
持ち場へ歩く → 予備動作（沈み込む）→ レバー／同じ動作を引く → 次の持ち場へ
```

レバーの前にいるときは**実際にレバーと鎖が動く**。持ち場は出現位置からの
相対で持っているので、村ではレバーの前が1つめになる。

引く動作は、近くにいれば巻き込まれる。プレイヤーを狙って撃つ攻撃は持っていない
―― この敵は最後まで水門を閉めに来ているだけで、そこにいると当たる。

### 4-3. 残響（§7）

本体がやったことを `recordAction` で控え、**1.6秒遅れて**同じ場所で再生する。

- 残響は敵ではない（`enemies` に入れていない。狙えない・倒せない）
- **無害なエフェクトでもない** ―― 引く動作をなぞった瞬間だけ、その場所で当たる
- 追ってこない。離れていれば当たらないので、**避ける遊びではなく見分ける遊び**
- 歩いただけの残響は当たらない（`harmAt` を持たない）
- 予備動作を持たない ―― いきなり始まるので、本体との差が読める

### 4-4. フェーズ（§9）

HPで3段階だけ。増えるのは**残響の数だけ**で、残響の性質は変わらない。

| フェーズ | HP | 同時に見える残響 |
| --- | --- | --- |
| 1 | 100〜66% | 2 |
| 2 | 66〜33% | 3 |
| 3 | 33〜0% | 4 |

上限があるので画面は埋まらない（ユニットテストで固定）。

### 4-5. 強さ

HP 900・攻撃36。硬さで強くしていない ―― 強さは「過去の行動が残っている」
という性質そのもの。見失わないよう、見た目だけ一回り大きくしてある。

## 5. 観測の灯（§10）・幻影歩法（§11）

**観測の灯**: 残響が始まるまでの遅れが 1.6秒 → 2.4秒 に伸びる。
「本体が先、残響が後」がはっきりするだけで、**どれが本体かは言わない**
（`echoDelay()` が返すのは秒数だけ）。灯りが無くても 1.6秒の遅れはあるので、
他職でも見分けられる ―― 必須にしていない。

**幻影歩法**: 釣られやすさ 0.5（水鏡の影 1.0 > 記憶漁師 0.6 > **水門守 0.5** >
写し身 0.35）。水門のほうを見ている敵なので、寄って置かないと気を逸らせない。
**必ず幻影を攻撃するようにはしていない**し、使わなくても勝てる。

## 7. 水門開放（§14）

撃破直後にリザルトも黒画面も出さない。**歩けるまま、世界の側が変わる**:

```
残響が消える → 引く手が止まる（レバーが戻る）→ 歯車が回る
  → 門が約7秒かけて上がる（鎖の音が繰り返し鳴る）
  → 水門の下で、止まっていた水が動き出す（波紋）
  → 開き切ってから当たりを外す（通れるようになる）
```

短い会話が3行だけ乗る:

```

魔法使い「ずっとです。何度も、同じところで」
```

村の過去は説明していない。見たままのことしか言わない。

## 13. 設計上の判断・残課題

### 13-1. `en.onDefeat` を1つだけ足した（設計判断）

中ボスには撃破時に個体ごとの後始末を挟む場所が無く、ボスの `onBossDefeated` は
リザルト・報酬・クリア処理まで抱えているので流用できなかった。`finishEnemyDeath`
に一行だけ足し、**水門守以外の敵は一切影響を受けない**形にしてある。

### 13-2. 残響は敵として登録していない（設計判断）

`enemies` に入れていないので、狙えないし倒せないし、体幹も持たない。
残響を倒せるようにすると「残響を全部消す」遊びになり、**見分ける**という
この敵の役目が消える。当たり判定だけを持つ独立した配列にしてある。

### 13-3. 本体を倒しても、飛んでいる残響は最後までなぞる（設計判断）

記憶漁師の網（WORK 5）と同じ考え方。撃破の瞬間に消えると、「過去がそこに
残っている」という読みのほうが崩れる。撃破演出の側で明示的に消している。

### 13-4. 数値はすべて暫定

`PROVISIONAL_` がついているもの: 残響の遅れ(1.6秒)・寿命(2.2秒)・範囲(2.4)、
本体の予備動作(0.55秒)、レバーを引く時間(1.5秒)、持ち場の移動(2.4秒)、
フェーズ閾値(66% / 33%)、水門守のHP(900)。実機調整待ち。
