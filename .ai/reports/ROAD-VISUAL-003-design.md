- **Human の判断が要るのは 6 件**（§15）
  - E-1 影の旅人の扱いと加入の時期
  - E-2 同行と操作
  - E-3 途中経過の保存
  - E-4 装備の報酬
  - E-5 旧仕様の上書き
  - E-6 PR #125
- **決定（Human、全項目 A）**
  - 影の旅人は残す。エリア 1〜3 では遠くに見えるだけにし、エリア 4 の入口の野営地で出会って加入する（「最後に出会う人物」を保つ）
  - 戦闘は今の「主人公＋支援 1 人」のまま
  - 到達したエリアを保存する
  - 装備は道だけの固定の報酬表にする

## 2. 全体の地形と接続（確定事項 1）

座標は、今の道（x 626〜654）とも重ならない、さらに東の未使用帯（**x 1000〜1200**、z 0〜760）。作っている間は旧道と新しい道が並んで存在するため（§9）。北へ進む。図の x は相対位置。

```
 z 760 ┄┄┄┄┄┄ 道は地平線へ（歩ける範囲の外）
       ┌─────── AREA 5 道の果て（高原・石環）200×120 ───────┐
 z 640 └───────────── 山道の出口（峠） ────────────────────┘
       ┌──── AREA 4 忘れられた山道 140×190 ────┐
       │ 野営地 → 森の外周 → 石の階段 → 遺構 → 山道 │  地下の通路（隠し・ショートカット）
 z 450 └────────────────────────────────────────┘
       ┌──── AREA 3 水鏡の谷 110×150 ────┐
       │ 上の崖道 ═╗ 滝（裏に隠し通路） │  崩れた石橋（メイン）
       │ 川沿いの道 ╝ 水辺の寄り道      │
 z 300 └─────────────────────────────────┘
       ┌──────── AREA 2 風渡る原野 200×190 ────────┐
       │ 旧道（西）  メイン街道  岩場の隠しルート（東） │
       │ 展望の高台（北西）                             │
 z 110 └────────────────────────────────────────┘
       ┌── AREA 1 旅人の宿場 80×110 ──┐
 z   0 └── 入口（酒場からの出撃・帰還の門）┘
```

- **一つの地域**
  - エリアの境は、門や暗転ではなく地形（峠・谷の入口・森の縁）で区切る
  - 前のエリアへ歩いて戻れる
- **野営地**
  - 各エリアの入口に置く（焚き火・荷）
  - 回復はしない（K-10）
  - E-2 / E-3 の答えに従って、「支援を選び直す場所」「到達を保存する場所」になる
- **高低差**: 歩ける高い所は、既存の段差と坂の仕組み（時計塔の坂・台）を使う
  - 歩ける高い所: 原野の高台・谷の崖道・山道の階段
  - 歩けない斜面と遠い山は、見た目だけにする
- **描画**
  - 地形と遠景はいつも描く
  - エリアごとの小物・建物の中・敵は、今いるエリアと隣のエリアだけ描く
  - これは**新しく作る仕組み**。宵待ちの村は屋外をいつも描き、建物の中だけを分けている（DUNGEON_RENDERING:33）
