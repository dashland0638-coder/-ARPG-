# CLOCKTOWER-002 — 設計（Planner）: 巨大な時計機構の内部を、自分の足で登る塔

「時計塔の各階を探索するゲーム」から「巨大な時計機構の内部を、自分の足で登りながら突破するゲーム」へ。
題材（止まった時刻・七時十三分・管理人と娘・過去への後悔）は残し、マップ・仕掛け・物語の運びを作り直した。

## 1. 縦断構造

```
            屋上 y52 ── 見晴台(跳躍) ── 名も無い島
              ▲ 口(ボスを倒すと開く)
  T5 y44  大時計の裏側 ─ 前室 ← 昇降台の上の口
              ▲ 鐘の昇降台(T4 北東の角)
  T4 y34  鐘楼(屋外の吹き抜け。眼下に止まった街。縦穴に大鐘)
              ▲ 坂 r3(西の外壁沿い、北 → 南)
  T3 y26  縦穴の上(管理人の住まい)── 鍵の扉 ── 裏の通路
              ▲ 歯車の輪(縦穴の中。下の桟橋 → 上の桟橋)
  T2 y16  縦穴の底(踊り場)   向こう岸の回廊(撃ち手。行けない)
              ▲ 坂 r1(東の外壁沿い、北 → 南)
  T1 y8   時計工房(西半分) ═ 長針の橋(縦穴を渡る) ═ 部品庫(東半分)
              ▲ 坂 r0(西の外壁沿い、南 → 北)
  T0 y0   塔の入口(前庭 → 玄関)   縦穴の底: 止まった巨大な振り子
```

- 塔は外壁の内側 36×36。真ん中に 12×12 の縦穴。層はその周りの幅 12 の帯（コンパクト: 一層の歩ける面積は 300〜600）
- 縦穴の中は上から下まで一本の機構（振り子・長針・歯車の輪・大鐘・大時計の機構の底）。どの層からも見下ろせ、入口で見上げると一番上に**目的地の大時計の裏が光っている**
- 層と層は**歩いて**繋ぐ: 外壁沿いの坂（踏み板を積んだ見た目、勾配 0.29）・歯車の輪の足場・鐘の昇降台。暗転する階段は屋上の口だけ
- 登るたびに縦穴の反対側へ回る（r0 西 → 長針で東へ → r1 東 → 輪で北へ → T3 を一周 → r3 西 → T4 → 北東の昇降台）＝螺旋
- 上へ行くほど景色が変わる: 石と真鍮の機械室（T0）→ 板張りの工房（T1）→ 鉄の縦穴（T2）→ 住まいの板張り（T3）→ 屋外の白い石と空・街（T4）→ 冷えた色と薄紫の光（T5）。霧と空の色も高さで変わる（既存 `updateAltitude`）
- 分割ロードはしない（一つの世界）。描画を層で分ける（§4）

## 3. 仕掛けの約束（依頼の設計制約への答え）

- 主要な仕掛けは三つ。どれも縦穴の機構そのもの（長針・歯車の輪・大鐘）
- 操作は「調べる」一つ（クランク・クラッチ・綱）。iPhone のタッチで押せる。精密な跳躍は無い
- 失敗の罰が無い: 長針は進めるだけ、輪は 4.6 秒ごとに足場が来る、昇降台は鐘を鳴らし直せば来る
- 落ちない: 縁・坂の口・昇降台の口には高さの帯を持つ手すり。桟橋の先は足場が並んで止まっている時だけ開く。乗り物の上では運ばれる間は降りない
- 重い処理をしない: 動く床は箱の床（`groundSlabs`）の座標を書き換えるだけ。物理演算は無い

## 4. 技術の設計（Phase A の共通の決まり）

| 問題 | 共通の決まり（02-world-common.js「階層」） |
| --- | --- |
| 別の階の壁に当たる・見通せる | 壁は高さの帯 `y0〜y1` を持てる（`wallApplies`）。当たり判定・視線・弾・ミニマップ・デバッグ表示のすべてで使う。帯の無い壁（他のダンジョン）は従来どおり |
| 坂 | 床に `ramp`（軸・両端の高さ）。`groundYAt` が解く（`slabHeightAt`） |
| 別の階の敵 | 同じ階 = 足元の差 4 未満（`onSameFloor`）。別の階の敵は描かず（影も出ない）・動かさず・忘れる（`updateEnemyFloorPresence`）。視線は別の階どうしを通さない。敵は自分の階から出ない（`keepEnemyOnFloor`） |
| 支援の追従 | 支援・使い魔は足元の床の高さに立つ（`allyFloorY`）。一歩ごとに壁と床を見る（`stepAllyOnFloor`）。別の階・遠くに 1 秒いたら、プレイヤーの斜め後ろへ戻る（`guestCatchUp` / `placeGuestNearPlayer`。階段・昇降機・坂のどれでも同じ処理）。別の階の敵は狙わない。射手の支援は塔では矢で届く所から射る（縦穴の向こう岸にも） |
| FPS | 点光源は 6 個を層ごとに置き直す（数を変えない → シェーダーを作り直さない）。静的な物は層ごとに一つのバッチで影を落とさない。描くのは今の層と、その下に見える二層（`updateTowerTiers`）。塔の敵の飾りの点光源は外す |

- セーブ・ロード: セーブは酒場でしか取らず、ダンジョンの中の位置は保存しない（`09-save-load.js`）。出撃のたびに支援を組み直して `repositionAlliesToPlayer` で床の上に置く
- 他のダンジョンへの影響: 上の決まりは `groundSlabs` を持つ世界（今は時計塔だけ）か、帯を持つ壁にしか効かない

## 5. シナリオの変更点

| PR #121 | CLOCKTOWER-002 |
| --- | --- |
| 手記を読んで真相を知る（点検記録・日誌・日記・譜面・書き置き・外套） | 一層に一つの出来事を見せる。手記は補い（読んだらその場で一言） |
| 管理人は最上階で初めて出る | 入口で縁から見下ろす人影、T2 で上からの声、T5 で対峙 ―― 登っている間ずっと上にいる |
| プレイヤーの操作は扉を開けるだけ | 長針を進めると工房の時計が動き出す、鐘を鳴らすと街の灯りが揺れる、撃破後は塔の振り子・輪・街の灯りが動き出す |
| 最上階に行く理由が弱い | 入口で見上げた大時計の裏（光っている・七時十三分）と管理人が目的地 |
| 4F の扉と鍵 | T3 の住まいの扉と鍵（場面は同じ意味。帰るつもりだった） |
| 5F 三つの鐘の旋律 | T4 の大鐘は昇降台と敵をすくませる仕掛け。娘の書き置きは鐘の綱に結ばれている |

- 結末は既存のまま: 管理人が針を進める（七時十四分）→ 塔が崩れ始める → 管理人が鐘を鳴らす → 屋上から跳ぶ → 島 → 翌朝の酒場
- 盗賊の閃き: 場所を 3F 針の通路 → T2 縦穴の底へ移した（「飛び込めない隙間（縦穴）もある。刃だけ通せばいい」）。代わりの発生は T3 に着いた所
- 管理人と娘の名前・娘の生死は出さない（DEC-018 のまま）
