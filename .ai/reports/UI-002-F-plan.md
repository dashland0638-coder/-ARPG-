## 1. 方針

1. **HUD と同じ視覚言語にそろえる**: C2 で Human が実画面で確認した「トゥーン・プレート」（matte な面＋厚い輪郭 `--ui-outline` ＋小さな内縁 `--ui-line` ＋落ち影 1 種、状態は形・塗り・overlay で示す）を、メニューと鍛冶屋のパネル・ボタン・タブに当てる。新しい視覚言語は作らない。
2. **古書・革装丁を「控えめに」**: パネルを「革表紙の手帳」、タブを「しおり」、見出しを「碑文」に見立てる。表現は **形と配置** で行い、画像テクスチャ・グラデーション・ぼかし・発光は使わない（V-2）。
3. **画面構成は最小の変更で、844×390 のスクロールを減らす**: 最もよく使う操作（冒険に戻る・セーブ）とキャラクターの状態を、開いた直後の 1 画面に入れる。
4. **表示条件・id・`data-*`・文言は変えない**（Chapter 1 の境界は PROGRESSION-001〜010 のまま）。見た目と並びだけを変える。
5. **アイコンは「入れ物」を先に作る**: 正式な絵は E の範囲（F-D4）。F ではアイコンが入るプレートの形・大きさを統一し、剣士の承認済み glyph 4 つだけを使う。

## 2. 画面構成の提案

### 2-1. メニュー（F-D1）

**案 A（推奨）: 3 つの「しおり」タブに分ける**

```
┌─[ 冒険 ]─[ 設定 ]─[ 操作 ]──────────────────────────┐   ← しおりタブ（上辺に並ぶ）
│  ┌────────┐  魔法使い                    ┌────────────┐ │
│  │ 肖像    │  魔法使い ｜ 支援: 剣士       │ 冒険に戻る  │ │  ← primary（大）
│  │ プレート │  HP ████████░░ 96/96        ├────────────┤ │
│  └────────┘  MP ███████░░░ 90/90         │ セーブ      │ │
│  攻撃力 30    移動速度 4.4                  ├────────────┤ │
│  必殺技  メテオフォール                     │ 街に戻る    │ │
│  所持金  100                              ├────────────┤ │
│                                          │ タイトルへ  │ │  ← danger の縁
│                                          └────────────┘ │
│                                    ver -                │
└─────────────────────────────────────────────────────────┘
```

- 「冒険」= キャラクター情報（左）＋行動ボタン（右）。844×390 で **スクロールなし** に収める（2 列）。
- 「設定」= 既存の 11 項目（取捨はしない。Undecided）。2 列のグリッドにして縦を半分に。
- 「操作」= 既存の操作説明を、入力ごと（キーボード / パッド / タッチ）の表に組み直す（文言は既存のまま。F-D5）。
- 既存の id（`#menu-name` ほか、`#set-*`、`#menu-resume` / `#menu-save` / `#menu-town` / `#menu-title`、`#menu-version`）はすべて残す。開いた時は常に「冒険」タブ。
- 影響: 「冒険」以外の区画にある要素を E2E が触るなら、その spec はタブを切り替える 1 行が要る（§6）。

**案 B: 1 枚のまま並べ替える** — 行動ボタンを上へ、設定・操作説明を折りたたみ（`<details>` 相当）に。DOM の変更は小さいが、844×390 で「冒険」相当が 1 画面に収まるかは要確認（情報が縦に並ぶため）。

**案 C: 現状の並びのまま見た目だけ変える** — 最小。844×390 の 3.5 画面のスクロールは残る。

### 2-2. 鍛冶屋（本編: 装備品 / スキル）

```
┌ 鍛冶屋 ─────────────────────────── 所持金 100 ─┐
│ [ 装備品 ]  [ スキル ]                          │  ← しおりタブ
│ ┌武器──────────┐┌上半身────────┐┌下半身────────┐ │  ← 装備枠を「横長の 1 行」に
│ │▣ 古びた杖 攻撃+2 [外す]││▣ 擦り切れたローブ HP+5 [外す]││ ... │ │    （844×390 で高さを約半分に）
│ └─────────────┘└─────────────┘└─────────────┘ │
│ [最強装備] [まとめて売却]        装備中 ■ 装備可 ■ 不可 ■ │
│ ┌所持品の一覧（スクロールはここだけ）──────────────┐ │
│ │▣ 旅人の外套  HP+6 ▲HP+1        [装備する][売却 12]│ │
│ └──────────────────────────────────┘ │
│                      [ 閉じる ]                  │
└────────────────────────────────────────┘
```

- 844×390: 装備枠を縦長カード（約 120px）から横長の 1 行（約 44px）へ。スクロールは **所持品の一覧の中だけ**（ヘッダー・タブ・装備枠・閉じるは固定）。
- スキル: 固定カード（アイコンのプレート＋名前＋説明）を、HUD の Skill ボタンと同じ形のプレートにそろえる（Skill = 角丸の四角、必殺技 = 菱形。C2 の形の区別を再利用）。「固定」は鍵の形の小さな印＋文字（色だけにしない）。
- タブ・パネル・ボタンは 2-1 と同じ部品。

## 3. 視覚デザインの提案

### 3-1. 部品（すべて既存 token から。新規値は DECISION と明記）

| 部品 | 提案 | 使う token / 値 |
| --- | --- | --- |
| **パネル（革表紙）** | 面は既存の暗色の **単色**（グラデーションをやめる）。外周に厚い輪郭＋1 段内側に細い縁（革の縫い目の見立て）。角丸は C2 のプレートと同じ 8px。外影は 1 種 | 面 `--ui-surface-panel-top`、輪郭 `--ui-outline` 3px、内縁 `--ui-line` 2px（C2 `.uip-plate` と同じ）、角丸 `--ui-p-radius-8`、影 `--ui-p-shadow-drop-20-60`（既存） |
| **背景の暗幕** | ぼかしをやめ、単色の暗幕のみ | `rgba(6,5,9,0.72)`（既存値）。`backdrop-filter` を削除 |
| **見出し（碑文）** | Cinzel / Noto Serif JP。下に短い区切り線（両端に小さな菱形の留め具） | `--ui-font-display`、色 `--ui-special`（gold、既存）、線 `--ui-line` |
| **しおりタブ** | 上辺に並ぶプレート。選択中 = 面が `--ui-selected` で塗られ、パネル側へ 2px 下がって「差し込まれた」形。非選択 = 面 `--ui-surface-panel-bottom`・文字 `--ui-text-muted`。**グラデーションなし** | `--ui-selected`、`--ui-outline`、`--ui-surface-panel-bottom`（既存） |
| **ボタン（primary）** | 単色の塗り `--ui-selected`、厚い輪郭、落ち影 2px。押下 = 1px 沈む＋影なし（C2 の pressed と同じ） | `--ui-selected`、`--ui-outline`、C2 の `--uip-drop` 相当 |
| **ボタン（通常）** | 面 `--ui-surface-panel-bottom`＋輪郭＋内縁。文字 `--ui-text` | 同上 |
| **ボタン（危険: タイトルへ・撤退）** | 通常ボタン＋内縁を `--ui-danger` に（色＋位置＝最後で区別） | `--ui-danger` |
| **無効** | 形を保ったままコントラストを下げる（HDE-E29 と同じ考え） | `--ui-disabled`、opacity 0.5 前後（既存値 0.35〜0.5 から選ぶ） |
| **パッドのフォーカス** | 発光をやめ、3px の `--ui-special` の輪郭＋2px のすき間 | `--ui-special`（既存） |
| **状態色** | 装備中 = `--ui-special`、装備可 = `--ui-recovery`、装備できない = `--ui-danger`、レア / 特殊 = テストモードだけなので現状維持。凡例は「色の四角」ではなく **形の印**（装備中 = 塗りの盾形、可 = 丸、不可 = 斜線）＋文字 | 意味色はすべて既存。直書きの `#7ad08a` / `#c05a5a` / `#e0b050` を置き換える（色はわずかに変わる → F-D3） |
| **アイコンのプレート** | 24px（PC）/ 20px（844×390）の角丸の四角。中身は正式 glyph（剣士の 4 つ）、無いものは **現行の Emoji のまま**（F-D4 で決まるまで） | `.uip-plate` の比率 |
| **書体の大きさ** | 本文 12px、補助 11px を下限（現状の 9〜9.5px を引き上げる） | **新規値（DECISION、F-D3）**。既存の 11 / 11.5 / 12 / 13px から選ぶ |
| **タッチの的** | 設定・装備のボタンの高さ 36px 以上（844×390） | **新規値（DECISION、F-D3）** |
