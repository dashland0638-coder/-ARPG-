## Root Cause
- **FACT**: 頭身は T-2 第3版（DEC-T2-9）で 3.4 → 5.0 に変えた。Human は T-2 の V-1 で「5.0頭身維持、キャラクター性は T-4」と判断している（CHARACTER-VIS-001 Status History 2026-09-25）
- **FACT**: 顔の造形は「眉・口を追加しない」（HDR-T4-15）で、目は大きさ・間隔・瞳・縦横比の4つの値を Human が確定。目の板の点数（8 / 6 / 4）は Face 再設計 Phase B の低ポリ化の値で、T-4 の Human 確認では「目の点数・輪郭・3層構造は不変」として扱われた（Human がその点数を選んだ記録は無い）
- **INFERENCE**: 可愛らしさを下げている要因は、(1) 頭が全身に対して小さい（5.0頭身）、(2) 頭の下半分が細い（顎 0.38）ため幼さより大人っぽさが出る、(3) 角の立った目、(4) 断面の少ない平らな面の筒が「硬い人形」に見える、の4つ。(1) は Human Decision、(2)〜(4) は造形の値で、既存の承認範囲の中の品質改善として扱える見込み
- **INFERENCE**: 職の識別が被り物・色・武器に頼るのは、体の外形（衣服の量感）が筒のままで、髪も共通だから。T-4 の S-a（衣服の量感で外形を作る）の方針は正しく、量感が足りない
- **FACT**: 描画回数の多さは `addOutline` / `addXrayShell` が部品ごとにシェルを作る方式（`05:2133-2150` / `05:2270-2285`）と、部品数（本体 72〜91）の積

## 6. 調査 B: マテリアル（FACT）
- 固有 Material は1人 16〜26個。役割（role）は7つで固定（P-D3: main / sub / accent / layer / hat / trim / boot）。flat の双子（clothMatFlat / trimMatFlat / subMatFlat）は flatShading のための複製
- 色の波及: T-5 で解消済み。`applyPlayerPalette()` が全 role を毎回上書きし、上位職の解除で基礎職の色に戻る（unit のソース検査）。共有 Material（輪郭線・X 線・役割 Material）を dispose しない処理は T-7 で入った
- 外衣・内衣・ズボン・装飾の分離: role で分離済み（パーカー = main、パンツ・袖 = sub、ゲイター等 = accent、白いシャツ等 = layer、帽子 = hat）
- 残る重複（INFERENCE）: 職ごとの分岐で作る小物の Material（矢筒・投げナイフ・毛皮の襟など）と上位職の専用 Material は role の外にある。描画回数への影響は Material 数より部品数の方が大きい（同じ Material でも部品ごとに描画が分かれる）
- iPhone の描画負荷: 上の §4。Material の統合だけでは描画回数はほとんど減らない（INFERENCE: three.js は Material が同じでもメッシュごとに描画する）。減らすには「同じ可動部・同じ Material の部品を1つのメッシュへまとめる」か「輪郭線・X 線の付け方を変える」必要がある

## 7. 調査 C: モーションとの整合（FACT / INFERENCE）
- 構え・攻撃・待機の姿勢は `STANCE` / `STANCE_ALT` / `STANCE_RELAXED` / `CLIPS`（基礎職キーで引く。影の旅人は charKey）。衣服は可動部（waist・股関節・膝・肩・肘・`headLookPivot`）の子なので、姿勢が変わっても衣服は追従する
- 武器は `updateGrip()` が手の位置から毎フレーム計算し、収納は `WEAPON_SOCKET`（`05:2562`）。体格（手の位置）を変えると武器の握り・収納位置も動く
- 干渉の既知リスク（CHARACTER-VIS-001 P-R25〜R28）: ワイドパンツの左右の重なり（`stanceW` 0.095〜0.11 に対して太腿の半幅 0.085〜0.095）、上着と腕を大きく振るクリップの貫通、フードと Look Rig、背中の大剣・弓と衣服、腰の短剣とパンツ
- 外見の変更で起こりうる問題:
  - 頭身を変える（BUILD を変える）と、手の高さ・武器の位置・衣服の取り付け位置・`weapon-stow` の切っ先の高さ（戦騎士の大剣で前例あり）・`character-motion` E-2（頭身・手とベルト・肩 / 腰の幅の比）が動く
  - 衣服の量感を増やすと、腕の振り（CLIPS）・回避の丸まり・魔法使いの明滅で貫通しやすくなる
  - 髪を長くする（魔法使い）と、首振り（Look Rig ±38°）・背中の衣服・杖の構えと干渉しうる
- 待機の立ち姿が全員同じ（O-5）のは `STANCE_RELAXED` の値の問題で、外見ではない。今回は記録のみ（モーションは改修しない）
- 上位職へのモーション展開: 上位職は基礎職の STANCE / CLIPS に `JOB_IDLE_MUL`（`src/core/combat-stance.js:82`）等の係数をかけるだけ。外見の改善は上位職のモーションに影響しない（FACT: 上位職の外見は `applyJobPromotionVisual()` で、モーションの表は基礎職キー）
