## 1. Story Connection Summary

```
[宵待ちの村]  魔法使い＋剣士   ――「忘れられても、消えたわけじゃない」
```

### 1-2. 一本の糸（すべて既存の素材から）

第一章の怪異には、どれも**「ずれ（遅れ・止まり）」**がある。新しい設定ではなく、既にある実装と台詞を並べ直しただけ。

| 段 | 何がずれているか | 既存の根拠 |
| --- | --- | --- |
| 洋館 | 影が人から離れ、遅れて追う | 館の主 Phase 3 の 0.42 秒遅れの追撃 |
| 村 | 記憶が遅れて繰り返される | 水門守の残響（1.6 秒遅れ）、「残ったんですね」 |
| 幽霊船 | 帰るはずの時から、船だけが進まない | 「早く帰れる近道」が呪いになった船長 |
| 時計塔 | 時刻そのものが七時十三分で止まる | 時喰らい＝「時を進ませない」 |
| 道 | 影が本人より少し遅れて動く人 | 橋の影、最後の酒場の魔法使いの台詞 |

**第一章の核心（案）**

- 怪異の正体は最後まで分からない。それでも「見て、分かる範囲で分かって、立つ場所を選び、時を合わせて、崩す」ことはできた。
- 最後に出会うのは、その「ずれ」を持った人。四人はそれを倒す相手にせず、一緒に歩く相手として選ぶ。

## 3. B. Recommended Proposal（推奨案）

**方針**: 既存の素材（七時十三分、鐘、霧で港が分からない船、出ていった娘、射出台、名も無い島、隅の席）を**因果でつなぎ直す**。新しい設定は最小限で、§7 に明示した3件のみ。

### 3-1. 宵待ちの村 → 幽霊船

**なぜ向かうのか**
- 弓師が霧の港の噂を持ち込む。「乗員のいない船が、毎晩同じ時刻に船鐘を鳴らしている」。
- 魔法使いは村で「消えたわけじゃない、残った」と知った。人だけがいなくなった場所を、もう一度自分の目で確かめたい。
- 弓師にとっての理由: 港は歩き慣れた場所。誰にも頼まれていないが、鐘の音が気になって眠れない。

**村で何が起きたか（既存）**: 村の残響を鎮め、夜明けを見た。何も戻らないが、暮らしの跡は消えていない。

**情報の提供者**: 酒場の主人（船の噂）と弓師（同じ時刻に鳴る鐘）。依頼主はいない。

**出発時の会話（叩き台。既存の交代4行の後に足す）**
- 弓師「毎晩、同じ時刻に鳴るんです。乗っている人は、いないのに」
- 魔法使い「……確かめに行きます。今度は、最初から見ておきたいので」
- 剣士（見送る側）「見てから決めろ。……あの村で、そうしただろう」
  - 剣士は支援を外れるので、酒場に残る側として一言だけ言う。

### 3-2. 幽霊船

**船の存在理由（既存＋整理）**
- 船長は沈没船の"錨"を「早く帰れる近道」と思い込んで引き上げ、船ごと霧に縛られた。
- B で足すのは1点だけ。**霧の中の船は「塔の鐘」を頼りに港へ帰る。その鐘が鳴らなくなったので、港が分からないまま霧の港へ流れ着いた**（新規設定 N-1）。

**第一章全体の謎との関係**
- 帰る時刻から進めない船。村の「遅れて繰り返す記憶」と同じ形の「ずれ」。
- 正体は説明しない。

**船内の流れ（既存の部屋・イベントを使う）**

| 場所 | 既存 | 足すもの（会話・手記の文面のみ） |
| --- | --- | --- |
| 甲板 | 歌声、海を見る影 | 弓師「……あの人、陸のほうを見ていました」 魔法使い「帰り道を探しているんでしょうか」 |
| 船長室 | 航海日誌、船長の手記 | 止まった船の時計（文面のみの手記）:「七時十三分」。弓師が気づく ―― 噂の鐘と同じ時刻 |
| 貨物室・下層 | 晩餐の食器の音、航海士の手紙 | **中間イベント**（晩餐の間）。魔法使いと弓師の会話。帰る場所の話（§3-7） |
| 船倉の警告 | 「船長は、もう船長ではない」 | 魔法使い「分かっているつもりで、決めてしまったんですね。……少し、覚えがあります」 |
| ボス前 | 船長の影 | 弓師「……鐘を待っている顔です」 |

**ボス（帰港を望む船長）**
- 戦闘性能は変えない。第一章のときだけ台詞を差し替える（既存の `dialogueLines` の分岐）。
- 叩き台:
  - 「……ここまで来たか。霧の中では、鐘だけが帰り道だった」
  - 「あの塔の鐘が、七時十三分で黙った。それきり、港がどちらか分からん」
  - 「近道など、選ぶべきではなかった。……だが、もう戻れん。お前たちも、ここに残れ!」

**撃破後**
- 既存の「港が……見える……」の前に一言足す。船長「……鐘を。あの塔の鐘を、鳴らしてくれ。まだ、霧の中に……」。
- 乗員の影が霧へ溶けていく（既存の演出文）。

**時計塔へ向かう理由**: §6 を参照。

**酒場の痕跡（案）**: 棚に**船の小さな角灯**（または既存報酬の「錆びついた錨の欠片」）。新しいセーブ項目は作らず、`scenarioClears('ghostship')` で判定する（村の木彫りの舟と同じ方式）。

### 3-3. 幽霊船 → 時計塔（最重視）

「次の噂」ではなく、**三つの事実が重なって塔へ向かう**。

1. **時刻が一致する**: 船の時計も、塔の鐘も、七時十三分で止まっている。
2. **船長が頼む**: 「あの塔の鐘を、鳴らしてくれ。まだ霧の中に……」。帰れない船は、この船だけではない。
3. **酒場の主人の情報**: 塔に入った管理人が、七日戻らない（既存）。

弓師は誰にも属さない。なのに、この頼みを引き受ける。理由は言わない。ここが弓師の物語の転回点（§5）。

盗賊が名乗り出る理由（既存の交代4行を前提に、一行だけ足す）。

- 主人「塔の鐘が、毎晩同じ時刻で止まるらしい」
- 弓師「止まっているのは、鐘だけじゃありません。船も、あの時刻で」 ← 足す一行
- 盗賊「止まってるなら、入るのは簡単だ。開いてる窓はどこにでもある」（既存）
- 弓師「……その言い方、あとで詳しく聞かせて」（既存。prevName）
- 盗賊「着いてからな」（既存）

### 3-4. 時計塔

**なぜ向かうのか**: §3-3 のとおり。目的は**鐘を正しい時刻に鳴らすこと**。管理人の捜索はその途中で起きる。

**塔で起きていること（既存）**
- 七時十三分＝管理人の娘が家を出た時刻。
- 塔は、その時刻から先へ進まない。時喰らいは「時を進ませない」。
- 正体は断定しない。娘が何者か、管理人と時喰らいの関係も断定しない。

**探索中の出来事（既存の部屋・手記を使い、会話を足す）**

| 階 | 既存 | 足す会話（叩き台） |
| --- | --- | --- |
| 1F 玄関 | 掲示板「管理人 入塔中 ―― 七日前」、置時計の前の影 | 盗賊「七日か。……待つ側にしちゃ、短いな」 |
| 2F 歯車の間 | 管理人の手帳「あの子が出ていった時刻と、同じだ」 | 弓師「待っている人がいるんですね」 盗賊「……出ていった方は、戻りにくいもんだ」 |
| 3F 針の回廊 | 娘の書き置き、針の合間の娘の影 | **中間イベント**: 盗賊が書き置きを拾う。弓師「上の階へ向かう側に落ちていました」 盗賊「下りる気は、なかったんだな」 |
| 4F 鐘の広間 | 譜面「後ろにいるのは、わたしじゃない」、背を向けた管理人の影 | 弓師「振り返らないで。……今だけは、私が後ろを見ています」 ← 弓師＝現在を見る、盗賊を背中から支える |
| 5F 前室 | （無し） | 管理人の外套と懐中時計だけが落ちている（文面のみの手記で表す。新しいオブジェクトは既存の `buildLoreNote`）。針は七時十三分。盗賊が懐へ入れる。「……預かっとく。返すまでな」 |

**ボス前（時喰らい）**
- 既存の台詞（「……七時十三分。幾晩、幾晩と…」）のまま。
- 戦闘の直前に盗賊の一言を足す。「止めてりゃ、出ていかれずに済むってか。……そうはいかねえよ」

**ボス戦**: 性能・フェーズは変えない。

**撃破 → 崩壊（既存の `towerCollapse` を一部書き換え）**
- 時喰らいが砕け、止まっていた歯車が一斉に回り出す。
- **時が動き出したので、塔は「七時十三分の塔」ではいられなくなる** ―― それが「塔が拒む」の中身（説明はしない）。
- 「降りる階段は無い。……ならば、上だ」（既存）

**屋上イベント**: §3-5。

### 3-5. 時計塔 → 道（CT-03 の接続）

**なぜ屋上から跳ぶのか**（三つを重ねる。どれも既存の素材）

1. **下へは戻れない**: 塔が崩れ、螺旋階段が失われる（既存「降りる階段は無い」）。
2. **塔の技師が残した脱出口がある**: 屋上の射出台。「非常時脱出装置」の銘板に二人分の名前、ひとつは彫りかけ（既存）。管理人と娘が、いつか使うつもりで作りかけた物（文面だけで示す。断定はしない）。
3. **跳ぶ瞬間がある**:
   - 盗賊が隙間を見つける。「出口は一つだ。……窓はどこにでもある、って言ったろ」
   - 弓師が「今」を読む。「鐘が鳴ります。……鳴ったら、跳びます」

- 遠い鐘が、もう一度正しく鳴る。
- 対岸の街道に、一人歩いていく人影が見える。弓師「……影が、少し遅れていました」。盗賊は答えない。道の伏線で、名前は出さない。

- 盗賊は懐中時計をカウンターに置く。「塔の管理人に、返しといてくれ」。
  - **盗った物ではなく、預かった物を返す**。盗賊の後悔に、行動で一つ応える。

## 4. C. Enhanced Proposal（強化案）

**方針**: B に加えて、第一章の前半（村）と後半（船・塔）を、**人の縁**で結ぶ。最も印象に残るが、完成済みの村の解釈に踏み込み、新規設定が増える。

### 4-1. B に足すもの

| # | 内容 | 既存の根拠 | 新規性 |
| --- | --- | --- | --- |
| C-1 | **航海士の手紙の宛先を、管理人の娘にする**。差出人も宛先も無い手紙は、塔を出ていった娘が乗った船から届かなかったもの。弓師が持ち帰り、塔の父親の元へ届けようとする | 「差出人の名前も、宛先も書かれていない」（既存）、「七時十三分＝娘が家を出た時刻」 | **大**（娘が船に乗った、という新事実） |
| C-2 | **村の木札（ボスの報酬「水底に沈んだ木札」）が、霧の港の船札だった**。村と港がつながり、村 → 船の必然が強まる | 報酬名（既存）。中身の設定は無い | 中 |

### 4-2. C の物語の芯

- 娘は七時十三分に家を出て、霧の港から船に乗った。船は"錨"とともに霧へ消えた。
- 父親は時刻を止めた（それが怪異になったのかは断定しない）。
- 弓師は娘の手紙を父親へ届け、盗賊は懐中時計を返す。
- 「どこにも属さなかった人」と「出ていった人」が、出ていった娘の代わりに手紙を持ち帰る、という一本の筋になる。

### 4-3. リスク
- **C-1 は物語の因果を断定する。** 「怪異の正体を断定しない」方針とぶつかる可能性がある。娘の行方は既存では意図的に伏せられている。
- **C-2 は完成済みの村（WORK12）の報酬の意味づけを変える。** 村の「忘れられること」の余白を狭める。
- 実装コストが B の約1.5倍（NPC 1体、手記の追加、村側の文面変更）。
