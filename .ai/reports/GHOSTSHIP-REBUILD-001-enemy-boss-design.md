## 0. 方針

- 敵は**乗組員の「残影」**: かつての持ち場で、生前の仕事を繰り返している人の影。役割（水夫・見張り・給仕・船大工・甲板長・船長）を**シルエットと道具**で見分けられるようにする。
- 見た目は村で Human が承認した方針（CH1-COMP-W3-GHOST: 幽霊・人型の影。ゾンビ・腐敗・骨・グロテスクな肉体は採らない）に合わせる。裾が透け、床の霧に溶ける。マットな材質、輪郭線、新しい光源は足さない。
- **AI は既存の型を使う**（突進 `charge` / 射撃 `fire` / 回り込み `ghost` / 強敵 `strongMob` / 中ボス `midbossName` / ボスの召喚）。新しい AI の型は作らない。新規はボスの「鎖の引き寄せ」1つだけ（代替案あり）。
- 予兆 = 判定（村・洋館の作法）。数値（HP・攻撃力）は**この設計では変えない**。変える必要が出たら実装後の通しで HE-3 の形式で上げる。

## 3. ミニボス: 甲板長

| 項目 | 設計 |
| --- | --- |
| 物語上の立ち位置 | 船長の命令「誰も降ろすな」を、船長に代わって守り続ける人。点呼をとる係。帰還不能の後、「なぜ帰れないか」を最初に**言葉で**突きつける |
| 生前の役割 | 甲板長（乗組員のまとめ役）。三日目に穴を破って出ようとした者たちを止め、船大工に穴を塞がせた（手帳） |
| なぜ敵対するか | 命令に従っている。二人を「持ち場につかない乗員」と見なす。悪意ではなく職務 |
| 外見・シルエット | 大柄（通常の敵の ×1.2 程度）。短い外套、首から下げた**号笛**、肩に掛けた**太い鎖**（錨の鎖の一部）。帽子は被らない（船長と見分ける） |
| 攻撃方法 | ①鎖の振り下ろし（前方の短い帯。長めの溜め）②突進（既存の強敵の突進）③**号笛**: HP 50% で一度だけ、水夫の残影を2体呼ぶ（既存のボスの召喚の仕組みを流用） |
| 戦闘中の演出 | 開始時に「点呼!」。廊下の両側の影が一斉に二人を見る（戦闘には加わらない）。号笛で影の列が一歩前へ出る（演出のみ） |
| 倒した後 | 号笛が床に残る（調べると短い一文）。手帳（③と⑦-d を繋ぐ）。廊下の終わりの点呼板に、名前の無い札が二本増える。次の扉（船長室……?）が開く |
| 既存との関係 | 既存の中ボス「沈んだ航海士」（宝物庫の脇、身体の半分が魚）は第一章では出さない。航海士は寄り道の手紙と船内図で物語に残す |

## 4. メインボス: 帰港を望む船長（既存の名前を改修して採用）

### 4-1. 設定

| 項目 | 設計 |
| --- | --- |
| 正体 | 船長本人の残影。錨の鎖を握り続け、船を霧に留めている |
| 船長の過去 | 長い航海の帰りに霧で港を見失った。流されぬよう沈んだ船の錨を繋いだ。陸を探しに出た五人が戻らず、「もう誰も降ろさない。全員で帰る」と誓った。毎晩、戻らない五人のために船尾の角灯を点け、点呼をとる |
| 船に残り続ける理由 | 数がそろうまで港へ向かわない、と決めたから。自分が手を離せば、残った乗員まで散ると思っている |
| 敵対する理由 | 二人を空いた席を埋める「新しい乗員」と見る。「帰る場所が無いなら、ここにいればいい」と弓師を引き留める。拒まれると、力で持ち場につかせようとする |
| 「帰港を望む」の意味 | 帰りたいのは本心。その願いが「全員で」に縛られて、誰も帰さない形に変わった |
| 比較 | 既存の「帰港を望む船長」の名前・立ち位置（最深部で待つ船長）は**採用**。「近道」「塔の鐘」は**削除**。動機を「全員で帰る誓い」に**改修**（物語 §2-1 の案 A） |

### 4-2. 外見・シルエット

- 背の高い人影。長い外套の裾が透けて床の霧に溶ける（脚は見せない）。三角帽（既存）。
- 左手に**船長の角灯**（唯一の暖色。戦闘中もずっと灯っている）。右腕から肩に**錨の鎖**を巻きつけ、鎖の端は床の穴へ続いている。
- 腰に舶刀（既存のカトラス）。既存の鉤の手は外す（鎖を握る手にする）。フジツボは外す（「残影」の方針に合わせる）。
- 目の光は既存（0x7ecbe8）。発光・光源は増やさない（角灯の暖色は材質の色で表し、ライトは足さない ―― 実装時に描画の負荷と合わせて決める）。

### 4-3. 戦闘の構成（3 段）

| 段 | HP | 名前 | 行動 | テーマ |
| --- | --- | --- | --- | --- |
| 1 | 100〜65% | 船長 | ①**舶刀の薙ぎ**（前方の扇。溜めの間に刃が光る）②**鎖の引き寄せ**（新規。下記）③角灯を掲げて一歩下がる（隙。攻撃の機会） | 一対一。「離れられない」を覚える |
| 2 | 65〜30% | **総員、点呼!** | 段1 の行動＋**点呼**: 壁際の影の列から水夫の残影が2体起き上がる（既存の召喚。同時に最大4）。召喚の間は船長が角灯を掲げて動かない（隙） | 数えられる・囲まれる |
| 3 | 30〜0% | **離さん、この鎖だけは** | 船長が鎖を両手で握る。①**鎖の薙ぎ払い**（床をなぞる大きな弧。予兆の線が先に床を走る。1回ずつ）②鎖の引き寄せの間隔が少し短くなる。召喚は止まる。部屋の壁が一瞬だけ、食堂や船員室の壁に見える（見た目だけ） | 船を留めているものとの対決 |

**鎖の引き寄せ**（新規の行動。1つだけ）:
- 予兆: 船長が鎖を後ろへ引く（0.9 秒前後）。床に、船長から弓師への**線**が描かれる（判定と同じ幅）。
- 当たると: 小さなダメージと、船長の方へ最大 4m 引き寄せられる。引き寄せの直後に確定で当たる追撃は置かない（理不尽にしない）。
- 避け方: 横へ動く・回避。弓師が距離を取り続けるほど撃ってくる ―― 戦闘で「帰れない」を表す。
- 代替案（実装の負担を下げる場合）: 引き寄せを外し、同じ予兆の**鎖の打ち据え**（線の範囲攻撃）にする。体験の差は「引き戻される感覚」が無くなること。

### 4-4. フェーズ移行の演出

| 移行 | 演出 |
| --- | --- |
| 開始 | 錨の間に入ると、壁際の影の列が一斉にこちらを見る。船長が角灯を掲げ、台詞（物語 ⑪） |
| 1 → 2 | 船長「総員、点呼!」。影の列が一歩前へ出る。環境音が止まる（BGM の変奏が使えれば厚くする。W9 で確かめる） |
| 2 → 3 | 召喚された水夫が霧に溶ける。船長が角灯を足元に置き、鎖を両手で握る。船全体が大きく軋む。BGM の拍が止まり、鎖の擦れる音だけになる |

演出の間は既存の作法どおりボスの行動を止める（理不尽な被弾をさせない）。

### 4-5. 撃破時の演出

1. 船長が膝をつく。角灯が床を転がり、暖色の光が揺れる。
2. 鎖が手から滑る。唸りを上げて床の穴へ走る（数秒）。**長い水音**（錨が海へ落ちる）。
3. 完全な無音（2〜3 秒）。壁際の影の列が、一人ずつ消える。
4. 結果画面（既存。第一章では時計塔と同じく `endsRun:false` ＋ `afterDefeat`）→ 撃破後の会話（物語 ⑫）→ 構造が戻る → 船長室（本物）→ 甲板（物語 ⑬）→ 小舟 → 酒場。

### 4-6. 撃破後に空間異常が解消される理由（因果）

```
船長の誓い「誰も降ろさない」
   └ 錨がそれを叶える（船を霧に留め、外への道を内へ繋ぎ直す）
        └ 船長が錨の鎖を握り続けている ＝ 誓いを手放していない
撃破 → 船長が「数が合わない。お前たちは乗員ではなかった」と認める
     → 鎖から手を離す → 錨が海の底へ落ちる
     → 船を留めるものが無くなる → 通路が元に戻る（「……?」の区画が畳まれる）
     → 上から押さえられていた昇降口が開く → 甲板へ
```

プレイヤーに見せる順: 鎖が落ちる（目と耳）→ 軋みが波の音に変わる（耳）→ 昇降口の光（目）→ 甲板で影が陸を向いて消える（目）。台詞で説明するのは船長の「降りて、いい」だけ。

### 4-7. 戦闘の公平さ

- すべての攻撃に予兆があり、予兆の形 = 判定の形（村・洋館と同じ）。
- 同時に避けるものを2つ以上にしない（召喚中は船長が動かない、鎖の薙ぎ払いの間は引き寄せをしない）。
- 数値は既存（HP 820 / ATK 40 / 速さ 1.95、難易度補正）のまま実装し、通し（CG-05 の目安: 初見 3〜6 分、倒れても 2 回以内）で確かめる。外れたら HE-3。
