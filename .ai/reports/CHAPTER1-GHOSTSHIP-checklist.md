目的: 既存の幽霊船（周回用ダンジョン）を、第一章③（弓師＋魔法使い）として使う前提で棚卸しする。そのうえで、承認済みの物語をどこへ載せるかを決める。**コードは変更しない。**

## 1. 構造（実装の事実）

出撃地点は甲板ではなく、**船腹の小舟の桟橋**（`GHOST_SHIP_ENTRY` = (-13,0,62)。「小舟で横付けして船内から入る」）。

```
桟橋 (-13.5,62) ─ 扉 dockDoor (-8,62)
 → 晩餐の間（中心 0,62、z 52〜72。食器の音 (0,66)、敵2）
     ├ 寄り道: 物資庫（廊下の曲がり角から）
     ├ 寄り道: 船員室（南、扉 quartersDoor (0,52)）→ 牢・宝物庫の脇【中ボス: 沈んだ航海士】
     └ 寄り道: 細い通路 → 小さな船室（航海士の私室。差出人も宛先も無い手紙）
 → 扉 messDoor (-5,72) → 控えの廊下 → 扉 crewDoor (0,80)
 → 船長室（z 80〜95。船長最後の手記 (-3,91)）
 → 扉 cabinDoor (0,95) → 甲板（z 95〜125。歌声 (0,112)、海を見る影 (-5,105)、航海日誌、瓶の手紙、敵4）
 → 階段 (6,108) → 貨物室（中心 30,114。強敵2）
 → 階段 (23,122) → 船倉の奥（警告の手記 (-38,104)、船長の影 (-30,110)、扉 bossHoldDoor）
 → 【ボス: 帰港を望む船長】(-32,120)
```

- **本筋**: 桟橋 → 晩餐の間 → 船長室 → 甲板 → 貨物室 → 船倉の奥 → ボス。
- **寄り道**: 物資庫・船員室・牢・宝物庫（中ボス）・小さな船室。
- **晩餐の間と船長室は本筋の上にある**（行かずに先へは進めない）。

## 4. 実装の境界（CG-02 / CG-03）
- 足すもの:
  - 会話イベント（既存の `registerProximityEvent` / `registerRoomEvent`。村と同じ `playCutscene` / `cutsceneLine` も使える）
  - 手記1つ
  - ボスの台詞の分岐
  - 撃破後の1行
  - 酒場の小物1つ
- 変えないもの:
  - マップ、敵、ボスの性能、扉、階段
  - 凍結中の第一章システム
  - セーブ（項目を増やさない）
- 話者名: 弓師・魔法使い（`CLASSES` の名前）。主人公が弓師なので、`state.name` は弓師。

## 5. 自動テストの計画（CG-04）
- 本編のときだけ第一章の台詞、テストモードでは既存の台詞（ボスの台詞・撃破後の行）。
- 晩餐の間の会話は、晩餐の間の戦闘を終えてから一度だけ出る。
- 酒場の小物は、幽霊船をクリアしたセーブでだけ出る。
- 物語の順番（甲板 → 貨物室 → 船倉の奥 → ボス → 撃破後 → 酒場）で、本筋の会話がすべて本筋の上にある（CM-06 と同じ作法の連結）。

## 6. 結論
- 幽霊船の既存の中身（マップ・敵・強敵・中ボス・ボス）は、第一章でそのまま使える。足りないのは物語だけで、それは CG-02 / CG-03 で載せる。
- 物語の載せ場所はすべて本筋の上にあり、取りこぼしは起きない（§1・§3）。
- Human の判断が要る事項は無い（置き場所は CHAPTER1_STORY の範囲で Agent が決める、と DEC-004 で取り決め済み）。
