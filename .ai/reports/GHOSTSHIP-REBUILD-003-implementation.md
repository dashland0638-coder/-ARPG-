- **船首 = -z(画面の下)、船尾 = +z(画面の上)、左舷 = -x(画面の右)、右舷 = +x(画面の左)**。往路はずっと画面の上(船尾)へ進む
- **各階層に同じ形の船体**: 外周の壁と上端の縁、4 ごとの肋材(柱)、船首側の舳先の形の床、船尾の板(居住区は船尾の窓)。どの階層でも船の向きが読める
- **断面の見え方**: 壁の高さを 2.3 → 1.15 に(幽霊船だけの `gsWallBox`)。上から部屋の中が見え、手前の壁で人物が隠れない
- **階層の表示(控えめ)**: ミニマップの部屋の名前に階層を前置き(例「居住区・食堂」「下層・船底……?」「最深部・錨の間」)。新しい UI は足していない
- **階層を移る時**: 階段・梯子・昇降口(暗転)。床の材質(居住区 = 明るい板、船倉 = 暗い板、下層 = 傷んだ板＋水、深部 = 冷たい板＋深い水)・灯りの色(下へ行くほど冷たい青)・環境音が変わる

## 3. カメラ(P1)

既存のカメラの仕組みはそのまま。`13-update-loop.js` に、幽霊船の中(`currentWorldKey === 'ghostship' && gsActive`)だけ通る変更を 2 つ足した: (a) 見せる場面のカメラの分岐 1 行、(b) 進行方向への自動の回り込みを止める(船首 → 船尾の向きを保ち、`w` がいつも船尾へ進むように)。他のダンジョン・旧い船は通らない。

| 場面 | 動き |
| --- | --- |
| 通常の探索 | 追従は既存のまま。進行方向への回り込みはしない。自動カメラが ON なら、手で回した後(待ち時間の後)に船尾(画面の上)を見る向きへゆっくり戻す。OFF の人のカメラは戻さない。ボス戦の追尾は既存のまま |
| 見せる場面 | `gsCamShot`: 見せたい物の少し上から 1.2〜2.2 秒見せる。演出(会話)が続く間は見せたまま。終わったら既存の追従へ滑らかに戻る |
| 食堂(往路) | 入る → 卓と皿を画面に入れる → 間 → 「十五人分の皿」 |
| 船員室……? | 扉の先の部屋を見せる → 間 → 「……ここ、船員室でしたか?」 |
| 食堂……? | 卓を見せる → 間 → 食器の触れ合う音 → 「十七人分」→ 会話 |
| 柱の印 | 印を見せる → 間 → 「この印……」 |
| 下層……? | 穴のあった所と印を見せる → 間 → 「印が、入ってきた穴を指している。……そこに、穴が無い」 |
| 点呼の廊下・前室・錨の間の前・甲板 | 廊下の奥行き・扉の先・陸影を見せてから |

## 4. 魔法の目印(P2)と船底の穴(P3)

- 弓師が矢じりで刻み、魔力を込めた**青白い光の矢**。床に大きく(長さ 1.6)・暗い輪郭・足元の輪・刻んだ柱の光の筋。加算の材質で暗がりから浮かぶ(光源は足していない)。ゆっくり明滅し、近づくと明るくなり小さく鳴る。刻んだ瞬間だけ強く光る
- 3 か所(既存の仕様のまま):

| 印 | 往路 | 帰還不能の後 |
| --- | --- | --- |
| 1 | 下層(船底)。左舷の**穴**を指す | 下層……? の同じ所で、同じ向きに**穴のあった所**を指す ―― そこは船体の壁。穴の形の**光の輪郭**だけが壁に残り、床に淡い光 |
| 2 | 船倉。下層への階段(帰り道)を指す | 食堂……? の出口の柱で、**逆向き(奥)**を指す |
| 3 | 船員室。船倉への梯子を指す | 深部の船員室……? で、**存在しない扉**を指す |

- 船底の穴: 板そのものを暗がりで見せるのではなく、**1 つ目の印が出口の位置を指し、その場所に出口が無い**ことで分からせる。新しい板は印の光を受けて青白く(材質の自発光を弱く)。光の輪郭が「出口があった場所が消えた」を示す
