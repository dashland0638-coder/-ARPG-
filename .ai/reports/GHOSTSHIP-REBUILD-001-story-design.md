## 1. 一行で

**「全員で帰る」と誓った船長が、錨で船を霧に留め、"誰も降ろさない"船を作った。主人公たちは乗り込んだ瞬間から"乗員"として数えられ、帰れなくなる。**

## 2. 幽霊船の正体（推奨案 A）

| 問い | 答え（プレイヤーが最後に理解できる形） |
| --- | --- |
| なぜ海上を漂っているのか | 長い航海の帰り、船は霧で港を見失った。船長は流されないよう、霧の中で見つけた**沈んだ船の錨**を引き上げて自分の船に繋いだ。それ以来、船は霧の沖を漂いながら、どこにも着かない |
| なぜ人の気配が残っているのか | 乗組員はいなくなったのではない。**持ち場に残った**。寝台・食卓・見張り台で、生前の仕事を繰り返す「残影」になっている |
| 乗組員はどうなったのか | 乗組員は二十人。陸を探して小舟で出た五人は霧から戻らなかった。残った者は船を降りられないまま、少しずつ船の一部になった（説明はここまで。死体・腐敗は見せない） |
| 船長は何を望んでいるか | **「全員で帰る」**。点呼で二十人がそろったら港へ向かう、と誓った。小舟で出た五人が戻らないので、数は永遠にそろわない。灯は、戻らない五人のために毎晩点される |
| なぜ主人公たちは帰れなくなったか | 船に乗った者は、船長の点呼に**乗員として数えられる**。空いた席を埋める者として、船が二人を降ろさない |
| なぜ船内の空間が変化するのか | 錨が船長の誓い「誰も降ろさない」を叶え続けている。**外へ向かう通路を、船が内側へ繋ぎ直す**。だから出口を目指すほど奥へ戻される |
| なぜボスを倒すと異常が解消されるか | 船を留めているのは、船長が握り続けている**錨の鎖**。船長が倒れて鎖から手を離すと、錨は海の底へ落ち、船はもう何も留めない。通路は元に戻り、閉ざされていた甲板への昇降口が開く |
| なぜ甲板へ戻れるのか | 船底の穴は船に塞がれ（船の一部になった）、錨が抜けた後は浸水で沈む。代わりに、ずっと上から押さえられていた**甲板への昇降口**が開く。甲板から、係留した小舟へ縄で降りる |

**説明しないこと**: 錨の正体と出所（瓶の手紙が地下水路を指すのは既存のまま）、霧そのものの原因、第一章を通す「ずれ」の原因。
**ゲーム内で言葉にしないこと**: 上の表の「錨が誓いを叶える」は設計上の因果で、**台詞・手記にはしない**。プレイヤーには「船長の誓い（日誌）」「外へ向かうと内へ戻る（魔法使い）」「鎖を離すと元に戻る（撃破）」の三つを並べて見せ、繋がりは推測に任せる（CHAPTER1_STORY §1「怪異の正体を断定しない」）。

### 2-1. 比較した案

| 案 | 内容 | 評価 |
| --- | --- | --- |
| **A（推奨）誰も降ろさない誓い** | 船長の誓い × 錨。外へ向かう道が内へ繋ぎ直される | 船長・乗組員・空間・ボス撃破の因果が一本で繋がる。「帰れない」を体験（出口へ向かうと奥へ戻る）と物語（数がそろわない）の両方で示せる。既存の錨・帰港を望む船長・角灯・「帰る場所」の会話を活かせる |
| B 船そのものが怪物 | 船が意思を持ち、船長も被害者 | ボスを倒しても船が残るので、撃破で解ける理由が弱い。ボスが「船」になると既存の船長の見た目・名前を捨てる |
| C 乗組員の未練の集合 | 帰りたい乗組員全員の思いが船を縛る。ボスは乗組員の集合体 | 宵待ちの村のボス（村の残響 = 重なった人の影）と型が重なる |
| D 現行の維持（近道の錨） | 「近道になると思って錨を引き上げた」 | 「近道」は塔の鐘と組で意味を持っていた。単独では空間変化の理由にならない |

### 2-2. 第一章の「ずれ」の連鎖（§2 の表）との関係

| 段 | 現行 | 新設計 |
| --- | --- | --- |
| 幽霊船 | 帰るはずの時から進めない船（港を見失ったまま霧を漂う） | **帰り道が、内側へずれる船**（外へ向かう通路が、船の奥へ繋がる） |

洋館（影が遅れる）・村（記憶が遅れる）と並べて見せるだけで、台詞では説明しない。原因は第一章で明かさない。

## 3. 人物（この章での役割）

| 人物 | 性格（既存） | この章での役割 | 到達点 |
| --- | --- | --- | --- |
| 弓師（主人公） | 丁寧で落ち着いた口調。「現在」を見る。帰る場所が無い（「私は、どこにも」） | 目印を付け、変化に最初に気づく人。船長に「ここにいればいい」と誘われる側 | 「帰る場所はまだ無い。でも、ここではない」→ 酒場で「……ただいま、戻りました」 |
| 魔法使い（支援） | 丁寧語。観察して考える。決めつけない（村で「見てから決める」） | 規則に気づき、言葉にする人（「外に向かうと、内側へ戻されます」）。船長の誓いに自分を重ねる | 「分かっているつもりで、決めてしまったんですね。……少し、覚えがあります」（既存の行を、船長の過去を知る場面へ） |
| 帰港を望む船長 | ― | 「全員で帰る」と誓い、誰も降ろさなくなった人 | 点呼の数が合わないと認め、鎖から手を離す |
| 甲板長（ミニボス） | ― | 船長の命令「誰も降ろすな」を守り続ける人 | 倒れると号笛が残る |

会話の口調は DEC-016 の基準（弓師・魔法使いとも丁寧語、短く、説明しない）。DEC-010 に従い、**怪異の正体は説明しないが、状況・人物の意図・次の行動は具体的に伝える**。

## 4. 物語の流れ（14 段）

各段: **見る** / **知る** / **疑う** / **感情** / **次へ進む動機**。台詞は意味の基準（実装時に言い回しを整えてよいが、意味は変えない）。

### ① 酒場で幽霊船の情報を得る（村クリア後の交代の会話＋出撃会話）

- 見る: 戻った魔法使い、交代で前に出る弓師
- 知る: 沖の霧の中に、毎晩灯が点る船がいる。乗っている人はいないはず。沈没船の錨を積んでいたという噂
- 疑う: 誰が灯を点けているのか
- 感情: 静かな好奇心
- 動機: 魔法使い「今度は、最初から見ておきたい」。依頼主はいない（既存の方針）

交代の会話（既存の4行の後。現行の弓師の行を差し替え）:
- 弓師「沖の霧の中に、毎晩、灯が点るんです。乗っている人は、いないのに」
- 魔法使い「……確かめに行きます。今度は、最初から見ておきたいので」（既存）
- 剣士（酒場に残る）「見てから決めろ。……あの村で、そうしただろう」（既存）

出撃会話（主人の行だけ直す。弓師の行は DEC-016 のまま）:
- 主人「幽霊船か。正気の沙汰とも思えんが……」
- 弓師「……詳しく、聞かせてください。」
- 主人「**霧の港の沖に、朽ちた帆船が流れ着いたそうだ。**沈没船から引き上げた"錨"を積んでいたらしくてな。」（「打ち上げられた」を直す）
- 弓師「錨ひとつで、そこまで朽ちるものでしょうか。」
- 主人「ただの錨じゃない、という話でな。死者をこの世に縛りつける錨だとか。今も甲板を彷徨う亡霊がいるとか。」
- 弓師「……まだ、船に乗っているんでしょうか。」
- 主人「……さあな。海の男でさえ近寄らん場所さ。**それでも行くなら、小舟を貸してやる。帰りに沈めるなよ。**」（既存の最後の行を置き換える。行数は変えない。小舟の出所）
- 弓師（締め）「では、行ってきます。」（DEC-016）

### ② 小舟で幽霊船へ接近する（導入の演出）

- 見る: 霧の海。オールの音。黒い船体が霧から迫り上がる。船尾にひとつだけ角灯。手すりに、海のほうを向いて立つ人影（近づくと、霧と一緒に消える）
- 知る: 船は大きい。人の気配がある。縄梯子は無い。喫水線の近くに穴
- 疑う: 灯を点けたのは誰か。上から入れないのはなぜか
- 感情: 畏怖。見上げる小ささ
- 動機: 穴から入るしかない

会話:
- 魔法使い「……灯が、点いています」
- 弓師「手すりに、誰か。……海のほうを見ていました」
- 魔法使い「縄梯子が、ありませんね」
- 弓師「下に、穴があります。……あそこから」

### ③ 船体に係留し、船底の穴から侵入する

- 見る: 弓師が小舟の綱を船腹の折れた肋材に結ぶ。穴の縁の板が**外側へ**折れている
- 知る: 穴は外からではなく、中から破られた
- 疑う: 誰が、何から出ようとしたのか
- 感情: 小さな寒気
- 動機: 中を見る。帰り道は「この穴」と覚えて入る

会話:
- 弓師「舟は、ここに。……帰りに、すぐ乗れるように」
- 魔法使い「板が、外に向かって折れています」
- 弓師「中から、破ったんですね」
（理由は言わない。答えは⑨の甲板長の手帳と⑩で分かる）

HUD の目標: 「船内を調べる」

### ④ 船内を探索する（船底 → 船倉 → 船員室）

- 見る: 足首までの水。船倉を縦に貫く**太い錨の鎖**。揺れているハンモック（風は無い）。寝台の木彫りの小物、書きかけの手紙
- 知る: 生活が途中で止まっている。乗組員は大勢いた
- 疑う: 皆、どこへ行ったのか
- 感情: 静けさの不気味さ
- 動機: 奥を見る

弓師の行動（帰り道の目印）: 曲がり角で、弓師が柱に**矢じりで小さな矢印**を刻む（3か所。演出で自動に刻む）。
- 弓師「念のため、帰り道に印を」
- 魔法使い「……几帳面ですね」
- 弓師「迷うのは、得意じゃないので」

船員室:
- 魔法使い「ハンモックが、揺れています。……風は、無いのに」
- 弓師「さっきまで、誰か寝ていたみたいに」

点呼板（調べる）: 札を掛ける穴が二十。名前の札が十五本、すべて「在船」の側に掛かっている。札の無い穴が五つ。
- 弓師「十五人、乗っていることになっています。……誰も、いないのに」
- 魔法使い「空いている五つは、降りた人の分でしょうか」

最初の戦闘（船倉）: 水夫の残影。**船内で最初の異常に気づく場面**:
- 弓師「……人、でしょうか」
- 魔法使い「人の、形をしたものです。持ち場から、離れません」

### ⑤ 乗組員の生活や船の過去を知る（食堂・航海士の私室）

- 見る: 長い食卓に十五人分の皿。皿は空で、杯だけが満ちている（海水）。どこかで食器が触れ合う音
- 知る: この船の人たちには帰る場所があった
- 疑う: なぜ降りなかったのか
- 感情: 哀しさ。弓師にとっての羨ましさ
- 動機: 船長室で、何があったかを確かめる

既存の会話（**そのまま残す**。食堂の戦闘の後）:
- 魔法使い「この船の人たちは、帰る場所があったんですね」
- 弓師「ええ。だから、降りられないんだと思います」
- 魔法使い「……あなたは?」
- 弓師「私は、どこにも。……だから、少しだけ羨ましい」

航海士の私室（寄り道）: 既存の手紙「もし故郷に戻れることがあれば、二度と海には出ないと誓おう」。

### ⑥ 帰還を試みる（船長室）

- 見る: 片付いた船長室。誰もいない。机の航海日誌。天井の**甲板への昇降口**は開かない（上から押さえられているように重い）。頭上を、ゆっくり歩く足音
- 知る（日誌の前半）: 霧で港を見失った／流されないよう、沈んだ船の錨を繋いだ／毎晩、点呼をとる
- 疑う: 頭上の足音は誰か。今夜の点呼とは
- 感情: 区切り。少しの安堵
- 動機: **見るだけの約束だった。舟へ戻る**

会話:
- 弓師「……誰も、いませんね」
- 魔法使い「今日は、ここまでにしましょう。見るだけ、の約束でした」
- 弓師「ええ。舟に戻りましょう。印は、付けてあります」

HUD の目標: 「船底の穴から、小舟へ戻る」

### ⑦ 帰還不能に気づく（帰還不能イベント）

マップの詳細は `-map-design.md` §3。体験は「違和感 → 確信 → 恐怖 → 理解」の4段。

**7-a 違和感（通路）**: 中央通路の「食堂」の扉が、船員室に開く。
- 弓師「……ここ、船員室でしたか?」
- 魔法使い「食堂の、はずです」
- 弓師「……来た道を、間違えたのかもしれません」（まだ自分を疑う）

**7-b 確信（同じ通路が別の場所へ）**: 船員室から船倉へ降りる梯子が、**食堂**へ出る。食卓の皿が**十七人分**に増えている。新しい二つの杯が、満ちている。環境音が止まる。
- 弓師「……席が、増えています」
- 魔法使い「二つ」
- 弓師「……私たちの分、でしょうか」

**7-c 恐怖（目印が動く）**: 食堂の扉の柱に、弓師が船倉で刻んだ矢印がある。向きは**船の奥**を指している。
- 弓師「この印……船倉の柱に、私が付けたものです」
- 魔法使い「私たちが迷ったんじゃない。……船のほうが、動いたんです」

**7-d 理解（出口が無い）**: 船底へ辿り着く。穴があった場所は、**新しい板で内側から打ち付けられている**。釘はまだ光っている。入った瞬間、どこかで鳴っていた槌の音が止む。板の隙間から、波に揺れる小舟と、結んだ綱が見える。→ 船大工の残影（強敵）との戦闘。
- 弓師「舟は、まだあります」
- 魔法使い「……でも、塞いだのは、中からです」
戦闘の後、弓師が板を射る。矢は刺さるだけで、板はもう「船体」になっている。

### ⑧ 空間の変化を体験する（一度だけのループと規則）

- 見る: 船底から上へ戻る梯子が、**同じ船底の反対側**へ出る（一度だけ）
- 知る: 外へ向かうほど、内へ戻される。**錨の鎖だけは、どの部屋でも同じ向きに通っている**
- 疑う: 鎖の先に何があるのか
- 感情: 迷子の恐怖 → 手掛かりを掴む安堵
- 動機: 鎖を辿って、奥へ

会話（同じ通路が別の場所につながった場面）:
- 弓師「……戻ってきました。同じ場所に」
- 魔法使い「外に向かうと、内側へ戻されます。……たぶん、何度やっても」
- 弓師「なら、奥へ」
- 魔法使い「鎖を辿りましょう。あれだけは、ずっと同じところを通っています」

HUD の目標: 「錨の鎖を辿って、船の奥へ」
以後、プレイヤーは**鎖を目印に一本道を進む**。迷い続ける構造にはしない（`-map-design.md` §4）。

### ⑨ 船内の奥へ進み、異常の原因を探る（変わった船・点呼の廊下）

- 見る: 見覚えのある部屋が、少し違う姿で続く（船倉……?・船員室……?）。ハンモックが全部、人の重さで沈んでいる。存在しないはずの長い廊下に、乗組員の影が二列に並び、通る二人のほうへ首だけを向ける（害は無い）
- 知る: **点呼**。甲板長（ミニボス）が号笛を吹き、「持ち場に戻れ」と迫る
- 疑う: 誰の命令か
- 感情: 圧迫感
- 動機: 甲板長の先、鎖の先へ

甲板長の前:
- 甲板長「……点呼。……二名、持ち場に、つけ」
- 弓師「私たちは、この船の者ではありません」
- 甲板長「船長の、ご命令だ。……誰も、降ろすな」

撃破後: 号笛が床に残る。甲板長の手帳（調べる）:
- 「船長のご命令。全員そろうまで、誰も降ろすな」
- 「三日目。数名が穴を破って出ようとした。船大工に塞がせた」
- 「空いた札が五つ。……数は、まだそろわない」
（③の「中から破られた穴」と⑦-d の「塞いだ板」が、ここで一つに繋がる）

点呼板（廊下の終わり）: 空いていた五つの穴のうち二つに、**名前の無い札が二本**、「在船」の側に掛かっている。空きは三つ。
- 魔法使い「名前の無い札が、二つ」
- 弓師「……数えられて、いるんですね。私たちも」

### ⑩ 船長・乗組員の過去と目的を知る（船長室……?）

- 見る: 膝まで浸水した船長室。もう一つの船長室。壁に刻まれた一行「全員で帰る」。角灯を掛ける鉤だけが空
- 知る（日誌の後半）: 陸を探しに小舟で出た者たちが戻らなかった／もう誰も降ろさない、全員で帰る、と誓った／毎晩、灯を点け、点呼をとる。数は合わない
- 疑う: もう答えは出ている
- 感情: 怒りではなく、哀れみ
- 動機: 船長に会い、鎖を離させる

日誌（手記・3行ずつ。読まなくても本筋は分かる）:
- 「霧で港を見失った。流されぬよう、沈んだ船の錨を繋いだ。霧が晴れるまで、ここで待つ」
- 「陸を探しに、五人が小舟で出た。戻らない。……もう誰も、降ろさない。全員で帰る」
- 「今夜も灯を点け、点呼をとる。数が、合わない。合うまで、この船は港へ向かわない」

**船長の過去を知る場面**の会話:
- 弓師「……全員で、帰りたかったんですね」
- 魔法使い「分かっているつもりで、決めてしまったんですね。……少し、覚えがあります」（既存の行）

### ⑪ ボスと対峙する（錨の間）

前室: 鎖が床の穴へ降りていく。船長帽の影が身じろぎもせず立ち、近づくと消える（既存の演出を移す）。

**ボスとの対峙前**:
- 魔法使い「この先です。鎖が、全部ここへ」
- 弓師「……行きます。帰るために」

ボス（第一章の台詞。戦闘の前）:
- 船長「……灯を見て来たか。よく来た。新しい乗員よ」
- 船長「帰る場所が無いのなら、ここにいればいい。食卓も、寝台もある」
- 弓師「……帰る場所は、まだありません。でも、ここではありません」
- 船長「ならば、持ち場につくまで、引き留めるまでだ」

戦闘中の台詞（フェーズ移行。短く）: 「総員、点呼!」（第2段）／「離さん……この鎖だけは!」（第3段）。戦闘は `-enemy-boss-design.md` §4。

### ⑫ ボス撃破後、異常が解消される

- 見る: 船長が膝をつく。手から鎖が滑る。鎖が唸りを上げて床の穴へ走り、**錨が海の底へ落ちていく**（長い水音）。船の軋みが、重い呻きから軽い波の音に変わる。天井の昇降口から、白い光が落ちる
- 知る: 船を留めていたのは、船長の手だった
- 感情: 解放。静寂
- 動機: 上へ

**ボス撃破後**の会話（結果画面の後）:
- 船長「……数が、合わんな。お前たちは、乗員では、なかったか」
- 船長「……降りて、いい。皆も、もう……」
- 魔法使い「……軋みが、変わりました」
- 弓師「上が、開いています」

### ⑬ 甲板へ戻り、脱出する

- 見る: 初めて立つ甲板。霧が薄れ、遠くに陸の影。手すりに並んだ乗組員の影が、ひとりずつ陸のほうを向き、薄れて消える。冒頭に小舟から見た人影も、今は陸を見ている。船尾の角灯だけが残っている。舷側の下、結んだままの小舟
- 知る: 皆、帰っていく（どこへ、とは言わない）
- 感情: 静かな哀しみと、帰れることの安堵
- 動機: 小舟へ降りる

**甲板へ戻った場面**の会話:
- 魔法使い「……陸が、見えます」
- 弓師「あの人たちにも、見えているといいんですが」
- 弓師が船尾の角灯を外す。「……もう、点けなくていいですね」
- 魔法使い「持って帰りましょう。……誰かが、待っていた灯ですから」
甲板の端に縄梯子。降りると暗転。

### ⑭ 酒場へ帰還し、シナリオを締めくくる

- 見る: 酒場の明かり。主人。棚の端に、持ち帰った船の角灯（既存の小物）
- 知る: 弓師にも戻る場所があった
- 感情: 温かさ
- 動機: （次の段へ。§9 の接続は Human 判断）

**酒場へ帰還した場面**（帰還の会話。DEC-006 の作法。交代の会話の前）:

## 5. 「帰れない」を体験させる仕組み

| 層 | 仕組み |
| --- | --- |
| 予告 | 小舟の綱を結ぶ（「帰りに、すぐ乗れるように」）。弓師が帰り道に印を刻む。プレイヤー自身にも「帰り道」を意識させる |
| 区切り | 船長室で「今日はここまで」。HUD の目標が「小舟へ戻る」に変わる ―― プレイヤーが**自分の意思で帰ろうとする** |
| 違和感 → 確信 → 恐怖 → 理解 | 扉の先が違う → 梯子の先が違う＋席が増える → 自分の付けた印が動いている → 穴が内側から塞がれている |
| 規則の学習 | 一度だけのループで「外へ向かうと内へ戻る」を体で知る。魔法使いが言葉にする。**錨の鎖**という動かない目印を渡す |
| 物語の理由 | 点呼板（二十の穴・十五本の札・五つの空き）に、名前の無い札が二本増える。船長の誓い「誰も降ろさない」 |
| 戦闘 | ボスの「鎖の引き寄せ」は、距離を取る弓師を引き戻す ―― 戦闘でも「離れられない」 |
| 解放 | 鎖が落ちる音、軋みの変化、昇降口の光、甲板の陸影。酒場で「ただいま」 |

## 6. ビジュアル・環境演出

基本方針: **静けさ・残された物・音・空間の違和感で怖がらせる。** 死体・骨・腐敗・流血は出さない（村の敵の方針 CH1-COMP-W3-GHOST と同じ）。

| 対象 | 設計 |
| --- | --- |
| 船体外観 | 霧の中に黒い壁のように立つ。帆は破れ、マストの先は霧に消える。船尾に角灯ひとつ（暖色の小さな点。船内の冷たい青との対比） |
| 船底の侵入口 | 喫水線のすぐ上、外へ折れた板の穴。中は暗く、水面が角灯の光を返す |
| 船内の照明 | 往路は角灯の暖色が点々と残る（人が住んでいた温度）。帰還不能の後は、同じ部屋でも灯が**冷たい青**に変わり、弱くなる（洋館の段階の照明と同じ作法: 正常 → 痕跡 → 歪み → 異常） |
| 水漏れ・浸水 | 船底は足首、船長室……? は膝。浸水は深部ほど深い（往路の船長室は乾いている → 後半の船長室……? は浸水、で「同じ部屋の別の姿」を示す） |
| 朽ちた木材・金属 | 黒ずんだ板と錆びた金具。ただし生活の物（食器・ハンモック・木彫り・手紙）は**きれいなまま**残す ―― 時間が止まっている違和感 |
| 生活痕跡 | 十五人分の食卓、点呼板、揺れるハンモック、書きかけの手紙、干したままの衣類 |
| 霧 | 外は濃い霧（既存のワールドの霧）。船内は薄い霧が床を這う。帰還不能の後は霧が少し濃くなる |
| 水面・反射 | 船底・錨の間の水面に灯が映る。錨の間では鎖が黒い水へ消えていく |
| 影・残像 | 敵は「乗組員の残影」（透ける裾・マットな色・役割の道具）。害の無い影（点呼の廊下の列、手すりの影）は `spawnApparition` |
| 空間変化の演出 | 扉を開けた瞬間は**何も起きない**（音もしない）。気づくのはプレイヤー。確信の場面だけ環境音を止める（`ambienceHold`）。画面の揺れ・閃光は使わない |
| 敵出現 | 持ち場（食卓の席、寝台、見張りの位置）から「起き上がる」。床の霧が一度だけ渦を巻く |
| ボス部屋 | 円に近い浸水した部屋。中央の床穴へ鎖が降りる。壁際に乗組員の影が並んで見ている（戦闘には加わらない）。船長の角灯が唯一の暖色 |
| 撃破後 | 鎖が走る → 水音 → 静寂 → 昇降口の白い光。甲板では霧が薄れ、陸の影。影が一人ずつ陸を向いて消える |

既存の見た目との整合: 船内の配色（暗い紫灰の壁 0x201a24 系、青い霧の灯 0x6fa8d8 系）を引き継ぐ。主人公・支援の姿は変えない。

## 7. 音響・BGM

### 7-1. 場面ごとの設計

| 場面 | 音 |
| --- | --- |
| 接近（小舟） | 波、オールの水音、遠い船体の軋み。BGM は鳴らさないか、ごく薄く |
| 船内（往路） | 低い軋み（`houseCreak`）、水滴（`waterDrip`）、床板（`floorTick`）を十数秒〜数十秒の間隔で。BGM は既存の低いドローン |
| 遠い物音 | 往路のうちから、ときどき**槌の音**（船大工。⑦-d の伏線）と、頭上の足音（`distantStir`） |
| 帰還不能（確信） | 食堂で環境音が**途切れる**（`ambienceHold`）。食器の触れ合う音だけが一度鳴る |
| 帰還不能の後 | 環境音の区画を切り替える。軋みの間隔を短く、水滴を増やし、槌の音は止める |
| 空間変化 | 効果音で強調しない。扉の音はいつもと同じ（気づかせるのは目） |
| 戦闘 | 既存の打撃・幽霊の材質音（`ghost`）。甲板長の号笛、ボスの鎖の擦れる音 |
| ボス戦 | 幽霊船の BGM の強い変奏（低音を厚く、遅い拍）。第3段で拍を止め、鎖の音だけにする |
| 撃破後 | 鎖が走る音 → 長い水音 → **完全な無音（2〜3 秒）** → 小さな波の音 |
| 甲板 | 風、波、遠い海鳥。BGM は無し、または短い長調の余韻 |

### 7-2. 実現性の区分

| 区分 | 内容 |
| --- | --- |
| 今の仕組みでできる | 環境音の区画（`AMBIENCE_ZONES` に幽霊船の区画を足す。cue は `houseCreak` / `waterDrip` / `floorTick` / `distantStir` / `caveBreath` を流用）、`ambienceHold` による途切れ、区画の無音、既存の効果音（扉・`chime`・材質音）、BGM の手続き生成の調整 |
| 小さな追加でできる | 手続き生成の短い効果音（波・槌・食器・号笛・鎖・長い水音。`audio.js` の環境音と同じ作り方）、幽霊船の BGM の変奏（`playBgm(key, variant)` は酒場で変奏を使っている。手続き生成側の変奏の有無は実装時に確かめる） |
| 将来の候補 | 実音源の BGM（`asset-manifest.js` の `ghostship: null`。作曲アプリで Human が承認してから。NEXT-DEV-PLAN の HD-C） |
| 推奨の調整 | 既存の幽霊船 BGM の `bell:true`（遠い鐘）を別の音色に替える。第一章では「鐘」= 時計塔と結びつくため（任意。Work Item W9） |

## 8. 時計塔の要素を外した後の整合

- 幽霊船の内側（船内の台詞・手記・ボス・撃破後）は、時計塔の要素を**一つも持たない**（§3-1 の表をすべて外す）。
- 宵待ちの村 → 幽霊船の動機は変わらない（魔法使い「最初から見ておきたい」）。弓師の噂の中身だけ「鐘」から「灯」に変える。
- 幽霊船 → 時計塔の接続は §9。

## 9. 時計塔への接続（Human 判断が要る。時計塔の中身は変えない）

現行の §4-3 は「三つの事実」（①船の時計と塔の鐘が同じ時刻 ②船長の頼み ③管理人が七日戻らない）で塔へ向かう。①②が無くなる。

| 案 | 内容 | 変える行 |
| --- | --- | --- |
| **A（推奨）** | ③（既存）だけを理由にする。弓師は船で「待っている人がいる」ことの重さを知った。塔の管理人を待つ娘（または家族）の話を聞き、「待っている人がいるなら、帰してあげたい」と引き受ける。**弓師の到達点は「初めて何かに関わる」のまま**、理由が船長の頼みから船での体験に変わる | 酒場の帰還の弓師の1行（④で「ただいま、戻りました」に置き換え済み）、時計塔への出発の会話の主人1行・弓師1行（例: 主人「塔の管理人が、七日戻らないそうだ」弓師「……待っている人が、いるんですね」）。時計塔の中身・盗賊の行は変えない |
| B | 幽霊船と時計塔の接続を持たない。酒場の主人の噂だけで塔へ向かう | 弓師の出発の1行を削る。弓師の動機が薄くなる |
| C | 現行のまま（船と塔の繋がりを残す） | 今回の Goal と矛盾するため不可 |

推奨は A。理由: 時計塔の内容（鐘・七時十三分・管理人・娘）は時計塔の中で完結しており、接続の2行を差し替えるだけで済む。「帰れない船」から「待っている人がいる塔」へ、弓師の気持ちの流れが自然に続く。
**この差し替えは `docs/CHAPTER1_STORY.md` §4-3・§5・§6（N-1 / N-5 の取り下げ）と DEC-004 の改訂を伴うため、Human の承認が要る**（レビュー E-1）。
