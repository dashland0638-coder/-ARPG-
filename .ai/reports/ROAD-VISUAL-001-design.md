# ROAD-VISUAL-001 — 道（名もなき街道）の改良設計（Planner）

基準: `origin/main` @ `0fc4572`。調査は `ROAD-VISUAL-001-analysis.md`。**この文書は設計案であり、実装・仕様の確定ではない**（Human の承認後に別 Work Item で実装計画を確定する）。

## 1. コンセプト
**「歩くほど、世界が開けていく朝の街道」**
- 入口は木立に囲まれた狭い朝の道 → 道標で「来た道」を振り返り → 小川で光と水 → 休憩所は木陰の小さな舞台 → 戦闘2の先で木立が切れ → 丘で遠くまで続く道が見える
- 明るさは保ちつつ、**白っぽさを抑えて色と陰影の差**を作る（朝の斜めの光・木陰・水のきらめき）
- 物語の要素（橋の人影・休憩所・遅れる影）は**見せ場として目に入るように**するが、ホラーにはしない
- 地形・導線・イベントの帯・敵の位置・会話は**変えない**。足すのは「見た目の物」「光と色」「小さな動き」「描画の工夫」だけ

## 2. 現状と改良後（推奨案 B）
| 地点 | 現状 | 改良後 |
| --- | --- | --- |
| 入口〜道標 | 平らな草地と石畳だけが画面に入る | 道の両脇（歩ける範囲の内側、石垣の手前 x ±6〜13）に**低い茂み・草むら・野花**（当たり判定なし・膝より低い）。木は石垣のすぐ外（x ±14.5〜17）へ寄せ、**枝葉が画面の端に掛かる**。入口は木陰が濃い |
| 道標 | 柱と腕 4 本 | 根元に苔むした石・踏み固められた土・小さな花。腕の文字の焼き跡（板の色の差）。古さの表現。**位置・手記・会話は同じ** |
| 戦闘1 | 平地 | 変えない（戦う場所は開けたまま。茂みは道から離す） |
| 小川・橋 | 平らな青い帯 | 岸の土と石・水際の草・**水面の小さなきらめき**（テクスチャのオフセットを動かすだけ、1 枚）。橋の板の色むら・苔。橋の人影・持ち主のいない影は同じ |
| 休憩所 | 近づくまで画面に入らない | 休憩所の上に**一本の大きな木**（遠くから樹冠が見える目印。木陰が長椅子に落ちる）。長椅子の脇に旅人の荷（袋・水筒）。井戸に桶。**出会いの位置・帯は同じ** |
| 加入前の影 | 紫の円 0.85、明るい草地で薄い | 木陰の手前に置かれる長椅子の位置はそのまま、影だまりを**やや大きく・濃く（0.55 → 0.7）、輪郭をぼかした円**にする。遅れの秒数（0.45）は変えない。露骨な演出にしない |
| 戦闘2〜丘 | 平地 | z 92 から先で**木立が切れ、草丈が低くなる**（視界が開ける）。道の両脇に里程石 |

| 空・光 | 露出 0.96・淡い | 露出を少し下げ（例 0.90）、太陽を低め・暖色寄りにして**長い影**、半球光の地面色を緑寄りに（白飛びを抑える）。`WORLD_MOOD.road` の数値だけ |
| 描画 | バッチなし（330〜360 回） | 木・石垣・柱・茂みを**静的バッチ / InstancedMesh** に。描画回数を**今以下**にしたうえで物を足す |

## 3. 色調・素材・照明
- 色調: 朝の「若草・土・古木・灰色の石・水色」。白っぽさを避け、彩度を少し上げる。影は青みの灰
- 素材: 既存のテクスチャ生成（`makeGrassTexture` / `makeCobbleTexture` / `makePlankTexture` / `makeStoneTileTexture`）の色と繰り返しの調整で作る。**新しい画像アセットは足さない**
- 照明: `WORLD_MOOD.road` の太陽の向き・強さ・露出・半球光の色。**点光源は足さない**（`sunFill` は残すか外すかを実機で判断）

## 4. 環境演出（軽いものだけ）
| 演出 | 方法 | 負荷 |
| --- | --- | --- |
| 草・茂みのそよぎ | InstancedMesh の頂点シェーダで揺らすか、数個の大きな塊を回転で揺らす | 小（インスタンス 1〜2 回の描画） |
| 水面のきらめき | 水のテクスチャの offset を毎フレーム動かす | ほぼ無し |
| 木漏れ日 | 地面に淡い光の斑（半透明の平面 数枚、静的） | 小 |
| 舞う葉・花びら | 入れない（常時動く物を増やさない）。案 C で検討 | ― |

## 5. iPhone 負荷対策
- 今の描画回数（330〜360）を**上限**とし、足す物はバッチ / InstancedMesh で吸収する（木 30 本＋石垣 90 個が今は個別の描画）
- 半透明は水面と木漏れ日だけ。影を落とすのは木と休憩所だけ（茂み・草は落とさない）
- 歩ける範囲の外の物（遠景の斜面・山並み）は面数の少ない形と霧で
- 計測: 改良前後で同じ地点の描画回数・三角形・FPS（E2E で数値を出す）

## 6. 案の比較
| | A 最小限 | **B 標準（推奨）** | C 演出重視 |
| --- | --- | --- | --- |
| 内容 | 光と色の調整・道の脇の茂み・休憩所の木・影だまりの調整 | A ＋ 景色の段階（木立 → 開ける）・小川の岸と水のきらめき・丘の先の斜面と遠景・バッチ化・軽いそよぎ・丘のカメラの一場面 | B ＋ 丘を実際に高くする（歩ける面の坂）・舞う花びら・時間の経過で光が変わる・橋の人影の場面に霧 |
| 物語との整合 | 高い | 高い（帯・会話・順番は同じ） | 中（坂で丘の会話の位置・帯の高さに触れる。光の変化は「明るい朝」の印象を変えうる） |
| 探索体験 | 少し良くなる | 歩く理由（景色が開ける）ができる | 良い |
| 視覚的な魅力 | 小 | 中〜大 | 大 |
| iPhone 負荷 | 変わらない | 描画回数は今以下（バッチで相殺） | 増える（常時動く粒・坂の当たり） |
| 実装コスト | 小（1 PR） | 中（2〜3 PR） | 大 |
| 既存仕様への影響 | なし | なし（地形の当たり・イベント・敵に触れない） | あり（地形・高さ・カメラ） |
| テストの難易度 | 低 | 中（撮影比較・描画回数の E2E） | 高 |

**推奨: B**。理由: 物語・導線・敵・セーブに触れずに、P-1〜P-8 の大半（単調な画面・景色の段階・丘の余韻・休憩所の目印・影の読みやすさ・描画回数）に答えられる。描画の工夫で iPhone の負荷を増やさない。C の坂と光の変化は仕様（地形・印象）に触れるので、B の後に Human が必要と判断した時だけ。
