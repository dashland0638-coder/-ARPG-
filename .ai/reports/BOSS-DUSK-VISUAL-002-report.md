## 1. 怪異性の強化

「複数の人の記憶が、別々の時間のまま一つの体に重なっている」を、形より**動きの時間のずれ**で見せる。目・光る部品・飾りは足していない。

- **暮らしの姿勢**: 重なる人影 2 枚は、それぞれ別の暮らしの姿勢をとる。1 枚は振り返って誰かを待ち、もう 1 枚はうつむいて手元の仕事をする。頭の向きは形に焼き込んだ。
- **別の時間の腕**: 人影は腕を持ち、本体の腕を遅れてなぞる（0.14 秒・0.26 秒）。そのため、一瞬だけ複数の姿勢が同時に見える。
- **とびとびの追従**: 待機・移動の間、人影は滑らかに動かず、それぞれの間隔（0.16 / 0.23 秒）でとびとびに追いつく。止まった記憶が遅れて進む見え方にした。
- **水へ戻りかける体**: 7.1 秒ごとに、体が水面へ沈みかけて戻る。
- **人と違う動き**:
  - 浮き沈みは周期の違う 2 つの揺れの重ね合わせ。
  - 肘が時々、人の関節では曲がらない向きへ反る。
  - 首の傾き・跳ねは PR #111 のまま。

## 2. 攻撃予兆

1. 振りかぶりの前半: 人影の腕が本体の腕より遅れてついてくる（ばらばらの高さ）。
2. 進み具合 0.4〜0.75: 腕の遅れ・位置のずれ・向きのずれが 0 になり、三つが一つに重なる。最後の 25% は重なったまま（分身の 0.34 秒でも 0.085 秒）。
3. 叩き下ろした後: 人影の腕が遅れて下り、輪郭がほどける。

足元の薔薇色の輪（半径・色・時刻）と、攻撃の時刻・判定・ダメージ・頻度は変えていない（E2E `dusk-enemy-design` の輪の検査が pass）。

## 3. 旋回・移動

- 本体が向きを変えると、人影はしばらく元の向きに残る（世界に対して固定。最大 0.7 rad）。人影ごとの速さ（3.0 / 1.8 /秒）で、とびとびに向き直る。
- 水の裾と垂れ布（体の下側）は上側より遅れて向きを変える。
- 本体・帽子・目は常に正しい向きを示す。振りかぶりの間は向きのずれも 0 にするので、攻撃の方向が分からなくなることはない。

## 4. 夜の見え方

- **胴**: 自発光の色を配色の暗い水の色に、強さを 0.12 → 0.5 にした。濡れた影のような暗い青灰に見え、真っ黒な塊ではなくなる。汎用の処理が下げる場面（突進の後・撤退・やり直し）でも、特殊行動の外では既定に戻す。
- **輪郭**: 人影の腕と、向きの違う頭が加わり、重なりの輪郭が読める。
- **水面との境**: 足元の霧の筒をやめ、水の裾を下ほど薄くした。
- **透ける面の殻**: 透ける面（水の裾、段階 3 の胴など）には輪郭線の殻を付けない。殻が透けた奥で、クリーム色の笠や柱に見えていた（レビュー Round 1 M1）。
- **色**: 新しい色は足していない。

## 5. 段階 3 の中心演出

既存の演出（記憶の灯り・中心の輪郭、`06-player-enemy.js`）の位置・形・色は変えていない。段階 3 になった時に次を行う:

- 胴の材質（頭・上腕も共有）と前掛けを不透明度 0.3 に透かし、それらの殻を外す。
- 水の裾を 0.86 → 0.5 にし、奥行きを書かない。
- 重なる人影を 1.25 倍に広げる。

これで、腰の高さの中心の輪郭が透けて見える（`3-phase3.jpg`）。撤退などで段階 1 に戻ったら元に戻す。
