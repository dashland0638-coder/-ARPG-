# MUSIC-BGM-REGRESSION-001 — 酒場 BGM の段階切り替えの重なり・タイトル復帰時に止まらない（報告）

基準: `main` `bdccbc1`（PR #107 の merge）。branch `claude/bgm-regression-001`。Work Item: [`../tasks/MUSIC-BGM-REGRESSION-001.md`](../tasks/MUSIC-BGM-REGRESSION-001.md)、決定: [DEC-015](../decisions/DEC-015-bgm-instances-title-silence.md)。

Status: CONTENT READY = HUMAN DEVICE CHECK REQUIRED

## 1. 原因（Analyzer）

### 不具合 2: タイトルへ戻っても BGM が止まらない（原因を特定）

- `audio.js` に `stopBgm()` はあったが、ゲームのどこからも呼ばれていなかった（`concat-plugin.js` で読み込むだけ）。
- タイトルへ戻る経路は 1 つ: メニューの「タイトルへ戻る」→ `returnToTitle()`（`10-input.js`）。画面と入力は片付けるが、BGM には触れていなかった。
- 起動時のタイトルも、裏で酒場を組む `buildWorld('tavern')` が BGM を鳴らし始めていた（最初のタップで聞こえる）。
- タイトルの間も毎フレームの段階の見直し（`updateTavernBgmStage`）が動き、`setBgmVariant` を呼んでいた。

### 不具合 1: 剣士 → 魔法使いで前の段が残る（仕組みの欠陥を特定。iPhone 固有の引き金は未特定）

| 調べたこと | 結果 |
| --- | --- |
| 段階の判定（`tavernBgmStage`、`scenarioClears` と主人公） | 正しい。会話の間は剣士、閉じた瞬間に魔法使い。行ったり来たりしない |
| 切り替えの呼ばれ方 | 毎フレーム `setBgmVariant` を呼ぶが、同じ段なら何もしない。読み込み中の重複は token で捨てる |
| 実物の流れ（Chromium） | 洋館から戻る → 帰還の会話 → 登場 → 交代の会話を閉じる、をゲームそのもので通した。前の段は 2.05 秒後に止まり、魔法使いの段は同じ位置（25.62 秒）から始まった。**再現しなかった** |
| 前の段を消す仕組み | 予約した 1 回の `stop(when)` だけ。例外は握りつぶしていた。消えたことを確かめる手段も、後から消し直す手段も無かった |

- 予約した停止が行われないと、前の段は出力につながったまま鳴り続け、コードの管理からも外れる（次の切り替えでも消されない）。
  - 行われない例: 停止が効かない・例外になる実装、AudioContext が止まっている・中断されている間に予約した場合。
- 新しい段は、前の段の開始時刻から計算した位置で始まる。前の段の実際の位置とずれていれば、重なりは「ずれて」聞こえる。
- iPhone の Safari で、どの条件で停止が行われなかったかは、この環境では確かめられない。
- **再発防止**: 停止が行われなくても音が残らない形にした（§2）。

## 2. 修正

### `src/audio/audio.js`（BGM の再生インスタンスの管理）

| 項目 | 修正前 | 修正後 |
| --- | --- | --- |
| 音源の持ち方 | `bufferBgm`（今の段）と `fadingBgms`（下がっている段）の 2 か所 | 台帳 `bgmVoices` 1 つ。今の段は `bgmCurrent`。他はフェード中だけ |
| 消し方 | 予約した `stop(when)` 1 回（例外は無視） | `killVoice`: フェードの終わりに停止を予約し、さらにタイマーで音量 0・出力から外す・停止。何度呼んでもよい |
| 続けて替えたとき | 下がっている段が増えうる | 先にフェード中の古い段を消す（0.08 秒）。同時に鳴りうるのは 2 つまで |
| 曲の位置 | 今の段の開始時刻から計算 | 共通の時計（曲の頭の時刻 `bgmClock.origin`）から。6 段階すべて同じ |
| `stopBgm()` | 呼ばれていなかった | クロスフェード中も含め全部を 0.08 秒で下げて消し、読み込み中のものも捨て、状態を空にする。AudioContext・効果音・音量の設定はそのまま |

### ゲーム側

- `returnToTitle()`（`10-input.js`）: タイトルを出すときに `stopBgm()`。
- 起動時（`14-hud-boot.js`）: `initThree()`（酒場を組む）の直後に `stopBgm()`。読み込んだ音はキャッシュに残る。
- 入場は今までどおり `finishEnteringGame` → `buildWorld(world)` → `playBgm`。止めた後なので、その時点の段を頭から鳴らす。
- タイトルの間の毎フレームの見直しは、止めた後は何もしない（BGM の世界が空なので）。

**変えていないもの**: 6 段階の音源・作曲アプリ・段階の決め方（`tavern-bgm.js`）・`asset-manifest.js`・効果音・手続き生成の BGM・セーブ。

**unit `bgm-regression.test.js`**（偽の AudioContext・タイマー。「関数が呼ばれた」ではなく、古い音源が音量 0・出力から外れた・停止したかを見る）

1. 剣士 → 魔法使い: 同じ位置から 2 秒で上がり、前の段は 2 秒で下がって止まり、フェードの後で出力から外れる。
2. 予約した停止が効かない（iPhone の不具合の再現）・2 回目の停止で例外になる実装でも、前の段は出力から外れる。
3. 0.3 秒ごとに 10 回替え、同じ段を毎フレーム頼んでも、同時に鳴りうる音源は 2 つまで。最後は今の段 1 つ。
4. 6 段階を順に進める: 毎回、共通の時計の位置から始まる（1 周をまたぐ位置も）。前の段は外れる。1 段に 1 つ。
5. `stopBgm`: 再生中・クロスフェード中のどちらでも 0.08 秒以内に 0 へ下げ、出力から外す。
   - 2 回呼んでも例外にならない。止めた後は段階の見直しで鳴り出さない。
   - 効果音は鳴り、AudioContext は閉じない。もう一度入ると頭から 1 つ（音量の設定どおり、BGM オフなら 0）。
6. 読み込み中に止めると、読み込みが後から終わっても鳴らない（起動時のタイトル）。
7. 組み込み: `returnToTitle` と起動時に `stopBgm`。入場はワールドを組み直す。AudioContext を閉じない。

**E2E `bgm-regression.spec.js`**（実物のゲーム。AudioContext を包み、音源の停止と GainNode が出力から外れたことを見る）

1. 不具合の流れそのもの。
   - タイトルでは鳴らない → つづきから → 洋館（手続き生成）→ クリアして酒場へ → 帰還の会話 → 登場 → 交代の会話（間は剣士の段だけ）→ 閉じると魔法使いの段が同じ位置から。
   - **クロスフェードの途中**（2 つが鳴っている）でタイトルへ戻る → 全部止まり、出力から外れる。3 秒待っても鳴り出さない。
   - つづきから → 魔法使いの段を頭から 1 つ、音量は設定どおり。2.5 秒後も 1 つ。攻撃の効果音が鳴る。
2. 酒場で鳴っている間に、BGM 音量を「大」にしてタイトルへ戻る → 止まる。タイトルの間は鳴らない。はじめると剣士の段を「大」の音量で 1 つ。

## 4. 実機で確かめること（iPhone）

`docs/CHAPTER1_PLAYTEST.md` の A-01c。

1. 起動してタイトル・キャラクター作成の画面を何度かタップしても、BGM が鳴らない。
2. 洋館をクリアして酒場へ戻り、交代の会話を閉じる。剣士の段から魔法使いの段へ約 2 秒で入れ替わり、前の曲が残って二重に鳴らない・ずれない。
3. メニュー →「タイトルへ戻る」で BGM が止まる。交代の会話を閉じてすぐ（入れ替わりの途中）に戻っても止まる。
4. タイトルから「つづきから」で、その時点の段（魔法使い）が鳴る。「はじめる」なら剣士の段。
5. 効果音・BGM 音量（オフ / 小 / 中 / 大）が今までどおり。
