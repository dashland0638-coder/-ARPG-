## 2. 洋館→酒場接続修正

### 何が起きていたか

```
洋館撃破 → 結果 → returnToTown()
   └ fadeTransition(暗転) の途中で returnToTownNow()
        buildWorld('tavern')
        advanceChapter1Cast() → playChapter1JoinScene()  ← ここで会話を開いていた
   → 暗転が明ける前に「✦ 魔法使いが酒場にいる」と会話が出る(=暗い画面に会話だけ)
   → 会話が終わると、洋館から戻った夜の「鍛冶士との再会」が発火
      → 魔法使いになったプレイヤーが鍛冶屋の前まで歩かされて会話
```

### 直した順序

```
returnToTown() → 酒場のワールド構築 → プレイヤー配置 → HUD
   → 暗転が明け、酒場が実際に数フレーム描かれる
   → 交代の一幕(魔法使いと剣士の短い会話)
   → 操作が戻る(次の出撃先は宵待ちの村だけ)
```

- 交代そのもの（主人公・支援・武器・Skill）は今まで通り `returnToTownNow` で済ませ、
  **会話だけを順番待ちにした**（`queueChapter1JoinScene` → 毎フレーム `updatePendingJoinScene`）
- 「開いてよいか」は `core/chapter1-rules.js` の `joinSceneReady()`（酒場・暗転なし・会話なし・
  数フレーム描かれた）。**時間では待たない** ―― 低FPSでも酒場が見えた次の瞬間に始まる
- 鍛冶士の再会は剣士の場面なので、交代した時点で `smithGreeted = true`（鍛冶士NPCは酒場に残る）。
  酒場を建てた直後に交代が起きるため、再会イベントの発火条件にも `!state.smithGreeted` を足した
- 交代の会話の種類を `'town'` から `'chapter1Join'` へ（`'town'` は会話の終わりに出撃を拾いに行く）

## 7. Event System

### 台詞の送り（§27〜28）

`playCutscene` の台詞（`cutsceneLine`）は **プレイヤーが送るまで次へ進まない**。
送ると次の手順がすぐ走る（台詞の後ろの待ち時間は「読む時間」だったので、送りがその代わりになる）。
入力は既存の会話と同じ（会話欄のクリック/タップ、ゲームパッドの決定）。台詞で終わる演出は、
送ったところで閉じて操作を返す。宵待ちの村・洋館・時計塔・道の演出すべてに効く（演出の中身は変えていない）。

### 始まりの間（§25〜26）

低FPSで「イベントに入ったら数秒止まってから会話が出る」のは、演出の前置き（歩く・振り向く・
人影が出る）を実時間で待っていたため。**最初の台詞までの前置きを合計 0.8 秒以内に縮めた**
（順番はそのまま、間だけ詰める）。例: 宵待ちの村の入口は 3.3 秒 → 0.8 秒。
台詞の無い演出（階段の自動移動など）は対象外。`setTimeout` などの待ちは足していない。
