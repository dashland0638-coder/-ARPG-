基準: `main` `413cbfe`（作業ブランチ `claude/dazzling-maxwell-y3msf3`）。**READ ONLY**。コード・マップ・敵・ボス・台詞・セーブには触れていない。

Human の Goal（2026-11-07）: 第一章③「幽霊船」を、テーマ「帰れない」を持つ独立したシナリオとして再設計する（第1段階 = 物語・体験設計のみ）。時計塔の設定（鐘・七時十三分・塔との関連・管理人・塔への伏線）は幽霊船に一切持ち込まない。時計塔シナリオ自体は変えない。

## 0. 結論

1. **今の幽霊船は「時計塔へ渡すための章」になっている。** 第一章版の物語（CG-02 / CG-03）は、船長室の時計（七時十三分）、ボスの台詞（塔の鐘・七時十三分）、撃破後の頼み（「あの塔の鐘を、鳴らしてくれ」）で時計塔への動機を渡している。これらは今回の方針で**すべて外す**（§3）。
2. **テーマ「帰れない」の仕掛けが無い。** 船内は「桟橋 → 晩餐の間 → 船長室 → 甲板 → 貨物室 → 船倉の奥 → ボス」の一方通行で、帰り道を試す場面・空間が変わる場面が無い。ボスを倒すと結果画面に出て終わる。脱出の場面は無い。
3. **使える土台は多い。** 小舟と船腹からの侵入（`GHOST_SHIP_ENTRY`）、船内の生活空間（晩餐の間・船員室・牢・物資庫・航海士の私室）、`錨` の噂（酒場）、「帰る場所」の会話、酒場の角灯、幽霊の回り込み AI、ボスの召喚。さらに**洋館の異常空間**（`core/mansion-anomaly.js`、`normalizeMansionStructure()`、`playMansionReunion`）が「見覚えのある部屋に、違う繋がり方で出る」「ボス撃破で構造が戻る」を一本道で実装済みで、同じ作法で帰還不能イベントを作れる（§5）。
4. **既存仕様との矛盾が1つある（Human 判断が要る）。** `docs/CHAPTER1_STORY.md` §4-3 と DEC-004 の N-1 / N-5 は、幽霊船 → 時計塔の動機を「船の時計と塔の鐘が同じ時刻」「船長に鐘を頼まれた」に置いている。幽霊船から時計塔の要素を抜くと、**時計塔へ向かう酒場の会話（3行）が根拠を失う**。時計塔の中身は変えずに済むが、酒場の接続の行は変える必要がある（§6、設計書 §9、レビュー E-1）。

### 3-3. 合わない・直すもの

| 要素 | 問題 |
| --- | --- |
| 本筋の順番（甲板を中盤で通る） | 甲板は「最後に戻る場所」にしたい。中盤で通ると脱出の解放感が薄れる |
| 撃破 = 結果画面で終わる | 「甲板へ戻って脱出する」場面が無い |
| 船長最後の手記「近道になると思った」 | 「近道」は時計塔の鐘（N-1）と組で意味を持っていた。単独では空間異常の理由にならない |
| 雑魚の約20秒復活 | 空間が変わって同じ部屋に戻る構成では、復活が「迷わされている」苛立ちに変わる（洋館は第一章で止めた） |
| `drowned` テーマ（膨れた体・フジツボ・海藻）と中ボス「身体の半分が魚」 | 村で Human が承認した「幽霊・人型の影。ゾンビ・腐敗・グロテスクな肉体は採らない」（CH1-COMP-W3-GHOST）と方向が違う。今回の依頼の「グロテスクに頼らない」にも合わない |
| 酒場の主人「霧の港に、朽ちた帆船が打ち上げられた」 | 「海上の船へ小舟で近づく」と合わない（打ち上げられた船なら歩いて行ける） |
| 船内の環境音が無い | 軋み・水滴・遠い物音の設計を載せる先が無い（`AMBIENCE_ZONES` に区画が無い） |

## 4. シナリオ進行・セーブ・クリア判定との関係（事実）

- 第一章の段は `scenarioClears` から毎回導く（新しいセーブ項目は無い）。幽霊船のクリアは船長の撃破で `scenarioClears('ghostship')` が増える。**この判定は変えずに再設計できる**（帰還不能イベント・空間の変化は出撃中だけの状態でよい）。
- 死んだら同じ段を最初からやり直す（SCENARIOS.md）。帰還不能イベントは毎回起きる → 前半を短く保つ必要がある（設計書 §10 のリスク）。
- 第一章の台詞は本編（`!legacyGrowth()`）とテストモードの既定で出す。旧成長・周回の台詞は残す（CHAPTER1_STORY §1、TEST-MODE-CURRENT-001）。新設計もこの分岐の内側に置く。
- 洋館の撃破後演出は、結果画面の「戻る」の後に `playMansionReunion` を流してから酒場へ戻る（`12-progression-ui.js` 540 付近）。幽霊船の脱出も同じ位置に置ける。

## 7. 再設計が必要な箇所（まとめ）

1. 物語の骨格（船の正体・帰れない理由・空間変化の理由・撃破で解ける理由）
2. 本筋の順番（甲板を最後に）と、帰還不能イベントの前後で変わる構造
3. 敵の見た目と役割（乗組員の「残影」へ。AI は既存）・ミニボスの差し替え・ボスの攻撃と演出
4. 撃破後の脱出（甲板）と酒場の帰還
5. 船内の環境音の区画と、帰還不能イベントの音の変化
6. 時計塔の要素の除去と、時計塔への接続の行（Human 判断）
