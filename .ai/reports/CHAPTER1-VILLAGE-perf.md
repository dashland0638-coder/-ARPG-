# CHAPTER1-VILLAGE — 宵待ちの村の表示と負荷（CV-01）

Date: 2026-10-07
対象: WORK12 の実機確認待ち（C 区分）のうち2件。
- 商店街の同時最大（8体）の見え方
- 実 GPU でのライト数の影響

## 1. Agent が確かめたこと（自動）

| 項目 | 値 | 根拠 | 固定するテスト |
| --- | --- | --- | --- |
| 商店街の同時最大 | **8体** = 水鏡の影 1 ＋ 分身 2 ＋ 泡沫 4（他の怪異と居合わせる間の上限）＋ 写し身 1 | `core/encounter-waves.js`（`PROVISIONAL_MARKET_WAVES`）、`core/mirror-shade.js`（`PROVISIONAL_CLONE_COUNT = 2`）、`core/foam-swarm.js`（`PROVISIONAL_FOAM_MAX_CROWDED = 4`） | `tests/unit/village-load.test.js` |
| 村の常灯 | **PointLight 19個**（`lamp()` 1つにつき1個、光源プールは使わない） | `14-dungeon-duskvillage.js` の `lamp()` | 同上（19個を超えたら落ちる） |
| そのほかの光源 | 半球光1・平行光2（全ワールド共通）、戦闘エフェクト用の光源プール 6 | `02-world-common.js`、`13-update-loop.js`（`LIGHT_POOL_SIZE = 6`） | ― |
| 比較: 洋館 | ランプを区画ごとにまとめ、使い回す実体は「1区画の最大数」だけ | `core/mansion-lamp-zones.js` | `mansion-lamp-zones.test.js` |
| 画質設定 | 軽量（倍率 1.0・影 512）／標準（1.5・1024）／高（2.0・2048）、影のあり／なし | `14-hud-boot.js`（`QUALITY_STEPS`） | ― |

- **この環境では重さを測れない**（software rendering で、実 GPU と比べられない）。
- 上の上限が守られていることだけをテストで固定し、計測は実機で行う。

**見立て（Agent）**
- 村は洋館と違い、常灯 19 個がワールドにずっと置かれている。three.js は点光源の数だけ描画の負荷が増える。
- そのため、**影あり・高画質・モバイル GPU** の組み合わせで最も重くなると見込む。
- 重かった場合の対処は §4（測ってから判断する）。

## 2. 実機で測ること（Human）

| # | 場所 | 操作 | 記録 |
| --- | --- | --- | --- |
| M-1 | 村の入口 → 中央広場 | 歩くだけ | FPS（平均・最低）、カクつきの有無 |
| M-2 | 商店街の複合戦闘 | 水鏡の影に手を出し、分裂させ、泡沫と写し身が揃うまで待つ（**8体が同時にいる状態**を作る） | FPS（平均・最低）。どれが本体か・何が攻撃してくるかが**見分けられるか**（画面が詰まって判断できない、になっていないか） |
| M-3 | 水門 → 村の奥 → ボス | ボス戦の分身と残響が出ている間 | FPS（平均・最低） |
| M-4 | 同じ M-1〜M-3 を、画質「軽量」・影「なし」でも | ― | FPS の差 |

**FPS の見方**
- Chrome: 開発者ツール → その他のツール → Rendering → 「Frame Rendering Stats」をオンにすると、画面左上に FPS が出る。
- ほかのブラウザでは体感と録画でよい（「60で安定」「時々30まで落ちる」など）。

**記録用紙**
```
端末 / OS / ブラウザ / GPU（分かれば）:
画質・影の設定:
M-1 平均 / 最低 FPS:
M-2 平均 / 最低 FPS:   見分けられたか（○ / ×）:
M-3 平均 / 最低 FPS:
M-4（軽量・影なし）:
気づき:
```

## 3. 合格の目安（案）
| 区分 | 目安 |
| --- | --- |
| 画質「標準」・影あり | M-1〜M-3 の最低 FPS が 30 以上 |
| 画質「軽量」・影なし | 低性能の端末でも最低 30 以上 |
| 見え方（M-2） | 8体の中で本体と攻撃の予兆が見分けられる |

**目安そのものは Human が決めてよい**（ここに書いたのは Agent の案）。

## 4. 結果による分岐
| 結果 | 対処 | 誰が決めるか |
| --- | --- | --- |
| 目安を満たす | C 区分の2件を閉じる（受け入れ） | Human が記録を返した時点で Agent が閉じる |
| ライトで重い（影なし・軽量で改善が大きい、または M-1 から重い） | 村の常灯を洋館と同じ「区画ごとにまとめて使い回す」方式へ寄せる。見た目は保ち、同時に有効な光源だけを減らす。描画だけの変更で、敵や数値には触れない | Agent（Bug Fix / 最適化として、新しい Work Item で実施） |
| 8体で見分けられない | 敵の数や上限を変える必要がある → **数値の変更なので HE-3** | Human |
