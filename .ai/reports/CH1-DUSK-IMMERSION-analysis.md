# CH1-DUSK-IMMERSION — 宵待ちの村の物語・街灯・第二スキル(調査と計画)

基準: `origin/main` `5765fda`。Analyzer → Planner。実装は 3 つの小さな単位(A 台詞 / B 灯りと電線 / C 観測の灯の見え方)に分ける。

## A. 台詞

### A-0. 既存の方針と、今回の依頼の関係

- 村の台詞は「説明しない」を方針にしてきた(`docs/CHAPTER1_STORY.md` §1「台詞は短く、説明しない」、14-dungeon-duskvillage.js のコメントの §17「台詞で village の過去を説明しない」)。その結果、**村で何が起きたか・なぜ水門と閂が閉じているか・敵が何者か・次にどこへ行くか**が、手記をすべて読んで自分で並べた人にしか分からない
- 今回の Human の依頼は「余韻は残し、情報まで曖昧にしない」。**怪異の正体を断定しない**(`CHAPTER1_STORY.md` §1・§2)は守り、**村人がしたこと(原因)・主人公の目的・次の行動**は具体的に言わせる。決定記録: `DEC-010`
- 正式に決まっている事実(DEC-001・手記・マップ)だけをつなぐ。新しい設定は足さない:
  1. 湖で漁をして暮らす村。夜、**水面に人が映る**(上には誰もいない)ようになった(見回りの控え「水面に人影」)
  2. 村人は**夜間の水門の開放を禁止**し(破れた貼り紙)、**水のほうへの道を内側から閂で閉ざし**(閂の門)、見回りは**裏通りから**水門へ通った(見張りの交代表)
  3. 村人は**子どもには話さず、忘れることにした**(商店街の記憶「忘れた方がいい」「子どもには」、紙片「子どもには――」「――閉めた」、帳簿の「水門の件について――」)
  4. そのあと人は**少しずつ**いなくなり(当番表の名前が途中から書かれない・帳簿が止まる・「誰も取りに来なかった」)、物と**記憶だけが残って繰り返す**(DEC-001 のテーマ「忘れられること」。「村人を復活させるのではなく、残された記憶が解放される」)
  5. **水門守の残響** = 最後まで水門を閉め続けた見張りの動作。**村の残響** = 村じゅうの記憶が水門の奥の水面に集まったもの。倒すと記憶が解放され「……ありがとう。」(DEC-001 で固定)
  - 断定しないこと: 水に人が映る理由・怪異の正体・人がどこへ消えたか(魔法使いは「たぶん」「〜と思います」で止める)

## B. 灯り・街灯・電線

- 現状: 村の灯りは `lamp(x, z)` 19 個(**PointLight 1 個ずつ**。`tests/unit/village-load.test.js` が上限 19 と、村のファイルの PointLight が `lamp()` の中の 1 か所だけであることを固定。CV-01 の実機計測の前提)。光源プール(`takeLight`)は世界の破棄で返されないので使えない。外壁のランプ・街灯の腕・電線は無い。洗濯物の縄(`ropeLine`)はある
- 方針: **PointLight を増やさない**。新しい灯りは「灯具(マットな枠 + 弱い自発光のガラス)+ 光の落ち方の面(壁と地面に置く、柔らかい暖色の円。光源ではない)」で表す。電線は暗い細い線(たわみ付き)を、建物の軒と街灯の柱の間に張る(電柱は立てない)。当たり判定は足さない
- 置き場所: 入口・広場・商店街・裏通り・水門前・魚屋の外壁(建物の道に面した壁)と、灯りの間隔が空いている道沿い(入口 → 広場、閂の門の前、裏通りの小道、水門前)。村の奥とボスの区画には置かない(「もう村のものではない」の暗さを残す)
- 予兆を隠さない: 光の面は床の少し上・予兆の輪より先に描く(renderOrder)。縁の無い柔らかい円で、輪に見せない。電線は細い(半径 0.02)
- 負荷: 部品の geometry・material は共有。追加のメッシュは 100 個程度(光源・影は増やさない。電線と光の面は影を落とさない)

- 崩し斬り・爆弾投げ・三連投げナイフは「当たった結果(数字・爆発・体幹)」がそのまま見える。改修は要らない(**村の範囲外で、今回は変えない**)
- **観測の灯だけが、使った結果を画面から読み取れない**。村は魔法使いの章なので、ここを直す

### C-1. 観測の灯の改善(見え方だけ。効果・時間・範囲・CD・発動条件は変えない)

1. **届く範囲**: 掲げた瞬間、足元から半径 14(= `OBSERVE_RADIUS`)まで、淡い寒色の輪が一度だけ広がって消える(予兆の暖色の輪と色・動きで分ける。広がって消えるだけで、満ちない)
2. **効いている敵**: 灯りが届いていて、灯りで挙動が変わる怪異(水鏡の影と分身・写し身・記憶漁師・水門守の残響)の頭上に、灯りと同じ色の小さな灯の粒が出る。本体と分身は**同じ**粒(答えは出さない)。灯りで変わらない敵(泡沫・洋館など)には出ない ―― 「灯りは怪異に効く」が嘘にならない
3. **差そのもの**: 灯りの下の水鏡の影・分身の波紋を、灯りと同じ寒色で少し濃くする(波紋の間隔の差 = 灯りで広がる差を、その場で見せる)
4. **効果中**: 頭上の球と粒が、残り 1/4 で一緒に薄れて消える
- ボスの段階 3 の残響の遅れ(灯りで変わる)は、ボスに粒を付けるとボスの分身(`group.clone`)と見分けがついてしまうので付けない。残響の遅れ自体は既存の輪で見える
- 判断が要る点(Human へ): 観測の灯は**村の怪異以外には何も起きない**(洋館などで使っても変化が無い)。第一章では魔法使いが主人公なのは村だけなので問題は小さいが、効果を他の敵へ広げるか・説明を足すかは設計の変更になるので、今回は実装せず報告する
