## 0. 結論(実機の感想の原因)

| 感想 | 原因(実装の事実) |
| --- | --- |
| 部屋が孤立していて、扉を一つずつ通過する作業が多い | 002 は部屋を 1 つずつ離れた箱として建て、部屋どうしの移動をすべて「扉・梯子 = 暗転のテレポート」にしていた(通路 39 件のうち 30 件が扉・梯子)。同じ階層の部屋が床で繋がっていない |
| 船の中を歩いている感じが薄い / 方向・階層が分からない | 箱どうしの位置関係が船の形になっていない(往路の部屋が x・z に散らばる)。階層の区別が無く、船首・船尾の手がかりも無い |
| 同じ場所に戻ったと分からない | 「……?」の部屋は家具の一部だけを写した別の箱で、柱・照明・樽・壁の傷など共通の目印が無かった。移動も扉のテレポートなので「繋がりが変わった」ではなく「別の部屋へ飛ばされた」に見えた |
| 矢印がほとんど見えない | 白い床の細い矢印(MeshBasic、不透明度 0.92、長さ 1.05)だけで、暗い床と霧に埋もれる。光らない・近づいても反応しない |
| 船底の穴を塞いだ板が見えない | 暗い船底の、暗い壁際に板を並べただけ。手がかりが板の色だけ |
| 食堂で机が見えない | カメラは常にプレイヤーを追い、壁(高さ 2.3)が手前で画面を隠す。会話はカメラと関係なく、部屋に入った瞬間に出ていた |
| 酒場に戻った後の会話が無い | 帰還の会話は本編の交代の一幕(`advanceChapter1Cast`)でだけ出る。テストモードは交代の一幕を出さない(`if(state.testMode) return false`)ので、テストモードで遊ぶと何も出ない。本編でも 2 行だけだった |

## 2. 方針

1. **階層ごとの一続きの床**: 同じ階層の部屋は壁の開口(`gaps`)で歩いて繋ぐ。階段・梯子・昇降口は階層をまたぐ時だけ。扉は 4 つ(食堂・船長室・存在しない扉・錨の間)
2. **船の向き**: 船首 = -z(画面の下)、船尾 = +z(画面の上)。往路はずっと船尾へ(画面の上へ)進む。各階層に舳先の形・船尾の板と窓・外周の肋材・縁を同じ形で置く
3. **断面の見え方**: 壁を低く(1.15)。上から部屋の中が見え、手前の壁で人物が隠れない
4. **同じ場所の変化**: 帰還不能(1)は瞬間移動ではなく、同じ部屋(壁・扉・柱・樽・壁の傷はそのまま)の中身が食堂から船員室に入れ替わる。写しの部屋は寸法と目印を元の部屋と揃える
5. **魔法の印**: 加算の青白い光の矢(床に大きく)、輪郭、足元の輪、柱の光の筋。明滅、近づくと明るくなり音。穴のあった所には光の輪郭が残る
6. **カメラ**: 見せたい物がある場面だけ短く見せ(演出の間は保つ)、その後に台詞。手で回していない時は船尾を見る向きへゆっくり戻す
7. **酒場**: 帰還の会話を 6 行に(弓師の「……ただいま、戻りました。」を真ん中に)。テストモードでも同じ行を一度だけ出す
