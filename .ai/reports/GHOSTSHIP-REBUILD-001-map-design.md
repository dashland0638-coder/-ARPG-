Status: DESIGN（Human 承認待ち）

## 0. 方針

- **各部屋に役割を持たせる**（物語・探索・戦闘のどれか、できれば二つ）。部屋数を増やすこと自体は目的にしない。
- **帰還不能の前後で、同じ船が違う構造になる。** ただし迷路にしない。変化は「出口へ向かう道が奥へ繋がる」という**一つの規則**に従い、ループは一度だけ。その後は**錨の鎖**を目印にした一本道。
- 作り方は洋館の異常空間と同じ（`core/mansion-anomaly.js`、MANSION_SCENARIO.md「異常空間」）: **見覚えのある部屋を別区画として建て（「……?」の部屋）、扉と梯子の行き先で繋ぐ。** 新しい移動の仕組みは作らない。
- 船の上下（船底・中層・上層・甲板）は、既存と同じく**梯子（`buildStairs` = 暗転して別区画へ）**で表す。
- 座標は Work Item W2 で決める（`worldKeyForPos` の `ghostship` 帯 x:-46〜42, z>28 の中。既存区画の作り直しを含む）。この文書は部屋・接続・目印・導線を決める。

## 4. 迷わせないための約束

1. **ループは一度だけ**（X3 → X3'）。二度目に同じ梯子を上っても X3' に戻らず、鎖の扉以外は開かない（扉を調べると「びくともしない」）。
2. **帰還不能の後は一本道**（寄り道は X5s だけ。本筋から一歩の距離）。
3. **鎖が常に見える**: 各部屋で、鎖は次へ繋がる扉のそばを通す。鎖の擦れる音を扉の近くで鳴らす（音の目印）。
4. **目標の表示**: 7-d の後は「錨の鎖を辿って、船の奥へ」。目標の表示は既存の HUD の作法に乗せる。
5. **開かない扉の反応**: 外へ向かう扉は、調べると「外から押さえられているように、動かない」（短い1行）。何度でも同じ反応で、罰は無い。
6. **敵は復活しない**: 船の第一章では `roomTag` を付け、倒した敵は出撃中に戻らない（洋館の第一章と同じ。CG-01 で観察として残っていた点）。同じ見た目の部屋に戻ったとき、倒した敵が戻っていると「迷わされている」苛立ちになるため。
7. **死んだとき**: 第一章の仕様どおり段の最初から。会話は元から短く保つ（2 回目以降の短縮は物語 §10 R-2 の条件つき）。

## 5. 撃破後の構造の戻り方

```
 [X9 錨の間] 撃破 → 鎖が落ちる
     │ 暗転（洋館の normalizeMansionStructure と同じく、「……?」の区画の
     │ メッシュと当たり判定を畳む。世界は建て直さない）
     ▼
 [H6 船長室（本物）] 昇降口が開いている。光が落ちる
     │ 昇降口・上り
     ▼
 [D1 甲板] 霧が薄れる。影が陸を向いて消える。船尾の角灯を外す
     │ 舷側の縄梯子（調べる）
     ▼
 [B0 係留地点] 暗転 → 酒場
```

- 甲板は**この時だけ**行ける（往路の H6 の昇降口は開かない）。冒頭で小舟から見上げた場所に、最後に立つ。
- 甲板では戦闘をしない。歩ける範囲は小さく、縄梯子まで一本（角灯と瓶の手紙は通り道の脇）。
- 撃破の時点で `scenarioClears('ghostship')` は今と同じく記録される（`12-progression-ui.js` の撃破処理。`endsRun` に関係なく増える）。甲板の場面の途中で中断しても、クリアは失われない。
- 前例: 時計塔のボスは `endsRun:false, afterDefeat:'towerCollapse'` で、結果画面の後も同じ出撃の中で崩壊 → 屋上 → 跳躍へ続く。幽霊船も第一章では同じ形（`endsRun:false`、`afterDefeat` に脱出の演出）にでき、新しい進行の仕組みは要らない。洋館の `normalizeMansionStructure()` と組み合わせる。
