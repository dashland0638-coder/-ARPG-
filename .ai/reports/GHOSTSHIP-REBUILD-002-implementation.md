## 0. 要約

第一章の本編（`legacyGrowth()` が偽）の幽霊船を、新しい「帰れない」船に置き換えた。テストモードの旧成長・将来の周回は既存の船のまま（`buildGhostShip`）。
導入（小舟・係留・船底の穴）→ 往路の探索 → 船長室での帰還の決断 → 帰還不能（指定の4つの異常を指定の順で）→ 一度だけのループ → 錨の鎖を辿る一本道 → 点呼の廊下（甲板長）→ 錨の間（船長3段）→ 鎖を手放す・錨が落ちる・構造が戻る → 甲板 → 縄梯子 → 酒場「……ただいま、戻りました。」まで、一続きにプレイできる。
時計塔の要素は幽霊船からすべて外した。セーブ形式・進行フラグ・他のシナリオ・キャラクター交代・成長と装備の方針は変えていない。

### 3-4. ボス

HP 820 / 攻撃力 40 / 速さ 1.95（既存のまま）。攻撃表は `core/ghostship-captain.js`:

| 段 | 行動 | 予兆（= 判定の形） |
| --- | --- | --- |
| 1 | 舶刀の薙ぎ払い（扇 3.4・±57°） / 鎖の引き寄せ（帯 11×1.4、当たると船長の手前 2.8 まで最大 4 引く） | 床の扇・床の帯（0.75 / 0.95 秒） |
| 2 | 「総員、点呼!」（角灯を掲げて止まる → 水夫の残影2体、同時4体まで） | 1.3 秒止まる（攻撃の好機） |
| 3 | 「離さん……この鎖だけは!」→ 鎖の薙ぎ払い（扇 1.2〜7.4・±100°、足元と背後は空く） | 床の扇（1.15 秒） |

鎖の引き寄せの公平さ: 線から横へずれる・回避で外れる（無敵中はジャストドッジの判定へ）。引き寄せの後は硬直 1.0 秒＋呼吸 0.5 秒、次の攻撃が当たり得るまで 2.4 秒以上（`captainReactionWindow`、unit で固定）。段の移行は 1.6 秒止まる。既存ボスの「段の移行で即時に爆発する範囲攻撃」は、この船長では使わない（予兆の無い被弾を避けるため。§5 の差分）。

## 4. 時計塔要素の除去

| 除去したもの | 場所 |
| --- | --- |
| 船長室の止まった時計（七時十三分）と弓師の3行、船倉の奥の「鐘を待っている顔」、甲板の2行 | `04-dungeons-ship-waterway.js` の `buildGhostShipChapter1Story`（関数ごと） |
| 船長の第一章の台詞（塔の鐘・七時十三分・近道）・撃破後の「あの塔の鐘を、鳴らしてくれ」 | `04` の `GHOST_CAPTAIN_CHAPTER1_LINES` / `_FAREWELL`、`07` と `12` の参照 |
| 出発の弓師「毎晩、同じ時刻に鳴るんです」 | `14-hud-boot.js` → 「沖の霧の中に、毎晩、灯が点るんです」 |
| 帰還の弓師「船長に、頼まれごとをしました。……塔の鐘を、と。」 | → 「……ただいま、戻りました。」 |
| 時計塔への交代の主人「その塔なら、鐘が毎晩同じ時刻で止まるらしい」・弓師「止まっているのは、鐘だけじゃありません。船も、あの時刻で」 | → 主人「塔の管理人が、七日戻らないそうだ。鐘も、止まったままでな。」・弓師「……待っている人が、いるんですね。」 |

時計塔のシナリオ（各階・ボス・崩壊・島・翌朝）と盗賊の行は変えていない。主人の行に残る「鐘も、止まったままでな」は時計塔の側の事実で、続く盗賊の既存の行「止まってるなら、入るのは簡単だ」を受けるために残した（船とは結ばない）。
確認: unit `ghostship-story` が幽霊船のソースの文字列リテラル全部に「鐘・七時十三分・時計・塔」が無いことを固定。
