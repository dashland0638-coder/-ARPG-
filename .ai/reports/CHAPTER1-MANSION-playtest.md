Date: 2026-10-07
対象: 森の洋館（第一章 ①）。新規開始から、洋館をクリアして酒場に戻り、魔法使いへの交代の一幕が出るまで。
実施者: **Human**（HE-2: a）。Agent は実機を操作できないため、手順・確認項目・記録用紙を用意した。

この記録が埋まり、§5 の合格条件を満たしたとき、洋館を **VERIFIED（Human 確認済み）** とする。
それまでは、自動テストで確認済みの項目があっても洋館全体を VERIFIED にはしない。

## 3. 中断・やり直し
- 途中で倒れたら、酒場に戻って洋館をもう一度最初から（進行は戻らない）。倒れた場所と原因を記録する。
- 進めなくなったら、その場の画面とコンソールを記録して中断してよい（§4 の「詰み」欄）。

## 5. 合格条件（洋館 = VERIFIED）

1. 区間 0〜10 をすべて通した。
2. A-1: ページエラー 0。
3. A-2: 詰み 0。
4. ×の項目は、次のどちらかに振り分けた。
   - **不具合**: Agent が Bug Fix として直す。
   - **調整（数値・演出の好み）**: Human が「受け入れる」か「直す」かを決める。

×が残っていても、不具合が直り、調整を Human が受け入れれば合格とする。

## 6. 記録の渡し方
記録用紙の中身をそのまま Agent に渡してください（チャットに貼る、または `.ai/reports/CHAPTER1-MANSION-playtest-result.md` として追加）。
Agent は不具合を Work Item にし、照合表（`CHAPTER1-MANSION-checklist.md`）の「実機」列を埋めます。
