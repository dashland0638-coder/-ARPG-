# CAMERA-001 — 森の洋館・宵待ちの村のカメラワークと空間描画（調査）

基準: `main` @ `8124c8f`（#117・#118 のマージ後）。作業ブランチ `claude/camera-001`。
共通方針: `docs/DUNGEON_RENDERING.md`。対象タスク: `.ai/tasks/CAMERA-MANSION-001.md` / `CAMERA-DUSKVILLAGE-001.md`。

## 1. 森の洋館

| 項目 | 事実 |
| --- | --- |
| 部屋の接続 | `MANSION_ROOMS`（03）の表。壁は表の `gaps`（開口・'full' は辺の全部）で切る。階をまたぐのは階段（テレポート）。各階は森の上の離れ島 |
| 廊下・階段・扉 | 壁の高さ 2.3（静的バッチで材質ごとに 1 つのメッシュ）。扉は `buildDoor`（玄関など少数） |
| 現在の部屋と隣の部屋の表示 | **区画ごとの表示の切り替えは無い**。視錐台カリングだけ。カメラは近い（camDist）ので壁でかなり隠れるが、上からの角度・広い部屋では壁の向こうの床・家具が見える。上からの全体写真（`a-m-top-*`）で確認 |
| 壁・外壁の遮蔽 | 一階は外殻（004 で影を落とさない）と屋根（外にいる時だけ）。離れ島は下地（暗い床）の上 |
| カメラ | `updateCamera`（13）: 追従＋自動の回り込み（`camAutoOn`）＋ボスの寄り。**イベント時に対象を見せる仕組みは無い**（会話はカメラと無関係に出る） |
| イベントの対象が見えるか | 食堂の皿・厨房の竈・塞がれた扉・作業室の鍛冶屋・瓦礫の山・異常空間の玄関ホールは、プレイヤーの位置次第で画面の外 |
| 描画欠落 | 004 で直した厨房・外殻の影・離れ島の草地を再確認 → 再発なし（`b-m-*` / `a-m-*`） |
| 自動カメラ OFF | 回り込みが止まるだけ。向き（camYaw）は手で回した値のまま |

## 2. 宵待ちの村

| 項目 | 事実 |
| --- | --- |
| 区画 | `DUSK_ROOMS`（core/dusk-village-map.js）。屋外の区画（広場・通り・水門前など）を水の上に並べ、木橋・小道で繋ぐ |
| 建物 | 入れない建物（`hut`: 箱＋屋根）と、入れる建物 5 棟（`house`: 出入口＋透かせる屋根）。入れる建物の屋根は**中にいる時だけ透ける**（`duskInteriors`）。外からは屋根が中を隠す |
| 壁越しの室内・NPC | 外からは屋根で見えない（上からの全体写真・各地点の写真で確認）。室内の記憶の人影は、建物の中で起きる |
| 屋外と屋内の境 | 出入口を通ると屋根が透ける（既存）。屋外は屋外として描く（村は屋外の舞台なので、隣の区画を隠すと水と空の上に島が浮く見え方になる） |
| カメラ | 入口の場面だけ `cutsceneTurnTo` で向きを変える。**記憶の場面・水門・ボスの手前は、対象を見せる前に台詞・人影が出る** |

## 3. 方針（共通化の範囲）

| 部分 | 共通化 | 理由 |
| --- | --- | --- |
| 見せてから話すカメラ | **共通**（`sceneCamShot`、13）＋ 出来事の `show` オプション（02） | どのシナリオでも同じ順序（見せる → 間 → 話す）。幽霊船は既存の `gsCamShot` のまま（作り直さない） |
| 今いる部屋を中心に描く | **共通の部品**（`roomCellBatch` / `initRoomCells` / `updateRoomCells`、02）。使うのは洋館だけ | 部屋の表を持つダンジョンで使える。幽霊船は既存の区画のまま（巻き戻さない・作り直さない） |
| 村の描画 | **変えない** | 屋外の舞台で、入れる建物は既に屋根で中を隠し、中にいる時だけ透ける。隣の区画を隠すと屋外として不自然になる |

表示の切り替えは描画の層（`layers`）で行う。洋館の既存の仕組みが `visible` を使い（宝箱・ミミック・瓦礫）、`scene.remove` で物を外す（異常空間の正常化・瓦礫）ため、親子関係と `visible` には触れない。
