## 3. 新規実装

### 3-1. 村の入口のセミシームレス演出

黒画面も場所の切り替えも挟まず、同じ場所のまま進む。

```
村の入口の部屋へ入る（registerRoomEvent, inset 1.2 ―― 入ってすぐ）
  → 剣士が数歩先へ出る（stepDuskGuestWalk）／魔法使いは歩度を落として止まる（state.walkTo）
  → 水面へ目をやる（cutsceneTurnTo + カメラも同じ方向へ）／風が止む（ambienceHold）
  → 水面に人影（spawnApparition）＋ 波紋（spawnDuskRipple）
  → 9行の会話（剣士が振り返る／最後は剣士が先に歩き出す）
  → 向き直って操作を返す
```

実時間で約15秒。台詞を9行に絞り、間に移動・振り返り・人影を挟んで、
「立ち止まって喋るだけ」にならないようにしてある。

### 3-2. 会話

魔法使いは説明役にしない。観察して、仮説を立てて、真顔で軽口を言う。
剣士も聞く側で終わらせず、自分で観察して判断する。「分かりません」は使っていない。

```
魔法使い「……止まってください」
剣士　　「どうした」
魔法使い「水面に、人が映っていました。上には誰もいないのに」
剣士　　「……今は」
魔法使い「消えました。急いで帰ったのかもしれません」
剣士　　「水の中へか」
魔法使い「ええ。……すみません、今のは冗談です」
剣士　　「笑うところが分からん。……足元を見ておけ、濡れてる」
魔法使い「はい。見ています」
```

`cutsceneLine(text, name)` に話者名を足したのはこのため（洋館は主人公ひとりの
独白だったので既定のままで足りていた）。

### 3-3. 魚屋の記憶

帳場へ寄ったときだけ、一度だけ。誰がいつ言ったのかも、なぜ聞こえるのかも明かさない。

```
（風が止む／木が軋む）
  → 帳場の内と外に、2人ぶんの輪郭が一瞬だけ重なる
  → 「……今日はこれだけか」
  → 「明日はもう少し獲れるさ」
  → 輪郭が消え、波紋がひとつ
  → 剣士「……聞こえたか」／魔法使い「はい。まだ残っているんだと思います、ここに」
```

声には名前を付けていない（話者名は空）。説明はここで止め、余白を残している。

### 3-4. 魚屋の生活痕跡

WORK 2 の小物（魚籠3・まな板・包丁・桶・秤・木箱・帳簿）に、**干からびた魚**を
籠2つとまな板の上へ足した。陳列にならないよう、目に入る3箇所だけ。
帳簿の「水門の件について――」は WORK 2 で設置済み（伏線はそのまま）。

### 3-5. 水鏡の影（最初の怪異）

**この敵が教えるのは倒し方ではなく、「観察すると挙動に規則がある」というルール。**

| 要素 | 実装 |
| --- | --- |
| 配置 | 2体のみ。中央広場の北西（村の中心で必ず目に入る）と魚屋の前 |
| 数値 | HP 260 / 攻撃 30 / 速度 2.2（`PROVISIONAL_*` と同じく暫定） |
| Phase 1 | 1体で接近し、予兆 → 打撃 |
| Phase 2 | HP 62% を下回ると同じ姿へ分裂（本体＋分身2体）。**分裂は一度だけ** |
| 分身への攻撃 | ダメージは入らず、手応えなく散る。散らすと約7秒後に本体がまた分ける |
| 本体撃破 | 分身も残らず消える |

**観察できる差（本体を示す印は出さない）**

1. **波紋の間隔** — 本体は約2.1秒ごとにゆっくり、分身は約1.15秒ごとに細かく水面を叩く
2. **向き直りの速さ** — 本体は 3.0 rad/s と鈍く、分身は 7.5 rad/s で鏡のように即応する
3. **予兆の長さと深さ** — 本体は 0.72秒かけて大きく引く、分身は 0.34秒で浅く来る

波紋は村の水面の波紋（WORK 2 の `spawnDuskRipple`）をそのまま使っている ――
怪異専用の表示を足していないからこそ「差」として読める。

### 3-6. 観測の灯（魔法使いの Skill 2）

- `state.observeLightT` を7秒立てるだけ。**何が見やすくなるかは敵の側が決める**
- 水鏡の影では上の3つの差が **1.8倍** に開く（本体はさらに遅く、分身はさらに細かく）
- **答えは表示しない**。本体に印・色・名前を出す処理は1行も無い
- 灯りが無くても差は残るので、**他職でも同じ敵を同じ方法で攻略できる**
- ダメージ 0。属性なし。見た目はプレイヤーの頭上に留まる静かな光（最後の1/4で落ちる）

旧 Skill 2「護りの魔球」は座を譲った。`castOrbGuard` / `updateMageOrbs` /
`tryConsumeOrbShield` の実装は残してある（各被弾経路の呼び出しは空配列に対して
false を返すだけで安全）。→ 残課題 7-3。

### 3-7. 演出中も世界を動かす

`updateDuskVillage(dt)` をメインループの演出分岐にも追加した。水面・小舟・洗濯物が
止まると、その瞬間だけ世界が書き割りになるため。同行者の演出歩きもここから進む。

## 4. 敵AI仕様（`updateMirrorShadeAI`）

```
chase  … 索敵（距離9 + 視線）→ triggered。間合い1.9まで接近
         本体/分身ともここで波紋を出し、向き直る（差が出るのはこの2つ）
windup … core/mirror-shade.js の windupPlan(dur, depth) で引く
         見た目は body.scale を沈める（既存の hurt 演出と同じ手法）
strike … 0.22秒。距離2.4以内で1回だけ命中判定
         無敵中は tryPerfectDodge へ回す（既存のジャストドッジ経路）
         振り抜き後は postAtkRecoveryT（パニッシュ窓）を開ける
```

- 新しい状態機械は敵の内部にのみ持ち、共有の戦闘基盤には手を入れていない
- 分身は `mirrorCloneOf` を持つ通常の `enemies` 要素。`hp:1 / xp:0 / goldBonus:[0,0]`
- `dealDamageToEnemy` の先頭で分身を判定して散らす（DoT では散らない）

## 7. 設計上の判断・残課題

### 7-1. ヘッドレス環境が実時間の約1/12でしか進まない（**要判断**）

計測した実測値（この環境、SwiftShader・1280×800）:

| ワールド | FPS |
| --- | --- |
| 森の洋館 | 1.4 |
| 宵待ちの村 | 1.6 |
| トレーニング空間 | 4.5 |

**宵待ちの村が特別に重いわけではない**（既存の洋館のほうが遅い）。
`dt` は 0.05 で丸められるため、1.6fps ではゲーム内時間が実時間の約 1/12 しか進まない。

このため:

- 15秒の演出を最後まで待つと実測3分以上かかる → E2E は「演出が始まって、二人の
  会話として表示される」ところまでを検証し、以降は打ち切っている
- 魚屋まで歩く（広場から45ユニット）と実測90秒以上 → **戦闘・記憶・観測の灯の
  実プレイ確認は E2E からは外してある**

判断が必要: 実機確認（⑤⑥⑦⑩）のために、テストモード限定の座標ジャンプなどを
用意するか。**今回も新しいデバッグ機能は足していない。**

### 7-2. 分身に当てた時の手応えについて（設計判断）

分身は「ダメージが入らず散る」。これは答えの表示ではなく、プレイヤーが自分で
試した結果として得る情報なので、印を出すことには当たらないと判断した。
散らした分は約7秒後に戻るので、「全部壊す」では解決しない。

### 7-3. 護りの魔球が未接続のまま残っている

Skill 2 の座を観測の灯へ譲ったため、`state.mageOrbs` を積む経路が無くなった。
実装（生成・更新・身代わり）は消さずに残してある。呼び出し側（`tryConsumeOrbShield`）は
空配列に対して false を返すだけで安全。

要判断: このまま残すか、別スキルとして再利用するか、削除するか。

### 7-4. 水鏡の影の数値はすべて暫定

HP・攻撃力・分裂閾値・分身数・波紋間隔・向き直り速度・予兆長さ・観測の灯の
倍率と持続はすべて `PROVISIONAL_*`。実機で「差が読めるか」「分身が鬱陶しくないか」を
見てから WORK 8 で詰める。

### 7-5. 観測の灯が効くのは今のところ水鏡の影だけ

「何が見やすくなるか」を敵の側に持たせた設計なので、写し身・記憶漁師・水門守の残響を
足すたびに、それぞれの敵が `state.observeLightT` を読む必要がある。
WORK 4 以降の各敵で同じ作法を守る。

### 7-6. 正式仕様に対する設計変更

**なし。** 属性は追加していない。観測の灯は必須にしていない。魔法使い専用の
通行制限も作っていない。旧ランタン／旧 duskCollective／旧「光を当てないと無敵」は
復活させていない。`state.chapter` も追加していない。
