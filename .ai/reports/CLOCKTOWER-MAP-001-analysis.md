# CLOCKTOWER-MAP-001 — 調査と方針（Analyzer / Planner）

## 1. 現状
- 塔は外壁の内側 36×36（`TOWER_OUT`）、真ん中に縦穴。層は y 0 / 8 / 16 / 26 / 34 / 44 / 52（`TOWER_TIER_Y`）
- 各層の壁（`TOWER_WALLS`）は 'w' でも高さ 2.4。層の間は 8〜10 あく
- 描画は今の層と、その下の二層だけ（`updateTowerTiers`）。**上の層はカメラを塞ぐので描かない**
- 塔の外観（`towerShell`、高さ 52 の四面）は前庭にいる時だけ描く
- 眼下の街（北、z −90〜2、高さ 0〜12。窓の灯りは鐘・時の再開で変わる）は描画の層 −1 で**いつも描く**
- カメラは追従の距離 7・高さ 5.6〜11.6（高さの設定 5 段）。壁に当たって寄る仕組みは無い

## 2. 原因
1. 低い壁（2.4）の上と、描かない上の層の間（6〜8 の隙間）から、塔の外が素通しで見える。カメラは上から見下ろすので、
   壁の上を越えた視線が眼下の街に届く（測定: 坂 r0 の途中で 1928 画素、4 層の北・坂 r3 でも漏れる）
2. カメラが外壁の外へ出る（外壁沿いの坂・帯でカメラが外壁の向こうになる向き）と、塔の角の向こうが直接見える
3. 外観は塔の中では描かない（描くとカメラを塞ぐ）

## 3. 方針
- 外壁のすぐ外側に**内側だけを向いた面**を、地面の下（−4）から屋上より上（62）まで立てる。四面で一つのメッシュ、当たり・影なし。
  1 層の門（南の外壁の口、x −266〜−258・高さ 3.2）は開ける
- 描くのは塔の中で鐘楼より下（`towerTierAt(y) < TOWER_VIEW_TIER = 4`）の間だけ。鐘楼の床（y 33.5 から鐘楼の扱い）に出た瞬間に消える
- 内側だけを向くので、外壁の外に出たカメラの手前の面は描かれずプレイヤーを隠さない。ただし塔の角の向こうが見えるため、
  面がある間はカメラを外壁の内側に留める（`clampTowerCamera`、13 の `updateCamera` の通常の追従とボスの注視の二か所）
- 変えないもの: 層の構造・壁・床・坂・仕掛け・敵の配置・会話・鐘楼より上の見え方・空・霧・光（`updateAltitude`）・塔の外観

## 4. 検証の方法
`tests/clocktower-view.spec.js`: 街だけを不透明のマゼンタで描いた一枚を小さな描画先へ描き、色で数える（深度・裏面の省略・描画の層は本番と同じ。
色の変換を通さない）。塔の中の 16 か所 × カメラの向き 8 × 高さ 2（低め・高め）＋ 自動追従 4 で 0 画素。鐘楼では 200 画素より多い。
直す前に同じ試験で漏れを再現した（坂 r0 の途中 1928 画素など）。
