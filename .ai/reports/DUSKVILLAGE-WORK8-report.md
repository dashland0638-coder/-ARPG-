## 1. 総合評価

WORK 2〜7 で作ったものを仕様と突き合わせ、**新しいものは1つも足していない。**
今回変更したのは「Scenario Test Mode の開始地点の位置1件」だけで、
ゲーム側の数値・敵・演出・進行はすべて据え置き。

シナリオ構造は仕様どおり通っている:

```
入口 → 中央広場 → 魚屋 / 住宅 / 船小屋 / 商店街 → 水門前 → 水門守の残響
     → 水門開放 → 村の奥 → 村の残響 → 記憶の解放 → 夜明け → 酒場
```

| 観点 | 判定 |
| --- | --- |
| 一本道に感じすぎないか | **適切**。中央広場から魚屋・住宅・船小屋が三方向に分かれ、どれも寄り道（戦闘も記憶も必須ではない） |
| 迷いすぎないか | **適切**。本筋は南→北の一方向で、ミニマップに場所名が出る |
| 各場所に意味があるか | **成立**。魚屋=帳簿の切れた一行 / 住宅=約束 / 船小屋=舟 / 商店街=話さなかったこと / 水門=記録。5つが最後に繋がる |
| 戦闘の間隔 | **適切**。広場(水鏡×2) → 住宅(泡沫) → 船小屋(写し身) → 商店街(複合) → 水門前(記憶漁師) → 水門(中ボス) → 村の奥(なし) → ボス |
| 静かな時間が長すぎないか | **適切**。敵がいないのは村の奥だけで、そこには5つの記憶が置いてある |
| テーマのつながり | **成立**。§23 に詳述 |

大規模なマップ改修はしていない。

## 2. 探索テンポ

この環境は実測 3〜7fps、`dt` が 0.05 で丸められるためゲーム内時間が実時間の
1/5〜1/10 しか進まない。**実時間の数字ではテンポを判断していない。**
判断材料にしたのは「歩く距離」と「イベントの間隔」。

| 区間 | 距離(ユニット) | 途中にあるもの |
| --- | --- | --- |
| 入口 → 中央広場 | 約56 | 木橋・道標・入場の演出 |
| 広場 → 魚屋 / 住宅 | 片道 約45 | 小道・記憶1つずつ |
| 広場 → 商店街 | 約36 | 複合戦闘・屋台の記憶 |
| 商店街 → 水門前 | 約26 | 水路・記憶漁師 |
| 水門前 → 水門 | 約34 | 記録3つ・中ボス |
| 水門 → 村の奥 → ボス | 約70 | 記憶5つ（敵なし） |

**「歩くだけの時間」が連続するのは村の奥の70ユニットだけ**で、そこは記憶が
5つ置いてあり、§22 の「静けさを体験させる場所」として意図どおり。
移動速度・建物間距離・カメラは変更していない。

## 4. 各敵の調整結果

**数値は1つも変更していない。** 以下は確認結果。

### 4-1. 水鏡の影（§9）

| 観察できる差 | 本体 | 分身 | 比 |
| --- | --- | --- | --- |
| 波紋の間隔 | 2.1秒 | 1.15秒 | 1.83倍 |
| 向き直り | 3.0 rad/s | 7.5 rad/s | 2.5倍 |
| 攻撃の予兆 | 0.72秒 | 0.34秒 | 2.1倍 |

**判定: 本体判別可能。** 3つとも比が1.8倍以上あり、どれか1つを見れば判断できる。
観測の灯はこの差をさらに広げるだけ（灯り無しでも差は残ることをユニットテストで固定）。
過剰・不足ではないと判断し、**据え置き**。

### 4-2. 泡沫の群れ（§10）

| | 値 |
| --- | --- |
| 単独時の上限 | 7 |
| 他の怪異と居合わせている時 | 4 |
| 増殖間隔 | 6.5秒（交戦中のみ） |

**判定: 単独時は適切。商店街の同時最大は要観察。**
商店街の最悪ケースは「水鏡の本体1＋分身2」＋「泡沫4」＋「写し身1」= **8体**で、
これはボス戦の Phase 3（4体＋残響3）より多い。

ただし、

- 波は1つずつ出る（同時に湧かない）ことは実機とユニットテストで確認済み
- 8体そろうのは「水鏡を倒さずに放置し、泡沫も散らさない」場合だけ

この環境（4fps）では**過密かどうかを目で判断できなかった**ため、
数値は変えず §11 で **TUNABLE（下げる方向）** として記録した。
下げる場合は混戦時の上限 4 → 3 が最初の候補（1行）。

### 4-3. 写し身（§11）

`WATCH → MIMIC → WATCH` の循環を実機で確認済み（WORK 4）。
コピーするのは現行の Attack Snapshot（魔法弾のみ・1回・威力0.8倍）で、
**全スキルの完全コピーへ拡張していない。** 現状を完成形として評価:

**判定: 適切。** 「攻撃する → 真似される → 避ける」の読み合いが1回で完結し、
情報量が増えすぎない。

### 4-4. 記憶漁師（§8）

狙うのは 0.8 秒前の位置。実機（WORK 5）で:

- 歩いている時 … 輪が背中側に出る → 当たらない
- 止まっている時 … 輪が足元に出る → 当たる

**判定: 予備動作を認識可能。** 予兆（0.85秒）の間は当たらず、見てから出られる。
観測の灯は予兆を1.45倍に伸ばすだけで、**着地点は変えない**（ユニットテストで固定）。
Phantom Step 使用時は「幻影には過去が無い」ので今の位置へ投げる。据え置き。

### 4-5. 水門守の残響（§12）

本体 `MOVE → WINDUP → OPERATE` の循環を Arena で確認済み（WORK 6）。
残響は1.6秒後に同じ場所で同じ操作をなぞる。

**判定: 時間差は認識可能。** 本体には予備動作があり残響には無いので、
「どちらが先に動いたか」で見分けられる。ルール（敵登録しない・狙えない・
倒せない・追跡しない）は変更していない。1.6秒も**据え置き**。

### 4-6. 村の残響（§13）

| | 分身 | 泡沫 | 写し身 | 残響 | 合計 |
| --- | --- | --- | --- | --- | --- |
| Phase 1 | 2 | 2 | – | – | 4 |
| Phase 2 | 2 | 3 | 1 | – | 6 |
| Phase 3 | 1 | 2 | 1 | 3 | 4＋残響 |

**判定: Phase 3 で「ただ忙しくなる」にはなっていない。** 敵の総数は
Phase 2 の6体 → Phase 3 の4体へ減り、代わりに残響が出る。
この方針は維持（ユニットテストで「総数が増えないこと」を固定済み）。

**判定: 将来候補として残す（削除しない）。**

## 16. 未確認項目

| 項目 | 理由 |
| --- | --- |
| **4職の戦闘手触りの比較**（§6） | Arena で4職とも水鏡の影に交戦できることは確認したが、この環境の自動入力では狙いを付けられず（特に遠距離職）、**手触りの比較にならなかった**。強弱ではなく「距離感・予兆を見てから避けられるか」を見るには人の操作が要る |
| **商店街の同時8体が過密かどうか**（§10） | 4fps では画面の読みやすさを評価できない。数値は変えず TUNABLE として記録 |

| **初回探索15〜25分 / 全体30〜40分**（§4） | ゲーム内時間が実時間の1/5〜1/10 しか進まないため、実時間では測れない。距離とイベント間隔で代替評価した |
| **実機GPUでのライト数の影響**（13-1） | ソフトウェア描画では差が出ない |
