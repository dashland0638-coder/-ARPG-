# CLOCKTOWER-003 — 調査と方針（Analyzer / Planner）

## WI-1 鐘の後の昇降台

### 現状
- 鐘（T4 の綱を「調べる」）→ `ringTowerBell` → 昇降台 `low → armed`（1.4 秒）→ `up`（3.2 秒で T5 の前室へ）→ `top`
- 初めての鐘は演出（街の灯りが揺れる → 台詞 3 つ。最後に「乗るぞ、台が上がる」）。演出の間は乗り物を止める（`updateTowerDecor` の `if(cutscene) return`）
- 上の台は、鐘を鳴らすと降りる（`downCall`）。降りた台は `low`（留め金が掛かった状態）に戻る

### 根本原因
1. 演出が終わって操作が戻ってから **1.4 秒** で台が上がる。綱から台までは 3〜4 歩。台の場所は演出で映らず、目印も音も無いので、気付かずに乗り遅れる
2. 乗り遅れると台は上に残る。戻すには「鐘をもう一度鳴らす（降りる）→ 降り切ったらもう一度鳴らす → 1.4 秒以内に乗る」という、どこにも説明の無い手順が要った（進行不能ではないが、事実上の詰まり）

### 方針
- 鐘の意味（振動で留め金が外れる）は変えず、「留め金が外れたら台は下の乗り場で待つ（`ready`）→ 乗ると上がる」に変える
- 初めての鐘の演出の最後に、台を映して留め金が外れる所を見せる（台の灯りが点く・金属音と鎖の音）。台詞と順番は変えない
- 目印: 台の柱の上の角灯（自分で光る材質。待っている間は脈打つ）と、乗り場の床の枠（待っている間だけ）。点光源は足さない
- 乗り遅れ: 上に空の台があり、人が下の階にいれば 1.5 秒でひとりでに戻る（「昇降台が降りてきた」と短く知らせる）
- 上の階（6 層）から下りる: 上の口に近づくと台が上がってくる。上で乗って待つと下りる・鐘で降りる（以前のまま）
- 初めて留め金が外れた時に一度だけ短い案内（上の帯。UI-VISUAL-001 の物語の通知）

## WI-2 管理人と娘の影

### 現状
- 塔の影はどれも本編の演出の中で `spawnApparition` で出し、演出の中で `towerFade` で消す（T0 の止まった人々・縦穴の縁から見下ろす管理人、T1 の作業台の父と娘、T3 の食卓の父と娘）
- 人影の濃さ（現れる・消える）は `updateApparitions` が進める。これは毎フレームの通常の更新（会話・演出が無い時）からしか呼ばれない

### 根本原因
1. **演出の間は `updateApparitions` が呼ばれない**（14-hud-boot の演出の分岐に無い）。演出は始まった瞬間から `state.dialogueActive` が立つので、影は濃さ 0 のまま演出の最後に「消える」状態になり、演出が終わった後、濃さ 0 から消えて取り除かれる ―― 一度も見えない
2. 色が暗い（`0x4a4238` / `0x6a5a80`、濃さ 0.5）。照明に左右されない材質なので、暗い塔の中ではほとんど見分けられない
3. T0 の縦穴の縁の管理人は、見上げるカメラから約 25 先で人の大きさ（画面で 10 画素ほど）、しかも縦穴の真ん中に吊られた大鐘の真後ろ

### 方針
- 演出の分岐でも `updateApparitions` を呼ぶ。**時計塔だけ**（他のダンジョンへ波及させない）
- 塔の影は淡い色の半透明（管理人＝灰褐色 `0xa89c88`・娘＝藤色 `0xbcaee0`・止まった人々＝青みの灰）。自分で光る材質のままなので、通常の NPC のように明るくはならない
- 縦穴の縁の管理人は、鐘楼の縁の北西の角（大鐘の脇、大時計の光のすぐ下）に、×2.6 の大きさで立たせる

## 残るリスク（範囲外）
