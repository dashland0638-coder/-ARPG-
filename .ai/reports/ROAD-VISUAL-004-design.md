## 3. 時間帯の表と、変わるきっかけ
時間帯は**物語の進行で決める**（実時間の時計は使わない）。引き返しても巻き戻らない（DEC-006 EX-2 と同じ）。

| 時間帯 | 始まるきっかけ | 区間の中の進み方 |
| --- | --- | --- |
| DAY | 出撃（宿場） | 宿場〜原野の分かれ道（N-2）までは一定 |
| AFTERNOON | N-2 の帯を過ぎた | 原野の後半を北へ進むほど日が傾く（z で補間） |
| SUNSET | 谷の入口（R3-01） | 谷を北へ進むほど深くなり、山道の野営地（z 458）で最も深い夕暮れ。出会い（R4-00）と加入はこの中で起きる |
| NIGHT | 森に入る（R4-01、加入の後だけ通れる帯。弓師「……暗くなってきました」） | 森 → 遺構の門 → 遺構。約 8 秒かけて夜へ |
| DEEP_NIGHT | 古き守り手の戦闘の始まり（R3-4b） | 戦闘の間だけ。倒すと NIGHT へ戻りかけ、そのまま夜明けの始まりへ |
| DAWN | 古き守り手を倒した（R4-05）。R3-4b より前の仮の条件: 遺構の北の端（z ≥ 615）を過ぎた | 峠（R4-06）までに薄紫 → 橙。道の果て（エリア 5）に入ると金色。R5-01「ここで、少し休もう」の暗転で日が昇り切る |

- 指示の表（宿場から出発 DAY / 原野 AFTERNOON / 谷・野営地 SUNSET / 加入 SUNSET / 遺構 NIGHT / 古き守り手 DEEP_NIGHT / 道の果て DAWN / 石環 DAWN）と一致させてある
- 指示の第四幕の「山道」は、遺構の後の山道と峠として扱う（遺構を抜けると空が白み始める）

## 4. 景観・会話・音（幕ごと）

### 第一幕 DAY — 旅立ち
- 光: 高い太陽（今の向き）、強い日差し、青空。影は短い
- 構図: 宿場の門の見晴らし（R3-T2 の `sceneCamShot`、DEC-026 HD-2 = B）で、道の先と遠くの山を見せる
- 会話: 承認済みの R1-01（ここまでの旅を振り返る）・R2-01（「……広いですね」）。軽い会話はこの幕に集める
- 音: 風・鳥・葉ずれ（今の `forest` の帯と同じ）

### 第二幕 AFTERNOON → SUNSET — 移動と出会い
- 光: 太陽が西へ下がり、色が白 → 黄 → 橙。影が長くなる。空は青 → 橙 → 赤紫
- 谷の水面: 空の色を映す（基準の色を橙寄りに）
- **野営地（山道の入口）**: 焚き火を景色の中心に
  - 夕暮れ: 周りの地形と仲間の姿は見える。焚き火は明るい点
  - 炎の揺らぎ（形の拡縮）と、地面の光だまり（村の作法）を足す
- 会話: 減らす。出会い（R4-00）の一幕が中心（台詞は R3-4a のまま。変えない）
- 音: 鳥が減る。風。焚き火のはぜる音（合成で足す）

### 第三幕 NIGHT → DEEP_NIGHT — 試練
- 光: 空は紺 → 暗い青。太陽の光を月の光（青白く、弱く、高い）に替える。霧を濃くして奥行きと不安を出す
- 局所の光: 灯籠（`ROAD2_LANTERNS`）・焚き火・魔法使いの杖・影の旅人の斬撃の色が目立つ
- **見やすさ**: 顔・衣装・敵の輪郭はリムライト（冷たい色）で分ける。半球光は下限を決める（§6）
- DEEP_NIGHT（古き守り手）: さらに暗く、霧を濃く。守り手の弱点の予兆（正面が硬い・背後）は、光ではなく形と色で見せる（暗くても読める）
- 会話: 間を長く。短い気遣い・警戒（承認済みの R4-01・R4-02 鐘。新しい行は §4-1 の案）
- 音: 風を弱く、遠いざわめき（`distantStir`）、虫の音（合成で足す案）。鳥は鳴かない

### 第四幕 DAWN — 道の果て
- 光: 空が紺 → 薄紫 → 橙 → 金。太陽は進む先（北東）の低い所から上がる
- 遠景: 山並みと霧の色に朝日を映す（霧の色 = 地平の色）
- 峠（R4-06）: 道の果てが朝焼けの中に見える。影の旅人「……まだ、続いています」（承認済み）
- 石環: 朝日を背にした輪郭を見せる。A-9（影が一瞬だけ太陽と違う向きへ伸びる）は、低い朝日で影が長いので、かえって読みやすい
- 野営地（道の果て）: 焚き火は残るが、自然光に負けて存在感が弱まる
- 会話: 増やさない。景色を見せてから、R5-02〜R5-04 の短い言葉で終える（承認済み）
- 音: 鳥が戻る（遠い鳥）。風は弱く

## 5. Three.js での作り方

### 5-1. 時間帯の管理（新規 core、村の作法を広げる）
- 新規 `src/core/road-daylight.js`（state・THREE に依存しない）
  - `ROAD_DAYLIGHT`: 6 つの時間帯の値の表（空の天頂・地平・霧の濃さ・太陽の色と強さと向き・半球光の空と地の色と強さ・リムの色と強さ・水面の基準の色・自発光の強さ・光だまりの濃さ）
  - `roadDaylightTarget({area, z, joined, nightBegun, guardian, dawnBegun})` → 目標の「位置」（0 = DAY 〜 5 = DAWN の連続値。区間の中は z で補間）
  - `advanceRoadDaylight(cur, target)`: 戻らない（大きい方）。出撃し直した時だけ直接置く
  - `stepRoadDaylight(pos, target, dt)`: 数秒で追いつく（`stepDuskBandPos` と同じ形）。`dt` は 0.1 秒で頭打ち（低い FPS でも飛ばない）
  - `roadDaylight(pos)` → その位置の値（`lerpHex` は `dusk-light.js` のものを使う。線形光の空間で補間）
- 道（新）の毎フレーム（`updateRoad2`）で、値を光・空・霧・水面・自発光へ当てる
- 露出は **固定**（K-11 / DEC-025）。`state.brightness`（設定の明るさ）はそのまま掛かる

### 5-2. 空・太陽・月
- 空: 道（新）だけに、低い分割の球（内側）を 1 枚。頂点の色で天頂 → 地平のグラデーション、太陽の側だけ明るく。`fog:false`・`depthWrite:false`・カメラに付ける。描画 1 回
- 太陽・月: 板 1 枚（向きに置く）。夜は月の色
- 星: 任意（品質「高」だけ、Points 1 回）。T4 で FPS を見て決める
- 霧の色は地平の色にそろえる（遠景が空に溶ける）

### 5-3. 太陽の向き（共通コードの小さな変更）
- 今は `13-update-loop.js:2388` で「プレイヤー + (30, 45, 20)」に固定
- 変数 `sunOffset`（既定 = 今の (30, 45, 20)）を足し、道（新）だけが時間帯で替える。ワールドを替える時に既定へ戻す（`disposeWorld`）
- 他のダンジョンは既定のまま（見た目は変わらない）。単体試験で既定値を確かめる

### 5-4. 焚き火・灯籠・魔法の光（点光源は使わない）
- 道（新）は「点光源は使わない」作りになっている（`road2BuildCamp` の注記）。光の数が変わるとシェーダーの作り直しが起きるため、これを守る
- 夜の灯り
  - 自発光（`M.glow`）の強さを時間帯で上げる（焚き火・灯籠が共有）
  - 地面に光だまりの板（村の `duskLightPoolTexture` と同じ作法。加算・深度を書かない）を、今いるエリアの野営地と灯籠の下に置く
  - 炎の円錐の拡縮で揺らぎ。音（はぜる音）と同じ周期
- 夜明け: 光だまりを薄くし、自発光を下げる（自然光に負ける）

### 5-5. 保存・再出撃・テストモード
- 新しいセーブ項目は作らない。時間帯は `state.roadArea`（到達）と出撃の中の出来事（森に入った・守り手と戦っている・倒した）から導く
- 出撃の中の出来事は `buildRoad2` で初期化（羅針盤・加入と同じ）
- テストモードと本編で同じ式。テストモードは通常のセーブへ書かない（変わらない）

### 5-6. 環境音・BGM
- `currentAmbienceZone` の `road2` を、時間帯で `roadDay` / `roadDusk` / `roadNight` / `roadDawn` に分ける（`AMBIENCE_ZONES` に足す）
- 足す合成音（`src/audio/audio.js`、音源ファイルは足さない）: 焚き火のはぜる音（野営地の近くだけ）、夜の虫の音
- BGM は新しい曲を作らない（§9）。夜は今の BGM の音量を少し下げる程度

## 6. 見やすさ（iPhone の横画面）
- 夜でも、キャラクターの顔・衣装・敵の輪郭が分かること
  - キャラクター・敵の材質の色は変えない（光で作る）
  - リムライトは夜に冷たい色で強める
  - 半球光の強さの下限を決める（初期値の案: DEEP_NIGHT で 0.16）
- HUD・羅針盤・ミニマップは光の影響を受けない（HTML）
- 確かめ方（T7）
  - E2E で各時間帯のスクリーンショットを撮り、主人公の周りの明るさと背景の明るさの差を測る（数値の下限を決めて試験にする）
  - 設定の明るさ（`state.brightness`）の各段で、夜が真っ黒にならないこと
  - 実機（844×390）で、夜の遺構・DEEP_NIGHT の守り手戦・夜明けの逆光の石環を見る

## 7. 性能
- 毎フレーム増えるのは、数個の色の補間と代入だけ（村と同じ）
- 描画: 空の球 1・太陽／月の板 1・光だまりの板（今いるエリアの分だけ）。点光源・影の数は増やさない
- 低い太陽: 影が長くなり、影の範囲（20〜34）の外で切れることがある。夕暮れと朝日だけ、影の範囲を少し広げるか、影の濃さを下げる（T3 / T5 で実機を見て決める）
- 霧が濃い夜は、遠景の板が見えなくなるだけで、描画の数は変わらない（必要なら夜は遠景の板を描かない）
- 低い FPS: 補間の `dt` を頭打ちにする。時間帯の切り替えで止まったり飛んだりしない
- 描画回数の E2E（`road2.spec` の scenery calls）に、各時間帯の値を足す
