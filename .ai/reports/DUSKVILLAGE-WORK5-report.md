## 3. 商店街

### 3-1. 置いたもの（§3）

WORK 2 の看板・空の棚・帳場・木箱・樽に加えて、

- **屋台** ―― 天幕だけ張ってある。売り物は無いが、壺が2つ残っている
- **作業台と椅子2脚** ―― 工具が出したまま
- **秤** ―― 皿が片方だけ下がり、釣り合っていない
- **三軒目の店（入れる）** ―― 棚と台だけ。屋内の灯りを1つ
- **水路** ―― 商店街の脇を通って水門のほうへ流れる。浅い掘割で、渡し板が1枚

店舗は4棟（うち入れるのは2棟）。**壁にはしていない** ―― ここは戦う場所でもあるので、
水路で逃げ道を割らない。真ん中は空けて、物は壁沿いに寄せてある（複数の怪異が
同時にいても画面が詰まらないように）。

廃墟にはしていない。壊すのではなく、**途中で置かれたまま**にしてある。

### 3-2. 商店街の記憶（§4）

屋台のそばで一度だけ。これまでの記憶（魚屋・住宅・船小屋）は「失われたもの」
だったが、ここだけは **村人が話したがらなかったこと** が残っている。

```
（風が止む・食器の音）
  屋台をはさんで、輪郭がふたつ。向かい合ったまま動かない
  「あの話は、もういいだろ」
  「……子どもには」
  「だから、もういい。忘れた方がいい」
  剣士　　「……何の話を、やめたんだ」
  魔法使い「分かりません。ただ、魚屋の帳簿にも途中で切れた一行がありました」
  剣士　　「水門の、と書いてあったやつか」
  魔法使い「覚えていたんですね」
  剣士　　「お前が読み上げたからな」
```

**何を恐れていたのかは言わない。** 断片は別々の場所に置いてある:

| 場所 | 断片 |
| --- | --- |
| 魚屋の帳簿（WORK 3） | 「水門の件について――」で途切れる |
| 住宅（WORK 4） | 子供の約束「明日、船に乗せて!」 |
| 船小屋（WORK 4） | 「……ねえ、まだ?」 |
| 商店街（WORK 5） | 「もう、その話は――」「忘れた方がいい」 |
| 水門の古い記録（WORK 2） | ある日から水位の欄だけが空白になる |

並べるのはプレイヤー。こちらからは答えを出さない。

## 4. 複合戦闘（§5・§6）

### 4-1. 時間差で出す

商店街の部屋に入った時点から数え始め、**1つずつ**現れる（`core/encounter-waves.js`）。

| 波 | 内容 | 出る条件 |
| --- | --- | --- |
| 1 | 水鏡の影 ×1 | 入った時点 |
| 2 | 泡沫 ×3 | 9秒後、または水鏡の影と交戦した時点 |
| 3 | 写し身 ×1 | 20秒後、または水鏡の影が分裂した時点 |

「時間 か 合図 の早いほう」にしてあるのは、**棒立ちでも急いでも進む**ようにするため。
合図だけにすると手を出さない限り進まず、時間だけにすると手応えと無関係に湧く。

出現位置は商店街の端。プレイヤーの真上には湧かせない ―― 「気づいたら隣にいた」
ではなく「向こうから来る」ように見せる。

**出し切ったら終わり。倒しても湧き足さない。**

記憶や会話の最中は波の時計を止めてある ―― WORK 3 以降、演出中も村の時間は
動き続けるので、そのままだと記憶を見ている間に次の波が出てしまう。

### 4-2. 正解の順番は決めていない（§6）

コード側にも「この順で倒せ」に相当する分岐は無い。
`encounter-waves.js` が決めるのは **いつ現れるか** だけで、何から倒すかには一切関与しない。

- 水鏡の影 → 見分ける
- 泡沫 → 増える前に散らす
- 写し身 → 自分の攻撃が返ってくる

どれから手を付けても攻略できる。

### 4-3. 過密にしない（§9）

泡沫の増殖上限を、**他の怪異が同じ場所にいる間だけ** 7 → 4 に下げた
（`foamCapFor()`）。見分ける相手と増える相手が同時に画面を埋めると、判断ではなく
反射の戦いになるため。泡沫だけを相手にしている時（住宅まわり）の手応えは今までどおり。

分身（水鏡の影が分裂したもの）は「他の怪異」に数えていない ―― 分裂のたびに
泡沫の上限が動くと、プレイヤーには理由が分からない変化になる。

### 4-4. 魔法使いが強すぎないこと（§7）

魔法使いに固有の優遇は足していない。使えるのは WORK 3〜4 のものだけで、
どれも **他職が詰まないこと** を先に担保してある:

- 観測の灯 → 差を広げるだけ。灯りが無くても差は残る（`mirror-shade.test.js`）
- 幻影歩法 → 釣られ方が敵ごとに違う（`DECOY_PULL`）
- 範囲魔法 → 泡沫をまとめて処理しやすいが、**上限があるので1体ずつでも必ず終わる**

## 5. 戦闘後の静けさ（§11）

波を出し切って、残りがいなくなったら **そこで終わり**。次の敵は出さない。
終わったことを台詞では言わず、`ambienceHold` で風と水音が戻るだけにしてある。
敵がいなくなったぶん、壊れた棚・帳簿・水路・看板が目に入る。

## 7. 記憶漁師（§13〜§19）

### 7-1. 何をする敵か

プレイヤーが **いま立っている場所ではなく、0.8秒前に立っていた場所** へ網を投げる。

```
溜め（身体が沈む）
  → 網を投げる
  → 0.55秒かけて「少し前の場所」へ落ちる
  → 0.85秒の予兆（輪が縮む）      ← ここでは当たらない
  → 発動（0.25秒）                ← ここだけ当たる
```

**追尾ではない。** 落ち先は投げた瞬間に決まり、そこから動かない ――
避けたあとに戻ってきて当たる、という後出しはしない（§16）。

立ち止まっていると自分の足元に落ち、歩き続けていれば背中側に落ちる。
逃げ方を覚える敵ではなく、「自分がどこにいたか」を意識させる敵。

### 7-2. 足取り（§14）

既存の位置履歴は無かったので、最小構成を新規実装した（`core/position-history.js`）。

- 記録するのは `{t, x, y, z}` の4つだけ
- **0.12秒ごと**に記録する。毎フレーム押すと fps によって同じ1秒の中身の密度が
  変わり、この環境（実測1.6fps）と実機とで遡れる長さが変わってしまう
- **3秒より古いものは自動で捨てる。** 長く遊んでも配列は伸びない
  （ユニットテストで10分ぶん回して上限を固定してある）
- 履歴がまだ短いときは、持っている中でいちばん古いものを返す ―― `null` を返すと
  出会い頭だけ無力な敵になる

プレイヤー専用にしていないので、将来ほかの足取りを追う敵が出ても同じものが使える。

### 7-3. 強さ（§19）

HPを盛るだけの強モブにしていない。硬さ（520）は水鏡の影（260）の2倍程度で、
強さは「過去を狙う」という性質そのもので出している。

**網だけの敵にしていない** ―― 網の合間は近づいて殴ってくるので、予兆を見て
動き続けるだけでは終わらない。通常攻撃・回避・体幹・処刑はすべて既存のまま。

### 7-4. 幻影歩法との関係（§17）

狙う相手は WORK 4 の `aggroPoint()` がそのまま返す（プレイヤー or 幻影）。

**幻影を狙うときは、その場所へそのまま投げる** ―― 置いたばかりの幻影に「少し前」は
無いので、記憶を辿りようがない。この一行が §17 の TargetReference そのもので、
将来別のデコイが出ても同じ経路で動く。

釣られやすさは 0.6（水鏡の影 1.0 > 記憶漁師 0.6 > 写し身 0.35）。近くに置かないと
逸れないので、**幻影＝必ず網が飛ぶ、にはなっていない。** 過去位置を狙う基本ルールは
幻影を使わないかぎり変わらない。

### 7-5. 観測の灯（§18）

予兆が 0.85秒 → 1.23秒 に伸び、投げる前の溜めも長く見える。

- **落ち先は変わらない**（ユニットテストで固定）
- 威力も範囲も変わらない
- 「ここへ移動してください」は出さない ―― 見える時間が増えるだけ
- **灯りが無くても予兆はある。** 他職が詰まないことをここで担保している

## 11. 設計上の判断・残課題

### 11-1. 位置履歴を新規実装した（§14 の「なければ新規」）

既存の位置履歴は無かった（`trailSamples` は剣の軌跡用で、武器先端のワールド座標を
スイング中だけ持つもの）。必要な最小構成だけを作り、プレイヤー専用にしていない。

### 11-2. 網は敵とは別に進む（設計判断）

投げられた網は `updateEnemies` の後ろで独立して進む。**漁師を倒しても、すでに
飛んでいる網はそのまま落ちて発動する** ―― 「投げた瞬間に落ち先が決まっている」
という約束をここでも守るため。撃破の瞬間に空中の網が消えると、後出しが無いという
読みのほうが崩れる。

### 11-3. 分身は「他の怪異」に数えていない（設計判断）

泡沫の上限を下げる判定で、水鏡の影の分身は数に入れていない。分裂のたびに泡沫の
上限が動くと、プレイヤーには理由の分からない変化になる。

### 11-4. 数値はすべて暫定

`PROVISIONAL_` がついているもの: 足取りの保持時間(3.0秒)と記録間隔(0.12秒)、
網の遡り(0.8秒)・飛翔(0.55秒)・予兆(0.85秒)・発動(0.25秒)・範囲(2.7)・間隔(4.6秒)・
射程(15)、商店街の波の時刻(0/9/20秒)、混戦時の泡沫上限(4)。実機調整待ち。

### 11-5. 残りの確認（次の WORK へ）

- 商店街の複合戦闘を全滅まで通す（⑧⑨）。4職での比較を含む
- 幻影歩法 × 記憶漁師の実機確認（⑮）
- 村を通しで歩いた時に断片が繋がるか（⑱）

いずれもこの環境のフレームレート（実測1.6fps ≒ ゲーム内時間1/12）が理由で、
実装側に未了はない。

### 11-6. 要判断事項

**なし。** 正式仕様（`docs/SCENARIOS.md` / DEC-001）を変更する必要は生じなかった。
