## Purpose

見た目を変えずに、UI の共通基盤（design token・共通部品の土台）を導入できるか検討し、可能な範囲で導入する。以降の V / C2 の足場にする。

## Scope

- 候補（確定ではない。Analyzer / Planner が設計する）:
  - design tokens
  - spacing
  - typography roles
  - panel
  - button
  - state（selected / disabled / focus 等）
  - icon container
- 既存の見た目を維持したまま、基盤を適用できる範囲の特定と導入

## Out of Scope

- visual redesign（C1 では実施しない）
- token の最終的な値・色・font-size・配置値の決定（V / C2）
- アイコンの作成（UI-002-E）
- HUD の情報設計（UI-002-D）
- module 構造・ES module 化の決定（Planner が提案し Human が判断）

## Planner requirements

- token の階層・命名・配置、共通部品の範囲、既存セレクタへの適用手順を設計する
