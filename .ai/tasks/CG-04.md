# CG-04 幽霊船のテスト(本筋のつながりと物語の並び)

- Goal: 幽霊船の本筋(桟橋→船長)が鍵・関門なしで一続きであること、CG-02/03 の会話が本筋の区間に順番どおり入っていることを unit で固定する
- 根拠: CG-01 の配置表、CG-02(#50)/ CG-03(#51)。#51 の上に積む
- 範囲外: ゲームのコードは変えない。歩いての通しは CG-05 → Human(HE-2)

## 受け入れ条件
1. 入口(桟橋)→ dockDoor → messDoor → crewDoor → cabinDoor → 階段(6,108)→ 貨物室 → 階段(23,122)→ bossHoldDoor の手前 → 船長(bossDoorKey)の座標の並び
2. 本筋の階段は関門(gateKey)を持たない。扉に鍵が付いていない
3. 晩餐の間の会話は messDoor の先・crewDoor の手前で、扉の幅をまたぐ。船長室の会話は部屋の中で cabinDoor への道筋を覆う。甲板の一言は階段の判定圏の手前。船倉の奥の会話は着地点で出る
4. 変異(範囲の移動・縮小、階段への関門追加)で失敗する
