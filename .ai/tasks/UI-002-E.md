## Purpose

emoji / Unicode 依存を整理し、ゲーム専用ピクトグラムへ移行する。icon の size / stroke / silhouette / active / selected / disabled / cooldown などを統一する。

## Scope

- UI 上の emoji / Unicode アイコンの置換
- icon の規則（size / stroke / silhouette / active / selected / disabled / cooldown 等）の統一
- icon の形式（ファイル形式・配信方法）は Analyzer / Planner で調査・設計する

## Out of Scope

- 見本にない新しい visual 方向性の決定（V / C2）
- 台詞・固有名詞の中の記号の扱い（Planner が範囲を提示し Human が判断）
- 3D 空間内の表示（看板・マーカー等）の置換（必要なら Planner が提示）
