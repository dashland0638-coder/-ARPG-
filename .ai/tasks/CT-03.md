# CT-03 時計塔の締め(時喰らい・盗賊の過去・跳ぶ瞬間・島・翌朝の酒場)

- Goal: docs/CHAPTER1_STORY.md §4-4(ボス前・盗賊の過去)と §4-5(跳ぶ瞬間・島・翌朝の酒場)を本編に置き、道へつなぐ
- 根拠: DEC-004 / HD-C1 / HE-1(N-2, N-3, N-4)/ CT-01 §2〜§3。#55(CT-02)の上に積む
- 範囲外: ボスの性能、崩壊・見晴台・着水の仕組み、進行の判定(凍結)、セーブ項目。島の遠景の人影の「グラフィック」は CR-02(加入前の人物の見た目と影の遅れを作る Work Item)で足す ―― ここでは地の文で描く

## 受け入れ条件
1. 時喰らい: 本編では既存の台詞の後に盗賊の一言。周回でも同じ。テストモードは既存のまま。性能不変
2. 盗賊の過去: 崩壊が始まった後、文字盤の裏で一度だけ(見晴台は乗った瞬間に終幕が始まるため)
3. 跳ぶ瞬間: 終幕の台詞だけを本編で差し替え(盗賊「出口は一つだ」/ 弓師「鐘が鳴ります」/ 正しい時刻の鐘)。仕組みは不変。既存の呼び出しは従来の台詞
4. 島: 管理人の懐中時計 / 正しい時刻の鐘 / 対岸を一人で歩く人影(影が遅れる)/ 弓師「……影が、少し遅れていました」。人影に名前・職業名・話者名を付けない
5. 翌朝の酒場(道の導入): 朝の鐘の一行 / 盗賊が時計を返す / 管理人は生還。テストモードは既存の5行
