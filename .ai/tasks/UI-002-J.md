## Goal

鍛冶屋の装備品タブを、装備中の情報（左）と、選んだ部位の候補の一覧（右）の 2 カラムにする。844×390 で品名を読みやすい大きさにし、一覧に十分な高さを渡す。1280×800 の見た目を不必要に壊さない。

## Plan（Planner）

### 構成

```
┌ 見出し（鍛冶屋 / 🪙）┬ タブ（装備品 / スキル） ┐ ← 背の低い画面だけ 1 行にまとめる
├──────────────┬──────────────────────────────┤
│ 左（約 32%）  │ 右（約 68%）                    │
│ ⚔️ 武器 ◆    │ [最強装備] [まとめて売却] 凡例    │
│  古びた杖     │ ┌ 一覧（ここだけスクロール）──┐ │
│  🪄杖 攻撃+2 [外す] │ │ 🪄 月光をたたえた…（折り返す） │ │
│ 🎽 上半身     │ │ 🪄杖 攻撃+6 HP+2 ▲攻撃+4 [装備][売却] │
│ 👖 下半身     │ └────────────────────┘ │
├──────────────┴──────────────────────────────┤
│ 閉じる（下に固定）                                   │
└────────────────────────────────────────────┘
```

- **左**: 3 つの部位を縦に並べる。
  - 各部位は「選ぶボタン（`<button class="gear-slot-select" data-gear-slot>`）」と「外す」ボタンを並べた形にする。ボタンを入れ子にしない。
  - 選ぶボタンには、部位名・所持数・装備名（折り返す）・武器種・能力値を出す。
  - 選択中の部位は、塗り＋左の太い線＋`aria-pressed` で示す（色だけにしない）。
- **右**: 上に道具の行（最強装備・まとめて売却・凡例）、下に**選んだ部位の候補だけ**を並べた一覧。
  - スクロールするのは一覧だけ。
  - 行の中身は、品名（折り返す）と、武器種・能力値・比較の行。ボタンは行の右に横に並べる。
- **閉じる**は今までどおりパネルの下に固定する（`flex:none`）。
- 選んだ部位は、画面を閉じても保持する（ページを読み込み直すと武器に戻る）。最初は武器。
- **文字**:
  - 品名・装備名は 14px（`--ui-fs-item`、新しいトークン）。
  - 能力値・武器種・部位名・比較は 12px（`--ui-fs-body`）。
  - 凡例と所持数は 11px（補助）。
  - 縮めて詰め込むことはしない。
- **タッチ**: 部位を選ぶボタンは 44px 以上。装備する・売却・外す・道具は 36px 以上（今の下限）を保ち、行の中のボタンは 40px を目標にする。
- **背の低い画面**（`max-height:480px`）: 見出しとタブを 1 行にまとめ、2 カラムに約 240px を渡す。
- **幅の狭い画面**（`max-width:560px`）: 1 カラムに戻す（横持ちの対象外の端末の保険）。
- **1280×800**: 同じ 2 カラムの構成。パネルの最大幅（760px）は変えない。

6. 長い品名が欠けない（折り返す）。ボタンの裏に重ならない。
7. 装備可・装備できない・装備中の表示が残る。
8. 装備する・外す・最強装備・まとめて売却・売却・スキルのタブが今までどおり動く。
9. 1280×800 でも同じ構成で崩れない。
10. build・unit・E2E 全件が通る。
