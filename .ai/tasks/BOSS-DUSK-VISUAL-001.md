## 計画（Planner）と決定

### デザインの方針

「水から立ち上がる、重なった人の影」。体は影（暗い胴）で、そのまわりに村の記憶の輪郭が淡い薄布のように重なる。漁師の帽子・前掛け・門番の鎖・鉤・網の束は、村の暮らしの記憶として残す。

### 変更

| 部位 | 変更 | 理由 |
| --- | --- | --- |
| 胴 | 台形の箱 → なで肩から細い腰を経て水の裾へ溶ける一続きの形（loft） | 箱は機械・人形に見えた。人の影の輪郭にする |
| 顔 | 四角い板と大きな丸目 → 帽子のつばの下の暗い楕円の影。目の光は色そのまま、大きさ 0.62 倍 | 一人の顔にしない。目は「どこを向いているか」の手がかりとして残す |
| 首 | 首の付け根ごと片側へ傾いだまま。時々わずかに跳ねる（4.3 秒ごと、0.12 rad） | 姿勢の不自然さで怪異を表す |
| 重なる輪郭 | 胴と頭の淡い人影 2 枚を、左右にずらして重ねる。下は水の裾へ消える（頂点の不透明度） | 口上「いくつもの輪郭が重なって、人のかたちになる」を形にする |
| 薄布 | 腕から袖の薄布、帽子の後ろから背へ垂れ布、水の裾の縁に低い霧。どれも端へ向かって消える | 霧・薄布で幽霊らしさ（村の敵の薄布・霧の映り込みと同じ考え方） |
| 鎖 | 六角の輪 → 縦長の鎖の輪 7 つ | ナット・機械部品に見えた |
| 網の束 | 多面体の塊 → 手から垂れる、下ほど膨らむ袋の形（帽子と同じ油引きの色） | 鈍器に見えた |
| 帽子のつば | 帽子の色 → 影の色 | 夜の光で裏が緑に浮いた。つばの下を暗くして顔を影に沈める |
| 待機 | 上半身が浮き沈みする（足の無い体）。重なりは体と違う周期で揺れる | 人の立ち姿ではない不自然さ |
| 旋回 | 体が向きを変えると、重なりと垂れ布が少し遅れてついてくる | 存在の不自然さ（記憶が遅れてついてくる = 村の「ずれ」） |
| 攻撃の予備動作 | 腕の振りかぶりは今のまま。加えて、振りかぶりが満ちるほど重なりが本体へ集まる（ずれ 15% まで） | 「ばらばらの記憶がひとつになって叩く」。輪と同じ時刻で、予兆を重ねて強める |
| 攻撃後の隙 | 叩き下ろした直後は重なりが散り（ずれ 1.9 倍）、首がうなだれる | 隙の間の個性。撃破の「輪郭がほどけ」とつながる |

### 決定（Agent Decision）

- **AD-1 薄布は村の敵の薄布と同じ「照らされるマットな布」にし、光らせない。** 最初は照明の影響を受けない材質（MeshBasic）で作ったが、独立レビュー（Round 1 M2）で「袖が光の筋、霧が光る笠に見え、村の『発光ではなく透け・薄布』の方針と矛盾する」と指摘され、撮影でもそう見えたので改めた。夜に黒へ沈みきらないよう、本体の胴（0.12）以下の弱い自発光（0.1、差し色）だけを足す。不透明度は 0.26〜0.34（村の薄布 0.36 以下）。光源は足さない。
- **AD-2 配色の表は変えない。** 胴の色（被弾の白から戻す色・段階移行の色と同じ）と ΔE の検査（味方・他の敵から離す）をそのまま守るため。暗い胴は「影」として読ませ、色の差は薄布で出す。
- **AD-3 予兆の輪と腕の振りかぶりは変えない。** 判定と一致していて、分身と同じ色（DEC-008）。重なりが集まる動きは「加える」予兆で、時刻は輪と同じ（振りかぶりの進み具合）。
- **AD-4 段階移行の見た目（記憶の灯り・段階 3 の中心の輪郭）は変えない。** シナリオの演出（DEC-001 / WORK 7）に結び付いているため。今回の新しい胴でも埋もれずに見えることを撮影で確認する。
- **AD-5 分身。** 分身はボスの複製で材質を共有する。姿勢は部品の位置・回転だけを書き換え、材質は書き換えない（unit テストで固定）。新しい部品も分身に複製され、同じ動きが付く（本体と姿で見分けられないという DEC-008 の設計を保つ）。分身の見分け（影なし・足元の水の輪なし）は今のまま。
