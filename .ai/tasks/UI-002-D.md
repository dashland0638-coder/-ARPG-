## Purpose

戦闘画面の情報設計と配置を整理し、キャラクターと敵を主役にする。HUD 情報を「常時 / 条件 / 一時 / 非表示」に分類する。

## Scope

- HUD 要素の分類（常時 / 条件 / 一時 / 非表示）
- 配置の整理（HUD 要素の重なり解消を含む）
- 「画面中央 60%×60% に常時表示 UI を置かない」という Planner 方針の検証（Human Decision ではない。本 Task で検証する）
- 1280×800 / 844×390 の両方での配置

## Out of Scope

- visual redesign（色・書体・形・アイコン。V / C2 / E）
- 支援 AI の HP 表示・目的表示・3 人パーティ HUD・影の旅人専用 HUD（Decision record の Undecided。必要なら本 Task の Analyzer / Planner で改めて判断を求める）
