## Purpose

（2026-09-29 Human の再定義）V で決めた Visual Decision（V-1〜V-7）を、実際のゲーム画面上で確認できる Combat HUD Prototype として実装する。C2 は Design System の全体適用ではなく、見た目・アイコンの視覚言語・状態表現・HUD 部品の視覚的まとまりを実画面で確認するための Prototype（デザインの試作品）とする。

## Scope

- Prototype 対象: Character Status（肖像・名前・HP・HP バー）/ Weapon Badge / HP / Attack / Skill 1 / Skill 2 / Ultimate / Heal / 代表的な通知 1 種 / ゲーム固有アイコン 2〜3 種（Attack・Ultimate・Heal を視覚言語の代表例とする）
- 状態: normal / pressed / disabled / cooldown / Ultimate ready（V-6）
- 表示場所: `?dev=1`（UI-002-B の開発用 UI ゲート）を利用する方向。production では表示しない・save data / gameplay state / 通常進行に影響しない・テストモードと混同しない。具体方式は Analyzer / Planner で確認する（実装は Human Approval 後）
- D との関係: 配置を決めない（「どこに置くか」ではなく「置いたときにどう見えるか」を確認する）

## Out of Scope

- V の Human Decision に無い見た目の決定（AI が補わない。必要なら Human に確認する）
- D1〜D6 のレイアウト・最終配置、既存本番 HUD の見た目の変更
- アイコンシステムの本実装（アイコンセットの体系化・全主要 UI への展開・icon mapping・各画面への適用・Unicode / Emoji からの本格置換）は UI-002-E。C2 の少数アイコン Prototype は E の Scope を奪わない
- MP の新規表示・MP 廃止、Skill 3・Level / XP・所持品チップの復活
- 攻撃モーション・武器形状・キャラクターモデル・VFX・combat logic・damage / balance の変更
- menu / tavern / save / シナリオ画面など C2 対象外の UI、新しいゲームシステム、Emoji の新規アイコン採用
- 画面ごとの情報設計の変更（F / G / H）
