## Purpose

Test Mode・Arena・PERF・Motion Preview・Debug UI など開発用 UI を、本番の通常操作から分離する（HD-3）。

## Scope

- 対象: Test Mode / Combat Test Arena / PERF / Motion Preview / Debug UI（デバッグバッジ・当たり判定表示等）/ その他の開発専用入口
- 開発用 UI への入口を、本番の通常操作から到達できないようにする方式を決めて実装する
- 実装方式は未確定。`?dev=1` は有力候補（HD-3）であり、Analyzer / Planner で既存 E2E への影響と安全性を確認して確定する
- 開発用途（E2E・実機での開発確認）で引き続き使えること

## Out of Scope

- 本番 UI（本編の HUD・画面）の変更（HD-3: 同時実施しない）
- 開発用 UI の見た目の再設計
- 開発用 UI の機能追加
- Decision record の Undecided
