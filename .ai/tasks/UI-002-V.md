## Purpose

C1 の基盤を使って少数の代表画面・代表コンポーネントの UI 見本を作り、Human が実画面で UI の方向性を判断する。V の Human Decision を C2 以降の唯一の visual specification source とする（HD-5）。

## Scope

- 見本の対象: 少数の代表画面・代表コンポーネント（大量の画面は作らない）
- Human の判断対象（候補）: トゥーン感 / マット感 / 中世ファンタジー感 / 書体 / アイコン / パネル / ボタン / 枠線 / 色 / 情報密度
- 見本は 1280×800 / 844×390 の実画面で確認できる形にする
- Human の判断結果を Decision record として記録する

## Out of Scope

- 本番 UI への visual implementation（C2 以降）
- 全アイコンの作成
- 見本以外の画面の作成

## Human Decisions

- HD-5（V は独立した Human Visual Decision Task。V 完了まで C2 以降の本格 visual implementation に進まない。C2 は V の Human Decision を唯一の visual specification source とする）
- HD-4（確認サイズ）
- **UI-002 Visual Decision V-1〜V-7（2026-09-29、Human。本セッションの会話）**。V の Human Approval・V の DONE ではない（下記）。Decision record への転記は未実施（`.ai/decisions/UI-002-human-decisions.md` に UI-002-D の未 commit 変更があり混ぜないため。時期は Human が判断 — `.ai/reports/UI-002-C2-analysis.md` §13 H-8）
  - **V-1 Visual Concept**: 「中世ファンタジー × トゥーン × マット × シンプル」。トゥーン・プレート型を基本とし、古書・革装丁型の中世素材感を加え、魔導紋章型の紋章要素をアクセントに使う。UI よりキャラクターとゲーム世界を主役にする。可愛さ・親しみやすさを残す。過度な高級感・SF 感・未来感を避ける
  - **V-2 Material / Surface**: matte surface、thick outline、subtle shadow、small inner accent、leather / wood / metal を想起させる程度の素材感。glassmorphism・blur・glossy plastic・excessive transparency・excessive gradient・neon・constant glow は禁止
  - **V-3 Shape / Readability**: シンプル、少し柔らかい形状、大きな色面、厚い輪郭、小さい画面でも判別可能、アイコン内部の線を増やしすぎない、シルエットを優先
  - **V-4 Graphic-first / Low Text Dependency**: 主要な操作・状態は icon・silhouette・shape・color・visual state で直感的に識別できることを優先し、文字は補助情報とする。「形を見て意味が分かる UI」が目標。既存仕様上必要な名称・数値は無理に削除しない
  - **V-5 Game-specific Icons**: Unicode / Emoji を新規 UI アイコンに使わない。ゲーム固有のトゥーン調ピクトグラム（thick outline、filled silhouette、simple geometry、16〜24px 程度でも判別可能、同じ意味には同じ視覚言語）。職業・武器・スキル固有の形状を使う（例: 剣士 → 大剣、盗賊 → 両手短剣、魔法使い → 杖＋魔導紋、弓師 → 小弓＋矢、戦騎士 → 長剣＋盾、バーサーカー → 両手小斧、魔導士 → 杖＋大きな魔導紋、鷹の目 → 大弓＋照準／鷹の紋）。全職業分を今作るという意味ではない
  - **V-6 State Visualization**: normal / pressed / disabled / cooldown / Ultimate ready を最低限、明度・塗り・アイコン・進捗・small emblem・overlay 等で視覚的に識別可能にする。色だけに依存しない。常時発光・常時点滅は禁止
  - **V-7 Semantic Color System**: UI の意味色（Background / Surface / Border / Text / Muted / Selected / Danger / Recovery / Special / Disabled）とキャラクター・職業パレットを分離する。職業色は icon accent・selected state・emblem accent・character-related accent に限定する。既存のキャラクターパレットは変更しない
  - **V の完了条件**: V-1〜V-7 の記録 ≠ V Task DONE。V の残作業は「実画面の Visual Sample を見て Human が方向性を確認する」こと
  - **V の完了（2026-09-29、Human）**: C2 Prototype を V の Visual Sample として実画面で確認し、V の目的を達成したと判断。V Status: DONE。V-1〜V-7 の Decision record への転記は UI-002-D の Persistence 後（H-8、未実施）
  - **E 以降の正式アイコン設計への引き継ぎ（Human、設計条件）**:
    - Ultimate: 16px では八芒星の細部が潰れる。細部だけに意味を依存しない形へ正式化する。「特殊技 / Ultimate」であることが小サイズでも分かる方向を検討する
    - Attack: 16px でも大剣シルエットが判別可能。大剣シルエットを維持する方向
    - Heal: 16px でも瓶形状は判別可能。回復用途を小サイズでも補助的に理解できる形を正式化時に検討する
    - Skill 1 / Skill 2: 現在の仮アイコンは 16px でも形状を維持できている。E で正式アイコン化する際の出発点とする
    - 色だけに状態の意味を依存しない
    - Ultimate Ready: 常時発光ではなく、Ready 状態の明確な状態差＋満タン到達時の一回的な反応を基本方向とする
    - 844×390 での最終配置問題は D の責務であり、C2 では修正しない
