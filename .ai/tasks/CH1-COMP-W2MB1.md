## Goal

宵待ちの村の記憶漁師（`atkType:'fisher'`）の攻撃を、見て判断できるものにする。

- 近接攻撃に、見て判断できる予備動作を付ける。
- 必要なら足元の予兆で、近接の範囲と当たる瞬間を見せる。
- 網の予兆の輪が縮んで見え、当たりの範囲（2.7）と合っていない問題を直す。
- iPhone の画面でも見分けやすくする。

## 実装方針（提案）

### 1. 近接の予兆（溜め → 判定）

| 項目 | 今 | 変更後（案） |
| --- | --- | --- |
| 始まる条件 | 2.3 以内、待ち時間が明けた | **同じ**（ここで溜めを始める） |
| 溜め | なし | **0.5 秒**（候補 0.45〜0.6。HD-MB1-1）。体を沈める（網の溜めと同じ変形を流用）。鈴と違う短い音（既存の効果音） |
| 足元の予兆 | なし | 漁師の足元に **半径 2.3 の輪**（外周は判定の半径そのもの）と、溜めの時間で満ちる内側の円 |
| 判定 | 条件を満たしたフレームに 1 回 | **溜めの終わりに 1 回**。判定の式は今と同じ（距離 < 2.3、全周、回避の無敵中は素通り → ジャストドッジ、オーブシールド、ダメージ `round(攻撃力 × 0.7)` = 26） |
| 溜めの間 | ― | 動かない。向きは溜めを始めた時のプレイヤーの方向に固定する（判定は全周なので、向きは見た目だけ） |
| 攻撃の後 | 0.45 秒の `postAtkRecoveryT`、動きは止まらない | **近接の判定の後だけ 0.45 秒は動かない**（専用の止まる時間を持ち、長さは今の `POST_ATTACK_RECOVERY_SEC` と同じ 0.45）。網を投げた後（P07`:3029`）の動きは今のまま変えない。止まっている間は次の溜めを始めない（待ち時間 2.2 秒の中なので、もともと始まらない） |
| 待ち時間 | 2.2 秒（判定から） | **2.2 秒**（溜めの終わりから数える。当たっても外れても同じ。値は変えない） |

- 判定の範囲（2.3）・ダメージ（26）・待ち時間（2.2 秒）は変えない。

#### 1a. 網との優先順（今の順を保つ）

- 網の溜め（`netWindupT > 0`）の間は、今と同じく近接を始めない（P07`:3013` の早期 return）。
- **近接の溜めの最中に網の待ち時間が明けても、網は割り込まない。** 近接の判定（溜めの終わり）まで網の判定（`canThrowNet`）を見ない。網の待ち時間はその間も減り続け、近接の後に網を投げられる。
- この順は unit で固定する（下の unit 6）。

#### 1b. 溜めの中断と、表示の後片付け

| 場面 | 近接の溜め | 足元の表示 |
| --- | --- | --- |
| ダウン（Break。`triggerKnockdown` P07`:5394-5410`。通常敵の分岐） | **取り消す**（溜めの残り時間を 0 に、体の変形を戻す。近接の後の停止も 0 に戻す）。待ち時間は使わない（起き上がった後、条件を満たせば新しく溜めを始める） | 消す |
| 浮き（切り上げで浮いている間。P07`:1031-1039` で AI が止まる。漁師は通常敵で重さが light なので実際に浮く） | 取り消す（P07`:1031-1039` の分岐で行う）。大怯みと違って止まる時間が長く、着地まで溜めを残すと読めなくなるため | 消す |
| 大怯み（0.4 秒の `stunT`。AI が止まる） | HD-MB1-2 に従う。推奨（入れない）の場合は **一時停止して再開**（溜めの残り時間は減らない。表示はそのまま） | そのまま |
| 撃破 | 取り消す（判定しない） | 消す |
| 再出現（P07`:853-870`） | 状態を初期化する（溜めなし・待ち時間なし・近接の後の停止なし） | 消えている |
| Arena の Clear・場所の移動（世界の破棄） | 敵ごと消える | 消す |

- **足元の表示の中心は、毎フレーム漁師の今の位置（`en.group.position`）に置き直す。** 判定は溜めの終わりの漁師の位置から測るので、溜めの間に殴られてノックバックで滑っても（通常敵。P07`:5279-5289` で設定され、P07`:1008-1017` で AI や大怯みより前に動く）、輪の中心と判定の中心がずれない。大怯み・浮きで AI が止まっている間も置き直す（表示の更新は AI とは別に行う）。外周の輪と内側の円は 1 つの Group にまとめ、置き直しと片付けを 1 か所で行う。
- **表示の持ち主は既存の `en.meleeTelegraphMesh` にする**（Rule 0）。この名前のメッシュは、撃破（P07`:5461`）・Arena の Clear（P07`:815`）・世界の破棄（P02`:348`）で既に片付けられている。ダウンと浮きでは `visible = false` にする処理を足す。
- 網の輪（`memoryNets`）は今と同じく敵とは別に進み、場所の移動で消える（`clearMemoryNets`）。漁師を倒しても、投げた網は今どおり落ちて発動する。

## テスト項目

### unit（`tests/unit/memory-fisher.test.js`）

1. 近接の溜めは定数の時間（0.5 秒）で、溜めの終わりに **1 回だけ** 判定する（20fps / 60fps、長いフレーム）。
2. 近接の判定の範囲は 2.3、ダメージの倍率は 0.7（今と同じ値であることを固定する）。
3. 溜めの終わりの距離で判定する（溜めの間に 2.3 の外へ出たら当たらない）。外れても待ち時間 2.2 秒は溜めの終わりから数える。
4. 網の輪の外周は、据わっている間ずっと判定の半径（2.7）と同じ。内側の円は 0 → 1 に満ちる。
5. 網の落ち先・時間・判定（`planNet` / `stepNet` / `netHits`）の既存のテストが変わらず通る。
6. 優先順: 網の溜め中は近接を始めない。近接の溜め中は網を始めない（網の待ち時間が 0 でも）。
7. 中断: 取り消すと溜めは 0 に戻り、判定しない。待ち時間は使わない。一時停止（大怯み）では残り時間が減らない。

### E2E（`tests/dusk-fisher-telegraph.spec.js`、テストモードの Arena）

1. Memory Fisher を出し、近くに立つ。テストモードの記録で `FISHER MELEE — WINDUP` →（HD-MB1-1 の決定値 −0.1〜+0.15 秒）後に `HIT` の順。ダメージの数字 26 は判定の時だけ出て、溜めの間には出ない（前提: training は ★1、`state.debugMode` は偽。Arena の漁師の攻撃力は 37）。

3. 網: `MEMORY NET — THROW` → `ARM` → `BURST` の順、37 は発動の時だけ。
4. コンソールエラーが無い。

## iPhone 実機で確かめること（実装の後）

1. 漁師に近づいたとき、殴られる前に体の沈み込みと足元の輪が見えるか。0.5 秒で輪の外へ出られるか。
