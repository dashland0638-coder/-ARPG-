## Goal

宵待ちの村の記憶漁師（`atkType:'fisher'`）の攻撃を、見て判断できるものにする。

- 近接攻撃に、見て判断できる予備動作を付ける。
- 必要なら足元の予兆で、近接の範囲と当たる瞬間を見せる。
- 網の予兆の輪が縮んで見え、当たりの範囲（2.7）と合っていない問題を直す。
- iPhone の画面でも見分けやすくする。

## Constraints（Human の指示）

- 敵の HP・攻撃力・攻撃範囲を、原則として変えない。
- 水門守の残響（`keeper`）の数値・攻撃は変えない（W2-MB2 で別に扱う）。
- 他の敵へ一括で広げない（洋館の近接・水鏡の影・泡・写し身・ボスには触れない）。
- `basefile.html`、legacy の連結構成、セーブの形式、進行のフラグ、第一章の成長の制約は変えない。
- 見た目だけでなく、攻撃判定と一致していることを確かめる。

## 実装方針（提案）

### 1. 近接の予兆（溜め → 判定）

| 項目 | 今 | 変更後（案） |
| --- | --- | --- |
| 始まる条件 | 2.3 以内、待ち時間が明けた | **同じ**（ここで溜めを始める） |
| 溜め | なし | **0.5 秒**（候補 0.45〜0.6。HD-MB1-1）。体を沈める（網の溜めと同じ変形を流用し、向きはプレイヤーへ固定）。鈴と違う短い音（既存の効果音） |
| 足元の予兆 | なし | 漁師の足元に **半径 2.3 の輪**（外周は判定の半径そのもの）と、溜めの時間で満ちる内側の円 |
| 判定 | 条件を満たしたフレームに 1 回 | **溜めの終わりに 1 回**。判定の式は今と同じ（距離 < 2.3、全周、回避の無敵中は素通り → ジャストドッジ、オーブシールド、ダメージ `round(攻撃力 × 0.7)` = 26） |
| 溜めの間 | ― | 動かない（向きは溜めの開始時に固定） |
| 攻撃の後 | 0.45 秒の `postAtkRecoveryT`、動きは止まらない | **0.45 秒は動かない**（`postAtkRecoveryT` の間、移動を止める。値は変えない） |
| 待ち時間 | 2.2 秒（判定から） | **2.2 秒**（判定から数える。値は変えない） |

- 判定の範囲（2.3）・ダメージ（26）・待ち時間（2.2 秒）は変えない。
- **当たる時刻は、近接の条件を満たしてから 0.5 秒遅れる**（予兆を足すことに伴う変更。意図した変更として記録する）。
- 溜めの間に 2.3 より外へ出れば当たらない（今の判定の式をそのまま溜めの終わりに使うため）。

### 2. 網の予兆の輪

| 項目 | 今 | 変更後（案） |
| --- | --- | --- |
| 輪の外周 | 2.7 → 1.94 に縮む | **2.7 のまま**（判定の半径） |
| 残り時間の見せ方 | 輪が縮む | **内側の円が満ちる**（W2-4a の段階移行の爆発の予兆と同じ見せ方） |
| 落ち先・飛ぶ時間・据わる時間・発動の判定・ダメージ（37） | ― | **変えない** |
| 過去を狙ったときの輪の色（水色 / 砂色） | ― | 変えない |

### 3. 見やすさ（iPhone）

- 輪の色は、夜の村の青い床の上で目立つ暖色（W2-4a と同じ系統）。網の輪は今の色分け（過去 = 水色、今 = 砂色）を残し、内側の円だけ足す。
- 輪の太さ・不透明度は W2-4a の値を出発点にし、実機で見て調整する（数値は判定に関係しない表示だけ）。

### 4. 範囲

- 記憶漁師の個体だけ（`updateFisherAI`、`throwMemoryNet` / `updateMemoryNets`）。網（`memoryNets`）は漁師だけが使う。
- テストモードの Arena の「Memory Fisher」は同じ AI なので、同じように変わる（測定と E2E に使う）。
- 他の敵の近接（洋館の床の弧 `updateMansionMeleeTelegraph` など）は変えない。部品の作法だけ参考にする。

## テスト項目

### unit（`tests/unit/memory-fisher.test.js`）

1. 近接の溜めは定数の時間（0.5 秒）で、溜めの終わりに **1 回だけ** 判定する（20fps / 60fps、長いフレーム）。
2. 近接の判定の範囲は 2.3、ダメージの倍率は 0.7（今と同じ値であることを固定する）。
3. 溜めの終わりの距離で判定する（溜めの間に 2.3 の外へ出たら当たらない）。
4. 網の輪の外周は、据わっている間ずっと判定の半径（2.7）と同じ。内側の円は 0 → 1 に満ちる。
5. 網の落ち先・時間・判定（`planNet` / `stepNet` / `netHits`）の既存のテストが変わらず通る。

### E2E（`tests/dusk-fisher-telegraph.spec.js`、テストモードの Arena）

1. Memory Fisher を出し、近くに立つ。テストモードの記録で「近接の溜めの開始」→ 0.45〜0.6 秒後に「近接の判定」の順。ダメージの数字 26 は判定の時だけ出て、溜めの間には出ない。
2. 溜めの間に後ろへ回避して 2.3 の外へ出ると、26 が出ない。
3. 網: 「投げた」→「据わった」→「発動」の順、37 は発動の時だけ。
4. コンソールエラーが無い。

## iPhone 実機で確かめること（実装の後）

1. 漁師に近づいたとき、殴られる前に体の沈み込みと足元の輪が見えるか。0.5 秒で輪の外へ出られるか。
2. 網の輪が縮まなくなり、輪の外にいれば当たらないか（輪の縁で当たらないか）。
3. 近接の輪と網の輪が同時に出ても見分けられるか。夜の村の床で見えるか。
4. 漁師が「易しすぎる」と感じないか（攻撃力・範囲は同じ）。

## Rollback

近接の溜めの時間を 0 にすると、今と同じ「条件を満たしたフレームに判定」に戻る（定数）。網の輪の表示は、縮む表示へ戻す 1 か所の切り替えにする。
