# CH1-FU-A — 歩行アニメーションの再改善（腕を肩から振る）

依頼: Human「CH1-EXP Follow-up」Work Item A（P1、2026-10-14。iPhone 実機で発見）。
前回: CH1-EXP X-3（#80）。Approval: Human の依頼そのもの。

Status: REVIEWING

## 観察された問題（Human）
- 腕の振りが体の内側に寄りすぎている。
- 肩が十分に動かず、肘から下だけで振っているように見える。
- 胴体は前傾しているのに、腕の振りが弱い。
- 手がベルトの前に張り付く。

## 原因（最新 main を調査）
リグ（`06-player-enemy.js`）の構成:

- 腰（waist、前傾は rotation.x +）→ 肩（armL/armR、Euler 順 XYZ = **z が先**）→ 肘（elbow、x だけ）→ 手。
- 歩行は `13-update-loop.js updateLocomotion` が書く。
- 休め姿勢は `05-rendering-rig.js STANCE_RELAXED`。

1. **腕が内側に寄る・手がベルトの前**
   - X-3 は歩くときも、肩の横方向（y = 捻り、z = 開き）を休め姿勢のまま使っていた。
   - 休め姿勢の z（左 +0.20〜+0.30、右 −0.18〜−0.26）は、z が先に掛かる XYZ では**手を体の中心へ寄せる**向き。
   - three.js で同じ寸法のリグを組んで測ると、剣士の非戦闘の歩きでは次のとおり:
     - 左手 x = −0.13（骨盤の半幅 0.20 の内側）。
     - 肘 x = −0.22（胴の外側の線より内側）。
     - 手が振りのどの位相でも、ベルトの前を通っていた。
2. **肘から先だけで振って見える**
   - 肩の振れ ±20° に対し、肘の追加の曲げが 0.5·swing（約 13.5°）で、肩の 7 割近くあった。
   - その曲げは `max(0, s)` なので、振りの中央で折れ曲がり始める（前へ出るときに急に曲がる）。
3. **止まり・歩き出しの跳ね**
   - 止まった瞬間に swing = 0 になり、振り途中の腕が 1 フレームで基準へ跳んでいた。
   - X-3 は基準の姿勢だけをなめらかにしており、振れの大きさは対象外だった。

## Implementation（既存のリグをそのまま使う）
- `src/core/relaxed-idle.js`
  - `RELAXED_WALK_ARM_BASE` に `twist: 0` と `out: 0.08` を追加。肘 `el` を −0.17 にした。
  - `relaxedWalkStance`: 肩の y・z も、歩くときの値（捻り 0、外へ 0.08 rad ≈ 4.6°）と休め姿勢の間で `stopW` によって補間する。左右で z の符号が逆。
  - `RELAXED_WALK_ARM_SWING` を約 1.2 倍にした（剣士 1.45 / 盗賊 1.15 / 魔法使い 1.45 / 弓師 1.20）。肩の振れは 4 職とも ±23.7〜25.3°。
  - `locomotionElbowBend(phase, swing, combatW, shoulderAmp)`: 非戦闘の肘は、肩の振れの `ELBOW_FOLLOW = 0.35` 倍を `(1 ± s)/2` でなめらかに足す。
    - 前へ振り切ると一番曲がり、後ろでは基準の軽い曲げ。
    - `shoulderAmp` を渡さない呼び出しと、構え（combatW = 1）の式は従来どおり。
  - 新規 `stepArmSwingAmp` / `ARM_SWING_SETTLE_RATE = 7`: 腕の振れの大きさを指数で追う。fps に依存しない。約 0.43 秒で 95%。
- `src/legacy/parts/13-update-loop.js updateLocomotion`
  - 腕は `armSwingAmp`（swing を上の速さで追う値）で振る。
  - 肘には肩の振れ（`armSwingAmp * asw`）を渡す。
  - 脚・足音・土煙・腰は従来の swing のまま。
- `src/legacy/concat-plugin.js`: import を追加した。

**変えていないもの**

- 戦闘の構え（walkW = 1）の腕の基準と肘の式。
- 攻撃・スキル（busy の間は腕を書かない）。
- 回避・空中のポーズ。
- 休め姿勢（STANCE_RELAXED）そのもの。止まると、既存の relaxStopBlend で今までの休め姿勢へなめらかに戻る。
- リグの構造、職ごとの武器の握り・収納。
- 胴の前傾の量（RELAXED_WALK_UPPER）。
  - 腕を大きく振ることで、前傾と釣り合うようにした。
  - 腕はリグ上、前傾した胴に付いている。現行の基準（肩 −0.03）では、歩くときの腕の振りの中心はほぼ鉛直になる（計算で、手は肩の真下 ±0.05 m）。
