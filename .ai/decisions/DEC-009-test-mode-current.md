# DEC-009 — テストモードを現行の本編ルールに追従させる

Status: Accepted（Human の依頼 2026-10-24「WI: TEST-MODE-CURRENT-001」）

## 決定

1. **テストモードの既定ルールは、本編の第一章と同じ**（`TEST_RULES.CURRENT`）。旧ハクスラ系（レベル・経験値・装備ドロップ・転身・パッシブ・スフィア盤・強化・異空間・旧版の台詞）は、開始画面で「🧪 旧成長システム」を選んだ時だけ動く（`TEST_RULES.LEGACY`）
   - `core/chapter1-rules.js legacyGrowthEnabled(testMode, testRules)`。本編は常に偽（変わらない）。`chapter1-rules.js` の「旧システムのコードは消さず、第二章以降の基盤として残し、開発用からだけ触れる」方針はそのまま
   - 呼び出し側（約 60 か所の `legacyGrowth()` の分岐）は変えない。判定だけを変えた
2. **転身・レベルは旧成長システムの時だけ選べる**。開始画面の欄そのものを隠し、見出しに「本編の第一章にはレベルは無い」と書く。現行ルールではレベル 1・基礎職で入る（レベルはステータスに乗らない）
3. **デバッグ用の強さ**は成長と別の倍率（Arena の `💪 強さ ×1(本編) / ×0.5 / ×2`）。最大 HP と攻撃力だけ、`recomputeStats` の最後に、`state.testMode` の間だけ掛ける。速さ・攻撃の時刻・敵の数値には触れない
4. **ボスの段階**: PR #100 の「村の残響を段階3へ」を「⏭ ボスを次の段階へ」に広げる（どのボスでも HP を次の境目 65% / 30% へ。段階の移り変わりは本編の処理）。村の残響の段階 3 の扱い（段階 1・2 の分身を散らす、分身が出るまで攻撃を止める、支援AIを休止）は今のまま
5. **Debug Info の見出し**（敵の行の上の 4 行）にルール・強さ・場所・ボスの段階・支援AIの状態を出す
6. テストモード専用の利便（Skill 2 を最初から持つ、鍛冶屋の画面をどこでも開ける、倒れない、潤沢な薬、セーブしない）は残す。デバッグの道具であり、本編の仕様の取り違えにはならないため
7. `testRules`・`testStatScale` はセーブに書かない。テストモードへ入るたびに決め、タイトルへ戻る時に戻す

## 既存のテストの扱い

`tests/helpers.js startTestMode` に `rules` を足す。`level` を指定したテストは、レベルが旧成長システムにしか無いので `rules:'legacy'` として動く（従来と同じ挙動）。旧成長系そのものを確かめるテストは `rules:'legacy'` を明示する（弱めではなく、確かめる対象のルールを指定する変更）。
