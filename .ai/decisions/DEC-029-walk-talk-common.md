# DEC-029 — 歩きながらの掛け合いを共通機能にする（方針）

Status: Accepted（Human の指示 2026-11-19「PR #134 R3-1 壁の影再設計・歩行中会話の共通機能化方針」）

## Decision
- 歩きながらの掛け合い（R3-1 で道（新）に作った、操作を止めない一行の会話）を、シナリオをまたぐ共通機能として扱う
- 方針の正本は `docs/WALK_TALK.md`（W-1〜W-8: 操作を止めない・戦闘と大事な場面では隠す・繰り返さない・条件と台詞はシナリオごと・位置と大きさと時間は共通・iPhone で読める・大事な会話は専用の窓のまま）
- 今の実装は変えない。一度に広げない・移さない・大きく作り直さない。二つ目のシナリオで使う時に、その Task の中で表示と止める条件を共通の場所へ移す

## Reason
- 掛け合いは探索の空気を出すのに効くが、シナリオごとに作ると位置・大きさ・止める条件がばらつく
- 流し方（`src/core/road-banter.js`）は既にシナリオに依存しない。シナリオに依存するのは表示の id と台詞のデータだけ

## Alternatives Considered
- 今すぐ共通の場所へ移す → 指示により行わない（使う所が道（新）だけで、移す利点がまだ無い）
- 大事な会話も掛け合いで出す → 行わない（W-7。読み飛ばされると物語が伝わらない）

## Consequences
- 新しいシナリオで掛け合いを足す時は `docs/WALK_TALK.md` に従う
- 道（新）の掛け合いの見た目・試験は変えない
