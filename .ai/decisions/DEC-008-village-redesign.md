# DEC-008 — 宵待ちの村の敵と探索マップの再設計

Status: Accepted（Human の依頼 2026-10-23「CH1-COMP：宵待ちの村 敵デザイン刷新＋探索マップ再設計」）

## 決定

1. **マップ**: 村の部屋のつなぎ替えと、通行の仕掛け（閂の門）の追加を認める。`CH1-EXP-X7-village-plan.md` §0/§3 の「部屋の追加・削除・つなぎ替えと新しい仕掛けは Human の依頼が要る」を、この依頼で解除する。DEC-001 の規則（水門が関門、鍵集め・複数レバー・アイテム探しの謎解きは作らない、魔法使い専用の道は作らない、セーブを変えない）は守る
   - 閂の門は「回り込めば外せる」だけで、鍵やアイテムは要らない
   - 水門の両脇の抜け道を塞ぎ、DEC-001 の「水門守との戦闘・観察を経て開く」に戻す（今までの迂回は意図しない抜け道）
2. **台詞と一幕**（DEC-004）は変えない。新しい区画には手記と短い記録（ログの 1 行）だけを置く
3. **敵**: 村の敵の模型・材質・姿勢・予兆の見た目を作り直す。HP・攻撃力・範囲・時刻・速さは変えない（W2-D の時刻の延長は Human の承認待ちのまま）
   - 予兆の輪は「今の判定の時刻と範囲」をそのまま見せるものに限る
   - ボスの段階 3 の残響にも輪を出す（W2-MB2 で「今回は水門守だけ」とした範囲を、今回の「予兆の見え方をそろえる」依頼で広げる。輪の半径 = 判定 3.6、時刻 = 当たる瞬間）
   - **例外（Agent Decision、数値の変更）: 村の雑魚の hitRadius（プレイヤーの攻撃が届く敵の表面）を見た目の体格に合わせる。**
     汎用の毛玉の 0.34 のままでは、新しい人型の体の外側を斬っても届かない／体の内側まで踏み込む必要があり、見た目と判定がずれるため（依頼の「見た目と判定の一致」）。
     水鏡の影・写し身・記憶漁師 0.34 → 0.40、水門守 0.34 → 0.54、泡沫 0.43 → 0.34。敵の HP・攻撃力・攻撃の範囲・時刻は変えない。
     値は `src/core/dusk-enemies.js` の `VILLAGE_PROPORTIONS.footprint` の 1 か所で戻せる
   - **ボスの分身の hitRadius は変えない（0.34 のまま）。** 2.0（ボスの体）に合わせると、段階 3 の分身が約 1.7 遠くから割れ、ソフトロックで本体と分身が同列になる（本体を見分ける手掛かりが変わる）。
     これは見た目ではなく遊びの釣り合いの変更なので、Human の判断に残す（推奨: 2.0 に合わせる。見た目どおりに斬れる）
4. **洋館**は変えない。分析と提案だけを記録する（`.ai/reports/CH1-COMP-W3-mansion-route-analysis.md`）。洋館で回り道を強制するかは、確定済みの仕様の変更なので Human の判断（Escalation）
