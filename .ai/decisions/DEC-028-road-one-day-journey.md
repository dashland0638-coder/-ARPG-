# DEC-028 — 道（新）の「一日の旅路」と、マップの二つのカテゴリー

Status: Accepted（Human の指示 2026-11-17「ROAD-VISUAL-004『一日の旅路』＋マップ設計方針の体系化」。Escalation E-1・E-2 は Human Decision 2026-11-17「E-1: A で OK」「E-2: A で OK」「両方とも承認します」）

## 決定（Human の指示）
| ID | 決定 |
| --- | --- |
| J-1 | 道（新）は、昼に出発し、夕暮れに仲間と出会い、夜の試練を越え、日の出とともに旅を終える。時間帯は DAY → AFTERNOON → SUNSET → NIGHT → DEEP_NIGHT → DAWN。出会いと加入（R4-00）は夕暮れに固定する |
| J-2 | 時間帯は実時間ではなく、シナリオの進行で変える |
| J-3 | マップを「閉じたマップ（ストーリー体験型）」と「フィールドマップ（移動・探索体験型）」に分けて設計する（`docs/MAP_DESIGN_PHILOSOPHY.md`）。第二章以降の基本方針。第一章の既存シナリオを一括で直す指示ではない |
| J-4 | 第一章の道（新）は、フィールドマップの魅力を少しだけ体験させる導入。リスキーモブ・依頼・サブミッションの本格化は第二章以降 |

## Human Decision（Escalation への回答、2026-11-17）
| ID | 決定 | 追加条件（Human） |
| --- | --- | --- |
| E-1 | **A**: 最終戦（高原の大角）は朝日の時間帯。段階 3 の名前は「朝日」（段階 2 は「雲が朝日を隠す」）。低い朝日が獣の影を長く伸ばし、突進の線を示す既存の仕組みはそのまま | 夜明けへの移り変わりと最終戦の始まりが自然につながるよう、シナリオ全体の時系列をそろえる（設計 `.ai/reports/ROAD-VISUAL-004-design.md` §3-2） |
| E-2 | **A**: 道（新）の中に限り、時間帯に応じて太陽・半球光・リム（輪郭光）の強さを変えてよい。**設計 K-11（「補間するのは空・霧・太陽の色と向きだけ」）の明示的な例外** | 強さは既存のマップで使っている範囲の中（`WORLD_MOOD`・`DUSK_BANDS`。半球光 0.13〜0.52、太陽 0.15〜0.95、リム 0.14〜0.30）。露出は固定（今の道の値 0.96 × 設定の明るさ）。他のワールド・ダンジョンには効かせない |

- 両方とも、ROAD-VISUAL-003 の作る順番を守る。**PR #131 の実機確認とマージの前に、これに依存する実装を始めない**

## K-11 の例外（E-2）
- 対象: 道（新）（`road2`）の時間帯の光だけ
- 例外にする文言: `.ai/reports/ROAD-VISUAL-003-design.md:48`（K-11）の「補間するのは空・霧・太陽の色と向きだけ」→ 道（新）では太陽・半球光・リムの**強さ**も補間してよい
- 例外にしない文言: K-11 の「既存のマップの値の範囲で作る」「露出は今の道の値に固定する」はそのまま守る
- 共通の基準（W3-2 / W3-3、DEC-024）は決めない。W3-3 ができたら道（新）の値を合わせ直す
