# DEC-017 — 第一章③ 幽霊船「帰れない」（時計塔との分離）

Status: Accepted（Human Decision 2026-11-07。GHOSTSHIP-REBUILD-001 の設計を承認 → GHOSTSHIP-REBUILD-002 で実装）

## 決定

1. **時計塔との完全分離**: 幽霊船から時計塔の設定（七時十三分・船長室の止まった時計・時計塔の鐘・鐘を鳴らしてほしいという依頼・撃破後の「塔の鐘を鳴らしてくれ」・船と塔を結ぶ伏線）をすべて外す。DEC-004 の **N-1 / N-5 を取り下げる**。時計塔のシナリオそのものは変えない。
2. **物語の核**: テーマは「帰れない」。船長は「全員で帰る」と誓い、錨の鎖を握り続けて船を霧に留めている。陸を探しに小舟で出た五人が戻らず、点呼の数はそろわない。乗り込んだ弓師と魔法使いは空いた席を埋める乗員として数えられ、船は二人を降ろさないため内部の構造を変える。船長が鎖を手放すと錨が海底へ落ち、構造が戻り、甲板への昇降口が開く。
3. **体験**: 小舟で接近 → 係留 → 船底の穴から侵入 → 弓師が帰り道に矢印を刻む → 探索 → 船長室で「今日はここまで」 → 帰還不能（①通路の食堂の扉が船員室へ ②船倉へ下りたはずが食堂、皿が 15 → 17 ③船倉で刻んだ矢印が食堂の柱で奥を指す ④船底の穴が新しい板で内側から塞がれている）→ ループは一度だけ → 錨の鎖を目印に一本道 → 点呼の廊下（甲板長）→ 錨の間（帰港を望む船長）→ 甲板（最後に初めて立つ）→ 縄梯子で小舟 → 酒場。
4. **敵**: 乗組員の残影 4 種（水夫 = 突進、見張り = 射撃、給仕 = 回り込み、船大工 = 強敵）。既存の AI を使い、見た目・配置・出現演出を変える。ミニボスは「沈んだ航海士」→「甲板長」（号笛で一度だけ仲間を呼ぶ）。
5. **ボス**: 名前は「帰港を望む船長」のまま。外見は角灯と錨の鎖を持つ外套の人影。3 段（1 舶刀の薙ぎ払いと鎖の引き寄せ / 2 「総員、点呼！」で水夫の残影 / 3 鎖を両手で握り床をなぞる大きな薙ぎ払い）。鎖の引き寄せは理不尽な拘束・回避不能にしない。
6. **酒場（E-1 = 案 A）**: 時計塔へ向かう動機は既存の「塔の管理人が七日戻らない」噂だけ。帰還の弓師の行を「……ただいま、戻りました。」、時計塔への交代の主人の行・弓師の行を差し替える（計 3 行）。出撃会話の主人の 2 行（沖に流れ着いた・小舟を貸す）も幽霊船の導入として承認。
7. **残すもの**: 「帰る場所」の会話、錨の噂、酒場の角灯、瓶の手紙（行き先・意味は変えない）。

## Reason

- Human の依頼（GHOSTSHIP-REBUILD-001 / -002）。幽霊船を時計塔へ渡すための章ではなく、単独で導入から脱出まで完結するシナリオにする。
- 因果（誓い → 錨 → 点呼 → 二人が数えられる → 構造の変化 → 鎖を手放す → 錨が落ちる → 昇降口が開く）を、皿・矢印・扉・点呼板・鎖の音で見せ、「ボスを倒したからマップが戻った」というゲーム都合に見せない。
