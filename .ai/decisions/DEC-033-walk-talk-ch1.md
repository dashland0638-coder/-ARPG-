# DEC-033 — 歩きながらの掛け合いを第一章の宵待ちの村・幽霊船・時計塔へ広げる

Status: Accepted（Human の依頼「WI：第一章・移動中会話システムの横展開」2026-11-22。実装仕様は Agent。DEC-029 の「二つ目のシナリオで使う時」に当たる）

## Decision（Human の依頼）
- 道（新）の移動中会話を第一章の他のシナリオへ広げる。単純なランダム台詞にしない。キャラクター・関係・舞台・直前の出来事・初訪問と再訪問・加入状況を考える
- 既存の道の動作を変えない・劣化させない。不要な保存項目を足さない

## 実装仕様（Agent）
| 項目 | 決めたこと | 根拠 |
| --- | --- | --- |
| 対象 | 宵待ちの村（魔法使い＋剣士）・幽霊船（弓師＋魔法使い）・時計塔（盗賊＋弓師） | 第一章の本編で支援が同行するシナリオ |
| 対象外 | 森の洋館（剣士ひとり。掛け合う相手がいない）、埠頭の地下水路・古代神殿・硝子の温室（第一章の本編の外。顔ぶれと物語の文脈が無く、第一章の台詞は旧成長のルールでは出さない）。「廃村」は宵待ちの村の旧名 | `docs/SCENARIOS.md`、DEC-004 |
| 共通の場所 | 流し方 `src/core/walk-talk.js`（旧 `road-banter.js`、関数名はそのまま）、表示・止める条件・帯の登録 `src/legacy/parts/14-walk-talk.js`。表示の id は `walk-talk`（シナリオの名前を持たない） | `docs/WALK_TALK.md` §3・§4 |
| データ | `src/core/walk-talk-ch1.js`（場所の帯・顔ぶれ・物語の進み具合の条件・台詞・もう一度出た時の台詞）。条件は各シナリオの既存の印を読む（時計塔の 1 層の鐘の出来事にだけ `towerStoppedSeen` を足した） | W-4 |
| 顔ぶれ | 操作している主人公と、今そばにいる支援の職業が合う時だけ（宵待ちの村の剣士は木橋で合流するまで出さない。テストモードの別の組み合わせでは出さない） | 「未加入・存在しないキャラクターの会話を出さない」 |
| 止める | 道と同じ（会話の窓・演出・一時停止・戦闘の緊張 0.35 以上）。横展開のシナリオだけ、会話の窓・演出で 3 秒より長く止まった話題は残りを捨てる（重要な出来事の後に前の話の続きを出さない）。戦闘で止まった間は捨てない | W-2、「会話中に戦闘・重要イベントが始まる場合の中断・終了」 |
| 繰り返し | 同じ話題はその出撃で 1 回だけ。出撃のたびに作り直す | W-3 |
| もう一度出た時 | 同じ出撃先へもう一度出た時（全滅・撤退の後）は、別の台詞のある話題はそちら。数えるのは遊んでいる間だけ（保存しない。読み込み直すと初回の台詞） | 「初訪問・再訪問」「不要な保存項目を足さない」。第一章はクリアしたシナリオへ戻れないので、再訪問は出撃し直しだけ |
| 道（新） | 自分の話題の列（続きから流す動き）はそのまま。表示と止める条件だけ共通のものを使う。会話の窓の間に前の行が画面に残っていたのを、隠すようにした（会話の後に続きから流すのは同じ） | DEC-029「道の見た目・試験は変えない」 |

## Consequences
- 第一章の他のシナリオに話題を足す時は `src/core/walk-talk-ch1.js` に足す（帯は止める会話・戦闘と重ねない。単体試験が部屋の中・重なり・顔ぶれ・行の長さを確かめる）
- 第二章以降で使う時も同じ共通部分を使う
