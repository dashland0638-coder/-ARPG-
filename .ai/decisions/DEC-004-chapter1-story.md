## Decision

第一章後半（宵待ちの村 → 幽霊船 → 時計塔 → 道 → 第一章の終わり）の物語接続を、
CS-01 の **B 案（推奨案）** で確定する（HE-1、Human Decision）。

| 項目 | 決定 |
| --- | --- |
| 案 | **B** |
| N-1（船は時計塔の鐘を頼りに港へ帰る） | 採用 |
| N-3（管理人の安否） | **生還** |
| 盗賊の過去 | 推奨案どおり。何を・誰から盗んだかは具体的には語らない |
| N-4（島から人影を先に見せる） | 採用。追加条件つき（下記） |

### N-4 の追加条件（Human）

- 加入前は**正体不明の人物**として扱う。名前を表示しない。「影の旅人」の名称も職業名も出さない。加入前のグラフィックを使う。
- 遠景や遭遇時に、**影が本人よりわずかに遅れて動く**違和感を見せる。怪異か人間かを断定しない。
- 道での遭遇でも、必要以上に正体を説明しない。
- **正式加入時**に加入後のグラフィックへ変え、このとき初めて「影の旅人」の名称を開示する（名前そのものが正体のヒントになるため）。
- 第一章では、四人が正体を完全には理解できないまま一緒に歩くことを選ぶ構成を維持する。
- 洋館の影の遅れ → 村の残響 → 帰れない幽霊船 → 七時十三分の時計 → 正体不明の人物の遅れて動く影、という「ずれ」の連鎖を維持する。正体と「ずれ」の原因は、第一章では説明し切らない。

### この決定から導いた実装上の扱い（Agent）

- 加入前の会話の話者名は「？？？」とする。既存の `registerProximityEvent` と同じ表記。
- 適用範囲は加入前の場面すべてで、**Chapter 1 本編の酒場の隅の NPC の会話を含む**。
  - 現状は `SHADOW_GUIDE_NAME = '影の旅人'` で名前が出ている。
  - テストモードと Chapter 2 以降の扱いは、CR-02 の実装時に既存の表示を壊さない形で決める。
- 正式な仕様は `docs/CHAPTER1_STORY.md`。

## Reason

- HD-C1 = b（幽霊船・時計塔に第一章専用の物語を足す）を、既存の素材（七時十三分、鐘、霧で港を見失う船、出ていった娘、射出台、名も無い島、隅の席）をつなぎ直すだけで実現できる。
- 幽霊船 → 時計塔が「次の噂」ではなく、因果（時刻の一致と船長の頼み）でつながる。
- 完成済みの洋館・村に手を入れない。

## Alternatives Considered

1. **A 案（最小）** — 不採用。幽霊船 → 時計塔に因果が無い。
2. **C 案（強化）** — 不採用。娘の行方を断定し、完成済みの村の報酬の意味づけを変える。
