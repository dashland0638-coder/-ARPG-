# DEC-018 — 第一章④ 時計塔「止まった時刻 ― 過去に縛られた後悔 ―」（全面再設計）

Status: Accepted（Human Decision 2026-11-10。依頼文「CLOCKTOWER-001：第一章④ 時計塔シナリオ・マップ全面再設計」に含まれる仕様の判断を記録。AGENTS.md §18）

## 決定（Human の依頼文から）

1. **全面再設計**: 既存の時計塔を拡張しない。残すのは「時計塔を少しずつ登り、最上階を目指す」体験だけ。シナリオとマップを一から作る
2. **フロア**: 1 フロアは従来よりかなり狭く、通常探索で 1〜3 分。無意味な通路・空きを作らない。各フロアに固有のギミック・イベントを最低一つ。迷うことを難易度にしない。上へ進むほど時間の歪みと過去の真相に近づく
3. **物語**: 毎晩七時十三分に時間が止まり、過去の光景や人影が現れる。管理人は塔の内部に閉じこもり、時間を止め続けている。主人公（盗賊、支援 弓師）は記憶の断片から、管理人が七時十三分に何を失ったか・なぜ時間を止めたかを明らかにする。テーマは「過去を変えられないなら、人はどうやって前に進むのか」。管理人を悪人にしない。娘は明るく自由な人物として描く
4. **ボス**: 「止刻の残響」（停止した時間と管理人の後悔が生み出した存在）。時計針の広範囲攻撃・歯車を飛ばす・一時的な行動制限・過去の残像・七時十三分に近づくと攻撃が変化。理不尽な拘束や長時間の待機を強制しない
5. **結末**: 戦闘後、管理人は過去を変えられないことを受け入れ、時間を再び動かす。娘を忘れるのではなく、思い出を抱えて生きる
6. **盗賊の Skill 2「三連投げナイフ」**: 弓師の戦い方を見て盗賊が自分の戦術を思いつく。教わる形にしない。見逃しても代わりの習得イベント
7. **第一章の制約は変えない**（レベル上げ前提にしない・スフィア盤・パッシブ・クラフトなし・装備は固定少数・武器種は職業固有）

## Agent の判断（依頼文の範囲での解釈。Task の Agent Decisions にも記録）

- 七時十三分に「失った」ものは、娘が家を出ていった瞬間と、その時に言った言葉（「出ていくなら、二度と戻るな」）。死別とは書かない
- 「管理人との対決」は会話の対峙とし、戦うのは止刻の残響（決定 4 の「後悔が生み出した存在」に合わせる）
- 跳躍・島・翌朝の酒場は残す。崩れ始めた塔で管理人が鐘を鳴らし、その一打で跳ぶ
