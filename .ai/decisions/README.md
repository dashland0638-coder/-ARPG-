# Decisions

AI開発中に決定した重要事項を保存する。

## Naming

```
DEC-001-short-name.md
```

## Template

```markdown
# Decision

## ID

## Date

## Decision

## Reason

## Alternatives Considered

## Consequences

## Related Tasks
```

重要な設計判断のみ記録する。

Task の未確定事項（DECISION、[`../AGENTS.md`](../AGENTS.md) §8）を人間が決めた場合は、
ここに記録してから Task の Approval へ進む。AI は決定を記録するだけで、自分で決めない。

一時的な実装メモはここに保存しない。
