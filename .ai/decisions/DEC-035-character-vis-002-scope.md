# Decision

## ID

DEC-035（CHARACTER-VIS-002 の頭身・改善範囲、ポリゴン接合の追加、モーション刷新の位置づけ）

## Date

2026-11-24

## Decision

Human が CHARACTER-VIS-002 の Escalation（E-1・E-2）に回答し、追加方針と T-0 の着手を指示した（PR #147 への追加指示）。

- **E-1 頭身 = A**: 全高を維持したまま 5.0 / 4.75 / 4.5 頭身の比較画像を作り、Human に提示する。Human が選ぶまで頭身を確定しない。**4.5 頭身未満は対象外**。DEC-T2-9（華奢で縦にスッとしたシルエット）は変えない
- **E-2 改善範囲 = A**: 承認済みの衣服・被り物・配色・キャラクターコンセプトは維持する。新しいデザインへの全面変更はしない。対象は造形品質・ポリゴン接合品質・見栄え・既存モーション品質
- **追加: ポリゴン接合・造形品質**: 頭部と顔・首と胴・胴と衣服・腕と袖・手と腕・肩肘膝の関節・髪と頭・帽子と髪・衣服同士の重なり・メッシュ境界の段差 / 隙間 / ちらつき・法線の不連続・輪郭線の接続・アニメーションで露出する隙間を調査し改善対象に入れる。**ポリゴン数を増やすことを解決策にしない**（頂点配置・形状・法線・重なり・接合方式を最小限変える）。**可愛らしいローポリ調は維持**し、すべてを滑らかにして個性・シルエットを失うことは禁止。描画負荷とのバランスと iPhone の性能を確認する
- **追加: アクションゲームとしてのモーション刷新**: 現状のモーションはプロトタイプ段階という認識。待機・歩行 / 走行・通常攻撃・コンボ・武器スキル・回避・被弾・戦闘不能 / 復帰・キャラクター切り替え・職業 / 上位職固有の動作を調査し、問題点と刷新計画を作る。目指す品質（職業ごとの立ち姿と控えめな生命感、足運びと速度の整合、予備動作→踏み込み→攻撃→フォロースルー→戻り、武器の重量、コンボの接続、スキルの差別化、回避方向の一致、被弾の重さと方向、不要な硬直を足さない）と職業別の方向（剣士 = 大剣の重量・踏み込み・安定、魔法使い = 優雅・詠唱・自然な復帰、弓師 = 構え・照準・射撃・弦、盗賊 = 軽快・左右の手の差、上位職 = 単純なコピーにしない）を示した。**攻撃判定・ゲーム時間・キャンセル仕様・操作応答性を維持**する。具体的な刷新は別途計画・レビューを経て実施し、CHARACTER-VIS-002 の造形改善と無理に一つの Task にまとめない
- **T-0 の実施**: 見た目・モーション・配色・Material の色値を変えない T-0 を実施する。影の旅人（加入前・加入後・フード・影の手）を剣士用の改善から分離し、共通関数の既定値を変えず、4職はオプション引数で改善を選ぶ設計を維持する。見えない鎧・不要部品の調査、描画回数の計測方法の整理と9キャラクターの記録
- **規則**: 並行実装禁止。各段階で独立 Reviewer の PASS。見た目が変わる段階は Human の目視承認を得てから次へ。比較画像には変更前・変更後が分かる情報を付ける。既存仕様・進行・セーブ・戦闘判定を勝手に変えない。影の旅人のデザイン・モーションを壊さない。main への merge は禁止（明示の Human 許可が要る）。PR の base は `claude/road-visual-003-r3-7`、既存ブランチの変更を破棄・rebase しない

## Reason

Human の判断（Escalation E-1・E-2 への回答と追加指示）。目標は「可愛らしいキャラクターが、自然な立体感を持ち、職業ごとに異なる魅力的な動きで戦う」完成したアクション RPG の品質。
