# Decision

## ID

DEC-039（CHARACTER-VIS-002 T-2R-3 顔造形方針の再定義: Stylized Realism / Geometry + Texture）

## Date

2026-11-28

## Decision

Human との協議により、キャラクターの顔造形方針を更新する。

- 従来の可愛らしいローポリ顔から、**骨格・顔面の凹凸・自然な横顔を持つスタイライズド・リアリズム**（FF7・ゼルダのような）へ方向転換する。**4.75 頭身とキャラクターとしての魅力は維持**する
- **ハイブリッド方式**: ポリゴンによる立体造形を主体とし、テクスチャで質感と細部を補完する
  - **Geometry**（メッシュの形で表現）: 額から眉骨・眼窩の奥行き・鼻筋と鼻先の高さ・鼻翼と鼻下・頬骨と頬・口元の前後関係・顎と下顎の輪郭・側頭部から後頭部の頭蓋。テクスチャや陰影だけで表現しない
  - **Texture**（Geometry の承認の後）: 肌の色むら・唇の色と質感・目元の陰影・頬の血色・肌の微細な表現・必要なら手描きの陰影
  - **Normal Map / AO**: 必要性を検証してから。顔の輪郭や鼻の高さを依存させない
- **品質目標**: 鼻筋が通り眉間から鼻先へ自然につながる・鼻先が前へ突出・鼻翼の立体・横顔で鼻の高さが分かる／頬骨による面の変化・頬の丸みと骨格・45° で奥行き・頬から顎へ自然／眼窩の中に目・眉骨との前後関係・**T-1 の目の基本仕様は維持**（職ごとの目は T-2R-4）／口元は鼻先より後退・上唇・下唇・顎の前後関係・顎は適度にシャープで尖りすぎない
- **合格基準**: **無地の肌色マテリアルだけで**、正面・45°・横顔で立体的かつ魅力的に見えること。満たすまでテクスチャに進まない
- **注意**: 鼻だけを大きくしない・顔面全体を前へ移さない・球体化しない・リアルな顔をそのまま縮小しない・目を大きくするだけで可愛さを出さない・過剰なアニメ記号も過剰な写実の皮膚も避ける
- **手順**: Phase A 共通顔面の立体設計 → Phase B 形状の実装（O1 の延長、必要な部分だけ頂点密度を上げる、髪・帽子・輪郭線・後頭部の髪の貫通修正を保つ）→ Phase C Human 確認（正面・45°・横・下・後頭部、同一条件、特に 45° と横）→ Phase D テクスチャ設計（Geometry の承認の後）
- **維持条件**: 4.75 頭身・正面の輪郭の良さ・下から見た頭蓋と顔面の接続・後頭部の髪の貫通修正・全身の可愛らしさとキャラクター性・影の旅人は不変・職ごとの差別化は T-2R-4
- **範囲**: 既存実装を分析し、Geometry 主体の新しい顔を設計・実装する。必要なら複数の形状案を顔確認モードで比較できるようにする。Human の承認の前にテクスチャ・職ごとの顔へ進まない。Build・Unit・関連 E2E・独立 Reviewer。PR の merge・main への統合・base/head の変更はしない

## Agent の読み方（記録）

- E-3 = B（DEC-037）の「小さな鼻（別部品の四角錐）」は、本決定の「鼻筋・鼻先・鼻翼の立体をメッシュの形で作る」で置き換える（別部品の鼻は作らない）。「控えめな口」「眉は足さない」は本決定に反しないので維持（眉骨はメッシュの形で作るが、眉毛は描かない）
- 「目の基本仕様（T-1）を維持」= 目の大きさ・間隔・高さ・縦横比・瞳・点数・傾き。目の奥行きは眼窩の形に合わせて顔の面から決める（`frontZAt`、面からの沈み込みは同じ量）
