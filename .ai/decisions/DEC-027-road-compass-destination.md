# DEC-027 — 羅針盤は「次の目的地」を指す・テストモードの顔ぶれと加入

Status: Accepted（Human の指示 2026-11-16「ROAD-VISUAL-003 R3-N 実機確認フィードバック対応指示」。DEC-026 HD-2 / HD-3 は変えない）

## 決定
| ID | 決定 |
| --- | --- |
| C-1 | 盗賊の羅針盤の針は、本道の 20 先ではなく、現在のシナリオの「次の目的地」を指す。距離・経路は出さない。隠し道・宝箱は目的地にしない |
| C-2 | 目的地のデータは、既存のシナリオ・イベント → クエスト → マップの地点の優先。道（新）には前の二つが無いため、マップの地点（各エリアの入口の野営地と石環、`ROAD2_DESTINATIONS`）を使う。新しい仕組みは作らない |
| C-3 | 目的地に着くと次へ進む（戻らない）。全部終えたら針はゆっくり回る（道の果ての回転の置き換え）。ボス後・シナリオの終わりは R3-5 / R3-6 で見直す |
| C-4 | テストモードの自由な主人公の選択と、本編の進行（加入の条件・`scenarioClears`・セーブ）を分ける。道（新）では、選んだ主人公のまま、同行ゲスト無しなら正規の支援を付け、出会いの一幕の後に正規の加入（影の旅人が主人公・盗賊が支援）を再現する。加入前の確認用・加入後の開始地点をテストに用意する |

## 変えないもの
- DEC-026 HD-3 = A（羅針盤は盗みと結ばない）。羅針盤の持ち主は盗賊のまま
- 左 8°・±15°・140°/秒・怪異の左右対称の揺れ・表示の条件（会話・戦闘・メニュー中は隠す、広域マップに連動、止まると薄く、文字無し・触れない・46px）
